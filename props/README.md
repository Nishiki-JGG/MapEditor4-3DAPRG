# 小物（props）

小物 1 種類につき 1 ファイルです。形・当たり判定・置ける場所などを、そのファイルだけで直せます。

- `common.js`：共通の部品です。葉・花びら・枝・石の削り・石積み・色、形を組み立てる `makeGeo` などが入っています。これを変えると、使っている小物の見た目がまとめて変わります。
- `foliage.js`：葉・針葉・ヤシ／シダ／バナナの葉・草・樹皮を、起動時に 1 枚のテクスチャに描きます（画像ファイルは使いません）。カードと曲げた葉の形の部品も入っています。
- `foliage2.js`：2 枚目のテクスチャ（1024×512）に、草むら・藁・風雨で色の抜けた木目・野の花 4 種・花の根元の葉を描きます。
- `detail.js`：岩肌の細かい模様のテクスチャ（継ぎ目なし）を描きます。
- `<id>.js`：小物 1 種類分のファイルです（例：`oak.js` が広葉樹）。

## 1 ファイルの中身

```js
TDProps.add({
  id: 'oak', name: '広葉樹',                       // id は書き出し・保存データで使う名前。変えないこと
  r: .6, min: 3.2, sc: [.8, 1.3], slope: .8, vis: 2.1, tree: true,
  sway: .5, tags: ['grassland', 'forest'], height: 5.53, material: 'foliage', canopy: true,
  build() {
    const { makeGeo, mat4, leafGeo } = TDGeo;      // common.js の部品を使う
    ...
    return makeGeo(parts, 12, { ao: 1.4 });        // 形（頂点色の低ポリゴン）を返す
  },
});
```

| 項目 | 意味 |
|---|---|
| `id` / `name` | 種類の名前 / 画面に出す名前 |
| `r` | 当たり判定の半径（m）。0 なら通り抜けられる |
| `offs` | 当たり判定の円を横に並べる位置（m）。壁や柵のような横長の物に使う |
| `height` | 当たり判定の上端（m）。`asset_catalog.json` にそのまま出る。見た目を変えても、この値は自動では変わらない |
| `min` | 撒くときの、ほかの小物との最小の間隔（m） |
| `sc` | 撒くときの大きさの範囲 |
| `slope` | 置ける斜面の急さの上限 |
| `vis` | 見た目の広がり（m）。中に入ったときに半透明にする範囲 |
| `tags` | 出てくるバイオーム。`['common']` ならすべてのバイオーム |
| `anyGround` / `tree` | どの地面にも置ける / 木として扱う |
| `sway` | 風で揺れる強さ |
| `light` | 光る物の明かり：`[色, 強さ, 高さ]` |
| `material` | `'cards2'`：2 枚目のテクスチャ（`foliage2.js`：草むら・藁・木目・野の花）を貼る。`'ice'`：氷（縁が明るい）。`'snow'`：雪（細かい粒）。`'gloss'`：光沢のある石。`'cards'`：葉のテクスチャ（`foliage.js`）を貼ったカード。`'foliage'`：植物用のなめらかな陰影。`'rock'`：岩肌と苔、岩壁の種類の色。`'stone'`：岩肌（石積み・石像など）。省略すると普通の材質 |
| `canopy` | `true` なら、自分の影を受けない（でこぼこの樹冠がまだらに暗くなるのを防ぐ） |
| `touch` | `true` なら、歩くモードで主人公が触れたときに押しのけられ、離れると揺れながら戻る（見た目だけ。今は茂み・シダ・葦・花・草むら） |

## 直す・差し替える・足す

- **直す**：そのファイルの `build()` か項目を書き換えて、ブラウザを再読み込みします。
- **差し替える**：同じ `id` のまま、ファイルを入れ替えます。
- **足す**：
  1. 新しい `<id>.js` を作ります。
  2. `index.html` の小物の `<script>` の並びに 1 行足します。
  - 並び順が種類の番号になります。保存データには種類の名前（`propTypes`）も入っていて、読み込むときは名前で対応させます。そのため、順番を変えたり途中に足したりしても、前の保存データは崩れません。
  - この版に無い種類が入った保存データは、読み込みを止めてエラーを出します。
- 公開した後の変更がブラウザに残った古いファイルで隠れないよう、`index.html` の `?v=r15b` を版ごとに上げてください。

## 注意

- `rock` と `fern` は共有化の検証版です。同じ形・PNG・材質値をブラウザとUnityで使います。契約・三角形数・制約・取り込み方法は [共有小物の検証](../docs/SHARED_PROPS_PILOT.md) を参照してください。
- `pine`・`log`・`stump` と新規 `rootfan` も共通資産経路を使います。枝下の寸法、縮尺制限、草地の由来、検証結果は [草地・自然物の試作](../docs/TERRAIN_NATURE_BATCH.md) を参照してください。
- その他の小物の形は、エディターの画面用です。Unity には位置・向き・大きさと `asset_catalog.json`（当たり判定など）を出し、見た目は Prefab で作ります。
