## 見た目と共通化

レシピは `tools/plants/understory.js`、生成は `bake_understory.cjs`。既存の `MeshRecipe` と共有アトラスを使い、新しい画像・外部素材・有料素材を導入していない。最初の目視で小高木が疎らだったため、枝途中の葉を補い、同じ602三角形のまま共通の葉群画像で樹冠密度を整えた。三つ葉は葉先の角を丸め、白花も丸い形へ調整した。苔は共通画像の細部と小さな葉を使い、既存キノコの傘の向き・大きさ・縁を整えた。

全6点は同じ512×512の `woodland-plants-atlas-v1`（PNG258,248バイト）を共用する。5画像の内容・サイズ・フィルタは完全一致。小高木と針葉低木は既存のalpha cutout .42、他4点は不透明。縦十字カードは追加していない。小高木の葉は上を向く曲がった葉群面で、真上から葉面と輪郭を読む。画像の透過部分ではRGBのにじみ処理も既存のものを使う。

小高木の動く枝葉の最低点は標準縮尺で約2.270 m。1.8 m人物との余裕は約.470 mで、風・接触は水平変位なので高さを下げない。幹の衝突半径は.22 m、樹冠全体を通行障害にしない。最低2.1 mを保つには、全体縮尺×縦縮尺を約.926以上にする。自動範囲は全体1～1.2、手動の縮小や保存済み配置を勝手に変更しない。

根元の負Yを地面へ揃え、全6点の最低点はY=0、pivotは地面原点。モデルは地形の凹凸へ変形追従しないため、急斜面や段差では一部が浮く／埋まる場合がある。とくに低い地被は緩い面で使い、岩際の配置は高さと接地を確認する。

## 風・接触と既存2種の伸縮

小高木・針葉低木・三つ葉は、既存の共有GPU風と歩行接触を最初から使用する。風の最大変位は.18 / .10 / .045 m、接触上限は.025 / .09 / .03 m。小高木の標準樹冠は人物の手が届く高さではないため通常の接触では曲げない。針葉低木と三つ葉は移動方向へ押し分け、離脱後に減衰する。硬いキノコ2種と苔小岩は風・接触へ登録しない。

前回残った強風＋接触の伸縮は、スゲ・広葉ロゼットに対象を絞って抑えた。風と接触を足した最終水平変位に、種類別の上限をGPUで掛ける。スゲ.20 m、ロゼット.14 m、新しい三つ葉.05 m。縮尺と頂点重みに合わせて上限も変え、根元を動かさない。風だけ・接触だけが上限以内なら従来の応答を保つ。ほかの植物へ上限を一律に適用しない。

理論最大風と最大接触を同方向に足した8方向の検査では、局所辺長の最大比がスゲ1.318→1.182、ロゼット1.207→1.144、三つ葉の上限なし1.237→あり1.149になった。三角形反転なし。厳密な長さ保存の物理計算ではなく、伸縮自体は残る。

## 負荷・Unityの設定・再現

追加の全頂点CPU更新や新しい更新管理システムはない。新しい可動3種のGPU重みは計25,248バイト。既存の最大8,000個/種の設計では、追加5種の行列・色・ghostと可動3種の接触にCPU配列を計3,425,280バイト確保する（モデル・JSON等は別）。描画時のGPUバッファも必要。共通画像の増分は0。小高木の葉群cutoutはポリゴン数を増やさないが、画面上の重なりと影の断片処理は増え得る。

接触CPUだけの4,000株検査は候補114・活動4、95%点約.1 ms（このPCのタイマー分解能を含む）。全体FPS・GPU時間・スマホ実機・発熱・Android/iOSの性能は未測定。低ポリと共有画像は軽量化の方針であり、実機動作の保証ではない。苔や小さな葉など接近時の細部は簡略表現。

新しい `shared-plants/4` を使うには同梱UnityのRuntime・Editorを両方更新する。旧書き出しも読み込める。接触源は人物の足元に `SharedPlantContactSource` を付け、取り込みルートの `SharedPlantContact.source` へ明示割り当てする。植物を実行中に動かしたら `Refresh()` が必要。ゲーム本体への組み込み、ゲーム本体Playモード、Unity Built-in描画は未検証。

生成順は `node tools/plants/bake_new.cjs`、`node tools/plants/bake_grass.cjs`、最後に `node tools/plants/bake_understory.cjs`。今回だけ再生成する場合は最後のコマンドでよい。検査は `understory_source.py`・`understory_validation.cjs <基準checkout>`・`understory_gpu.cjs`・`understory_motion.cjs`・`understory_preview.cjs`・`understory_visual.cjs`・`understory_scene.cjs`。Unity隔離環境へ同梱Runtime/Editorと `UnderstoryChecks.cs`・`PlantMotionProbe.shader` をコピーし、PC指定のキュー経由で `UnderstoryChecks.Run` を使う。比較画像・個別PCのプロジェクト・ログはリポジトリ外に保存する。
