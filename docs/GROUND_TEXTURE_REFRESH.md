# 草・土テクスチャの更新（2026-10-21）

森林・草原の既存共通材質で使う草と土の画像を更新した。地形、植生配置、保存形式、通行判定、水、主人公には変更なし。

- 草：既存の自作 `tools/nature/grass-source.js` を再利用。色の大きな濃淡を残し、向きの揃いすぎない小さな葉の群れを重ねた。512²、4mタイルを維持。
- 土：従来の数値生成による土を引き継ぎ、細かな土粒・鉱物粒の明暗を追加。256²、2mタイルを維持。
- 両方とも従来の30度回転サンプルとの混合、mipmap、trilinear、異方性2、1回の色空間変換を保つ。normal mapや追加材質は増やさない。
- `shared_ground.json` は更新した画像をそのまま持つ。schemaVersion1/materialVersion3、既存ID、画像寸法、メートル単位の倍率は不変。UnityのBuilder・Shaderは変更不要。
- JPEG合計は67,846→108,536 bytes。RGBA8全ミップ概算は草1,398,100＋土349,524 bytesで不変。スマートフォンの性能測定ではない。

## 再生成

Pillow・NumPyのあるPythonで `python tools/nature/refresh_ground_textures.py`。草の入力は既存の自作画像のみ、土は固定乱数の数値生成。購入素材・Unityデモ画像・外部サービスは使用しない。元画像を変更しない。

## 確認範囲

PC Chromeの既存描画処理で、変更前後の草/土近景・境界7m/17m・サンプル実景を同じカメラで比較。書き出しと保存の既存検査を実施する。ゲーム本体への取り込み・Unity再描画・モバイル実機は対象外。

画像変更前からサンプル地形の出入口検査に3エラー、候補地点に2警告あり。変更後も内容と到達可能セル数が一致。これらをテクスチャ変更による合格とは扱わない。
