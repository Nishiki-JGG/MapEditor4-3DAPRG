# 配置プレビューのScene登録を復元

段階読み込みへの変更 c9610c7 で、共通previewのScene登録・初期非表示・renderOrder指定が抜けていた既存問題。表示フラグや形状は更新されるが描画されず、通常小物とタッチの曲線レールに影響していた。キノコ224の製品変更で発生したものではない。

初期化に1行だけ復元。空geometry、ready判定、遅延material生成、別groundPreviewとrailDragGroupを維持する。キノコ改修とは別コミット。

`node tests/placement-preview.cjs before` は固定旧版6d6a9a0のappのみをローカルで配信し、既存失敗を再現。`after` は現在のappで修正後を確認。専用headlessでマウスのキノコ・樽、タッチ曲線を入力し、Scene所属・実画素・確定形状/位置/回転/scaleが一致することを確認。visible/hidden画像差は旧版3例すべて0、修正後すべて正。ready未完/完了は既存フラグをテスト内で切替し、非配置tool・歩く/編集モードも確認。実ネットワーク遅延テストとは称さない。

既存入力境界テストも変更せず実行し、タッチ曲線、右/中ボタンの途中追加による取消とカメラ移行、静止ポインターのWASD取消を確認。直線/左右曲線/閉ループ/既存端点/一括Undo/保存再読込は同じリリースのローカル敷設検証を使用。

最初の診断の種類名誤りと、停止したフレームを進めず状態を読んだテスト誤りは修正して再実行。製品チェックを弱めていない。Native資産/Importerはこの修正で変更なし。公開ページは既知証明書エラーのため再アクセスせず、配信後の画面/hash確認は保留。
