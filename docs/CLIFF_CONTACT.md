# 自動配置岩と崖の密着

「崖に岩を自動配置」は、元の縦長の岩を配置した後、表示中の地形・崖面に合わせて傾きと位置を調整します。岩を消して隙間を隠す処理ではありません。地形・手置き・植生・水・橋・階段・マーカーは変更しません。

新たに採用する配置は接触90%以上、最大隙間12cm、元の中段・上段の可視点80%以上を条件とし、橋・階段・出入口の保護範囲を避けます。元メッシュの面・UV・頂点色を保ち、必要時は既存の接合岩を使います。成立しない岩は型・位置・大きさ・ID・色をそのまま維持し、完了表示で維持数を知らせます。維持した岩には元の隙間が残ります。全ての隙間を解消する機能ではありません。

計算は全件終了後に一括反映します。処理中に地形や配置が変われば結果を破棄し、ユーザーの編集を保持します。処理中は保存・別名保存・読込・書出し・再配置を無効にします。既存マップはそのまま読めます。自動配置の再実行は元と同じく自動岩を再配置します。手置きの岩は残します。

## 保存と描画

任意のcliffFits属性に確定形状と元部品SHA・入力署名・配置署名を記録します。描画は同じ形状に相当するアフィン行列を既存InstancedMeshへ適用し、保存・当たり判定・書出しは確定頂点を使います。行列と頂点の一致を読込時に検査するため、変換を二重適用しません。元部品の不一致や壊れた属性は拒否し、地形・配置の編集で古くなった形状を無効化します。Undo/Redoは形状も復元します。

## Unity向け出力

加工岩がある場合、meta.jsonのrequiredFeaturesにcliffFitsMeshV1、cliffFitsに対象IDを明記し、cliff_fits_mesh.jsonを追加します。配置済みprops.csvの対象IDの描画・衝突を確定形状で置き換える契約です。位置・法線・三角形はUnity座標へ変換済み。UV・頂点色・元の色倍率も含みます。

unity/Assets/MapSharedProps/Editor/CliffFitsMeshV1.csは補助読込APIです。元IDと部品SHAの照合後に元Renderer/Colliderを無効化して適用します。必須形式を無視して元形状だけを読み込まないでください。実ゲームのImporterへの自動接続・Unity上の描画/物理確認は今回の範囲外です。

## 承認後の上下重ね配置（2026-10-22）

自動配置の仕上げは、崖側への12度の傾斜と元の1.05倍の全高を持つ上下重ね方式へ更新しました。重なり45〜57%、上下を別の既存岩にして継ぎ目をずらします。特定の画角や片岸の座標で対象を限定せず、近い・同じ向きの崖の岩から隣接間隔を求めます。橋際も対象へ含め、保護範囲へ岩が入る場合は元の個体を維持します。

以前の密着90%等の数値は旧方式の条件です。新方式をその条件に合格したとは扱いません。幅保持・実形状の衝突・橋/階段/入口/スポーンの幾何保護を維持し、歩行可能点が岸際で少し減る場合でも主要経路を切らない採用条件へ変更しています。0.5m間隔（大きなマップでは1m）の連結領域で、橋・階段・各マーカーを含む領域と4㎡以上の草地が切断される配置は元へ戻します。微小な岸の端片を主要な通路とは数えません。元の岩へ戻した個体は完了表示で別記します。

layering:1を確定岩の保存に追加し、読込後の再適用で同じ岩をさらに二重化しません。表示は既存InstancedMeshへの等価行列、保存/衝突/出力は確定頂点という契約を継続します。
