# 共有小物の検証結果（Lambert・接地・正面順序修正版）

基点 `c9128cf7f49c877a1aefc5fc4cf0f55f624fdfc4`、ブランチ `pilot/shared-rock-plant`。ローカル検証版で、コミット・push・公開はしていません。現在の正本は `shared-rock-fern/4`、資産版は岩4／シダ3です。

## 見直しで見つかった原因と修正

- **三角形順序**：以前の共有データはZ反転後の三角形順序を補正していませんでした。Unityでは岩120面・シダ220面すべての順序が法線と逆で、岩の裏側の面が見えていました。無照明の岩の模様も一致しなかったため、照明差だけではありません。Unity用の正本は各三角形の第2・第3頂点を交換し、ブラウザではZ反転と同時に交換して元の正面へ戻します。修正後、逆向きの面は0です。
- **接地**：全体の最下点を0にするだけでは、3塊ある岩の小塊が浮いていました。小塊2つをそれぞれ10.916591mm／65.251932mm下げ、各塊の最下点を0にしました。形の細分化や三角形の追加はしていません。撮影用の地面も5mm下げる設定をやめ、実際のY=0に合わせました。
- **材質**：共有化にPBRは不要です。ブラウザは `MeshLambertMaterial`、Unityは拡散照明のみのshaderにしました。PBRのBRDF・鏡面反射・粗さ・金属度・環境反射を外しています。Unity URP版は主方向光＋環境光の頂点照明、Built-in版はLambertです。

## 証拠と判定

最終の機械判定・数値は作業フォルダーの兄弟 `shared-props-final-evidence/summary.json`、`visual-comparison.json`、`browser-results.json`、`unity-results.json` に保存します。

| 確認 | 方法 |
|---|---|
| 軽量な元メッシュ | `node tests/shared_props_source.js`。岩120→120、シダ220→220三角形。記録した接地移動・軸変換・正面順序以外の位置・法線・色・三角形接続を比較 |
| 保存・既存書き出し | 元版で作ったマップを読み、CSV・meta・地形・水などを比較。追加ファイル・任意カタログ参照・manifest以外の一致を確認（書き出し時刻を除く） |
| 実配置・材質 | 通常高と明示高、異方性拡縮、yawOffsetを含む4配置をブラウザとUnityで全頂点照合。Lambert契約、両面、cutoff=.42、深度書き込みを確認 |
| UV/画像方向 | 法線・頂点色・照明を使わない参照shaderで岩の模様を比較。四隅が異なる色で左上にLがある非対称PNGも両環境で描画。シルエット重なりと岩の内部画素差を別々に計測 |
| 実接地 | 地面上面Y=0、横からの正射影。岩の3塊とシダの最下点を数値で照合し、画面上の下端と地面の隙間も確認 |
| 葉の抜き | FOV38度、俯角.9rad、7m（歩行カメラ最短）／17m（既定距離）、1024×640で描画。17mではカメラを横へ1cm動かした別画像も保存 |

画像・材質数の予算は各1材質、岩256×256／シダ512×128、RGBA8・ミップなしで計512 KiBです。画像ファイルは岩57,871 bytes、シダ36,083 bytesで、変更していません。葉は従来の11枚・220三角形のまま、半透明合成を使わずアルファ抜きです。元のアトラスなど他のエディター画像のメモリはこの予算に含みません。

静止画で葉の細い部分に点状・ギザギザの輪郭が残ります。ミップなし・アルファ抜きによる細部の欠落は、特に17mで確認対象です。三角形を追加したり、葉を増やしたりしていません。以前の深度検査前の重なり推定（平均1.178〜1.581層、最大5〜7層）は参考値であり、GPU測定ではありません。

環境光の評価・追加ライト・色管理はエンジン間で完全には統一していません。無照明の一致判定と、照明付きの見え方を区別します。スマートフォンで速くなったとは主張しません。

**NotRun**：Android/iOSのPlayerビルド、スマホ実機のGPU時間・フレーム時間・発熱・実メモリ、ゲーム本体のPrefab解決・衝突統合、影の見た目、実機での移動中のちらつき。Unity 6000.5.9f1／URP 17.5.0の隔離プロジェクトで検証し、ゲーム本体は起動・変更していません。

Libraryの画像転送はHTTP 403で拒否されています。再試行・別経路での回避はせず、画像はローカル保存のみです。添付IDはありません。以前の不一致画像とログは `shared-props-v2-evidence/` に保全しています。

## 最終判定

状態は **Ready with limitations**。ブラウザ9項目、Unity30項目、実画像比較5項目がPassed。逆向きの三角形は岩・シダとも0、各岩塊とシダの最下点はY=0です。基準面が描画されていることも画素で確認し、両環境とも見える下端と基準面の隙間は0pxでした。

無照明のシルエットIoU=0.996205、岩内部55,242画素のRGB平均差=0.4292/255、相関=0.999013。四隅の色とL印が一致。実配置の最大頂点差は約0.067mmで、PNGのSHA-256、法線・頂点色・UV・接続は一致しています。

17mでの葉の外周は両環境とも76×66px、緑の画素はブラウザ945／Unity943。横へ1cm動かした画像は989／992画素となり、細い葉のサブピクセル依存は残ります。これは1024×640・MSAAなしの比較条件による静止画診断であり、実機の時間方向測定ではありません。

最終画像は `final-browser-front.png`、`final-unity-front.png`、`final-contact-rock.png`、`final-contact-fern.png`、`browser-unlit.png`、`unity-urp-unlit.png`、各 `plant-7m/17m` 画像です。水・他の小物など89ファイルは不変。差分検査とpatch検証を行い、ステージ済み・未コミット・未pushで引き継ぎます。
