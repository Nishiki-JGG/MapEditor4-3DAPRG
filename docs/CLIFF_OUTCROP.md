# 崖石を柱から岩塊へ変更

`props/cliff.js` の五角柱を並べた形を、幅のある主岩に高さの違う張り出しが重なる形へ改善した。

- 主岩は輪郭が連続したメッシュ。途中のくびれ、張り出し、欠けた上部で長い直線を崩す。
- 低い岩塊を重ねて裾を厚くし、地面へ沈める。上に浮いた小石の帽子は使わない。
- 元の岩色・苔・濡れ・雪・粒子の材質処理を流用する。新しい画像や材質は作らない。
- `cliff` のID・配置座標・回転・倍率・外寸・高さ設定を維持する。既存部屋を作り直す必要はない。
- 1パーツ130→475三角形。同じInstancedMeshを使うため描画呼出は増えない。
- 当たり判定は既存の `shapeFootprint` が新しいメッシュの輪郭から再計算する。形が変わるので局所的な通行可能範囲は変わり得る。
- 保存形式は同じ。exporterVersionは `tdj-map-editor/2026.10.21-r18`。

## 確認

- `node tests/cliff-shape.test.cjs`：元の外寸、決定性、有限値、面積のある三角形、法線、600面以内。
- `node tests/cliff-collision-browser.cjs`：0/90/180/270度×0.9/1.2倍の8条件で、岩の中央は通れず、外側は通れ、メッシュ由来の判定を使う。
- 同じ48m遺跡で見た目、描画、保存再読込、反復export、既存の出入口/階段警告の増減を確認する。

## 範囲

Webエディターの既存崖石の造形変更。Unity側の同等Prefab/メッシュへの変更と実機での物理確認は含まない。カタログの対応Prefabが古い形のままであれば、Unityでは古い形が出る。
