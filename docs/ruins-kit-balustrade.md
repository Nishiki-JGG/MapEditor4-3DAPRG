# 透かし石欄干（ローカル候補）

既存の低い床縁と高い壁の間を補う、回廊・高床用の低い石欄干。`balustrade` と `balustrade:carved` を個別選択する。既存25構造種・既存配置を置換しない。

- 接合点間2m、厚さ0.5m、高さ1.1mの固定規格。90度回転。自由拡縮は非対応。
- 3つの透かし穴（高さ0.70m、幅0.39/0.42/0.39m）。人用の開口ではない。通常の身長1.6m・半径0.25mで通過不可。
- 両端は既存の壁系接合点。高さ1.1mの壁・角・T字・端部との接合が可能。高い壁と高さを自動調整して接合しない。
- 高床上に置くと支持IDを保存し、床高変更に追従。支持床の先行削除・支持範囲外への移動は一括拒否。既存の格子吸着／パーツ接合を利用。
- 透かし穴は実形状。Unityは描画メッシュと同じMeshColliderを参照。Webは既存の箱集合による保守的な衝突で、摩耗角の微小な差は従来同様。
- 簡素版と装飾版の形状は同じ。装飾は上笠石に限定し、幅約68cmの大きな菱形凹彫2箇所で通常俯瞰の識別性を確保。既存の石材3マップ・共有材質・局所摩耗を再利用する。
- 保存形式 `ruinsStructuresV1` を継続。新しいkindを受け付けない旧Importerはホワイトリスト検査で拒否する。旧バイナリの実行検証ではない。

跳躍・乗り越え機能、任意寸法、曲線欄干、独自の欄干角、複数階の手すり規則は対象外。必要な角は既存の同高壁系部材で構成する。

正式Web保存／exportと専用Unityの最新検証結果は作業フォルダーの `ruins-work/balustrade51-final-report.json` を参照。製品公開と元ゲーム組込は行っていない。
