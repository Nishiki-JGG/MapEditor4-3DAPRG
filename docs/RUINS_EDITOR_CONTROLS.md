# 遺跡の格子と壁の削除

- 「0.5m格子を表示」は地面と高床に沿った格子です。カーソル位置で地図全体が上下しません。
- 格子吸着は部材の接合点が基準です。長さ1.5mの壁などは中心が格子交点にならなくても正常です。
- 壁を消すには「地図で選択（削除・編集）」をON → 壁をクリック → 黄色枠を確認 →「選択を削除」。選択欄からも選べます。
- 移動は選択後に「選択を移動」→ 移動先をクリック。新規は「新しく配置」から。
- Ctrl+Zで削除を取り消せます。参照されている支持床などは従来通り削除を拒否します。

## 検証範囲

格子吸着後に地面高と支持床を再計算します。保存形式・部材形状・Unity形式は変更していません。

個別実行の遺跡基本15項目・統合・格子と選択の回帰テストは合格。ブラウザーでは格子、配置、直接選択、削除、取り消し、再選択、移動、空白クリックを確認しました。

CJS一括検査は未検証テレメトリー通信に対する実行制限で完了せず、全件合格とはしていません。
