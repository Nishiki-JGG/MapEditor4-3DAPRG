# 草・土と崖の表面改善（2026-10-22）

参考はユーザー提示の川・橋・草地の画像。観察した差は、低い草の土台と細葉の群れ、道の中央と縁の密度差、細かな石粒、不揃いな草と土の境界。画像と同じ完成品質に達したという判定ではない。

- 既存の草・土画像を再利用して細部のサンプリングと斜め視点のフィルタを改善。土には数cmの埋まった粒を加え、草との境界を大小2段階の揺らぎにした。
- 既存の三つ葉・黄花・白花・小石を再利用。不足していた細葉の草だけを追加（meadowgrass、30枚の曲がる葉、150三角形、共有atlas再利用）。共有小物JSONにも同じ形を出力する。
- 森林・草原の自動下草は数mの密度差と草丈差を持つ。土の中央・水中・急斜面・橋・階段・入口の中心には生やさない。小石は通行判定なし。
- 既存の保存マップは読込だけで配置を変更しない。「草・小石を更新」で適用でき、Undoで戻せる。地面の塗装とサンプル生成でも更新する。手置きの小物と崖の自動岩は保持。
- 他担当の樹木・根元改善（3c6019eまで）を取り込み、根元と草地の土の混合式を揃えた。

崖は肩の付近だけ表示用の面を細分化し、連続した勾配から草と岩の境を決める。地形編集用Hと歩行用の高さは維持。補間の変位は双線形高さから最大15cmで、橋・階段・滝・水際・既存岩の周囲は抑制する。実装は terrain/cliff-shoulder.js。表示用地形は terrain_visual_mesh.json に出力し、元の地形描画との二重表示を禁止する情報をmetaに記録する。

検査：同一構図の道・木陰・川岸で比較、保存再読込、自動生成の再現性（再生成するIDを除く）、手置きの維持、歩行1,024点、描画Shaderのコンパイル。崖は別途2,500歩行点と橋・階段、合格済み588岩の形状・配置保持、面の連続性、表示と出力の頂点数を確認。既存port_0001の着地点警告は残る。

負荷：64m比較マップの草・花等の自動配置は336から3,123へ増加。撮影した近景の描画三角形は約48万から98万。増分は主に細葉の草。大きなマップでは面積に応じて自動配置密度を抑える。実機GPUのFPSは未計測。

再実行：node tests/cliff-shoulder.test.cjs と node tests/ground-detail-browser.cjs。比較画像と実行記録は制作担当stagingに保存。

未実施：Unityの実取込・Shader描画・ゲーム本体統合。草の共有メッシュは書き出すが、Webで追加した地表の粒・境界・表示用の肩補間をUnity側で同じ絵にするconsumer更新は別途必要。既存のUnity側Shaderは変更していない。樹木・川・橋そのものの追加改修は今回の範囲外。
