# 洞窟の新規標準床を既存の土へ変更

基準は取り消し後の `2188fbd`。`terrain/paint.js` の洞窟既定値を荒れ地（3）から既存の土 `dirt`（0）へ変更する。土・荒れ地の画像、色、シェーダー、材質は変更しない。新しい材質や画像は追加しない。

新規洞窟、洞窟での新規平面・新しいランダム生成は土を標準床とする。塗装済みの荒れ地などは保持する。

旧保存には標準床の指定がないため、洞窟の旧保存は従来の荒れ地を既定床として読み込む。塗りデータを書き換えて移行する処理は行わない。洞窟の新規保存には任意項目 `baseGround` を既存IDで記録し、再読込や取り消しでも選択を保持する。古いエディタはこの項目を解釈しないため、新しい未塗装の洞窟床を古い版で開くと旧既定床で表示する場合がある。

既定床の判定を変更しただけで、新しい毎フレーム処理や崖岩の再生成は追加しない。固定森林・遺跡サンプルは完成内容を変更せず、生成元・スクリプト構成に対応する署名だけを更新する。

確認用コマンド：`node tests/cave-default-floor.cjs`、`node tools/build-prepared-samples.cjs --check`。別途、基準版との土・荒れ地・旧洞窟保存の同条件画像比較、保存再読込、既存マテリアルの不変を確認する。これは床の選択変更であり、品質改善や拒否された洞窟素材の再導入ではない。
