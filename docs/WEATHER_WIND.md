# 天候による草木の揺れ

そよ風でも葉先と枝先が動き、強風・暴風雨では大きくあおられます。天候の強度0と「なし」は静止します。雨粒、水面の波、衝突形状には変更を加えていません。

既存の保存済みマップ・共有メッシュ・材質をそのまま使います。風の計算はGPU側に集約し、WebとUnity用書き出しのSharedPineWind.hlslで同じ式を使います。幹の根元と静止小物は動かしません。

変更理由：従来は強さの二次減衰と弱い往復成分が重なり、微風がほぼ見えませんでした。また最大強度の暴風雨1.1が1.0に制限されていました。

現在の応答は 2.6*s*(0.7+0.3*s)*(0.2+0.8*wave)、sは0〜1.1、waveは既存の二つの正弦波の合成です。波の速さは1+0.65*s。最大応答は2.946です。描画境界には資産の風変位の3倍を確保し、接触との合算上限にも追加の風変位を含めます。

pine_wind.json の response は従来の取り込み互換用、animationResponse が現在の表示方式です。保存形式・部品データの再生成は不要です。

検証: tests/weather-wind-browser.cjs。固定カメラ・時刻指定で天候4種を比較し、GPUの描画変化、無風静止、CPU頂点書き換えなし、暴風雨の最大強度保持を確認します。
