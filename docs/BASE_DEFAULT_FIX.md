## 海岸の確認

海岸は砂ブラシではない。初期コミット `c3eab70`（作者 Claude）からある `makeCoast(a,c)` は、陸から海へドラッグした範囲の地形を削り、浜から海へ下る地形と海表示を作る。砂塗装はその内部処理の一部。キーは L。R26の `strandline()` は貝殻・漂着物を配置する。現行公開 `9dd9c14` に対して両関数の本文は変更していない。水・波のファイルも変更していない。
