# 崖の岩の改善（2026-10-21）

目的は、縦長の岩が見える量を維持し、巨大な黒い単独岩の張り出しと単調な反復を減らすこと。
既存の岩・小石を加工した6種を使う。購入素材全体を再作成する変更ではない。

| ID | 役割 | 加工元 |
|---|---|---|
| cliff | 縦割れの基本岩 | 旧縦長cliff。長い面を層分割して風化したくびれを追加 |
| cliff_split | 斜割れ・片側欠け | 旧縦岩の隣接する2本を抽出して加工 |
| cliff_shoulder | 段状肩 | 現行cliffの肩と縦面 |
| cliff_joint | 継ぎ・角・終端 | 旧縦岩の一本を独立して加工 |
| cliff_slab | 低い裾岩 | 既存rockの形状を加工。暗い共有材質を継承しない |
| cliff_talus | 崩落小石群 | 既存pebbleの向き・高さを変えた組合せ |

## 配置

- 現地の上下端に合わせて縦に伸ばす。横倍率を高さ計算で相殺し、実メッシュの高さと最下点から配置する。
- 主面は3形状を組合せ、細い継ぎ岩は橋際など幅の厳しい場所に使う。岩を隠したり、主面を小石へ置き換えたりしない。
- 上下積層を1本の縦伸ばしへ置き換えたため、個数の減少を見える崖の減少とは扱わない。同じ画角と岩帯の位置で比較する。
- 裾岩は配置後も幅1.2m・高さ0.45m・奥行0.6m以下。従来の最大幅5.48mの自動配置rockは使わない。低い小石は既存pebbleと同様、通行を塞がない。
- 橋・階段・出入口・着地点の余裕は、回転後の占有輪郭で確保する。中心点だけで通す判定はしない。
- 全加工部品は共通のrock材質と岩色を使う。元の手置きrock、植物、地形、水、橋は変更しない。
- 新しい部品は登録の末尾へ追加し、保存済みの種類IDを既存のremapPropTypesで復元する。

## 使用

ページを再読み込みして「崖に岩を自動配置」を押す。読み込んだ既存マップを起動時に勝手に再配置しない。
手置きオブジェクトは保持し、以前の自動配置だけを置き換える。

## 再生成と確認

原型と加工スクリプトは tools/nature/cliff-family/。三角形数を品質の代用にせず、輪郭・継目・陰影は画像で確認する。

    node tools/nature/cliff-family/build-cliff-family.cjs
    node tests/cliff-shape.test.cjs

Astraレビューに基づき、6種の部品・中立色/逆光・12m/36m・角/終端・2.4/4.8/7.2mの見本と、固定64mマップの前後比較を実施する。
6種で永久に十分とする計画ではない。不足は画像で位置と用途を特定してから追加する。
Unity版の取り込み・実機性能はこの変更では未確認。
