# 茂みの葉照明

丸く密な `bush` v2 の形状・色を保ち、内部に見える黒い葉面を軽減した。

既存の樹木補正は `rootWood` を使うが、茂みにはその識別がなかった。UV面積から葉144三角形と単色UVの木質40三角形を分け、葉だけに両面法線の補正と弱い透過光（逆光の直接光35%）を適用する。焼込みAO、自然な側面陰影、影の投影・受け取りは保持する。環境光や発光は増やさない。

ブラウザの風・接触フックへ連結し、Unityは茂み限定のキーワードと葉識別チャンネルを使用する。他の樹木・樹皮・根・水の照明は変えない。

## 負荷と検証

- 552頂点・184三角形・1材質、512×512共用画像を維持。追加画像・描画パス・透過面は0。
- メッシュの識別バッファはブラウザ2,208バイト、Unity4,416バイト増加。配置ごとの追加ではなく、毎フレームのCPU頂点処理も増やしていない。葉のシェーダー演算は増える。
- 上・斜め・歩行と光4方向の36比較、影の有無と無照明の診断、保存読込、歩行接触と復帰、ghost、継続描画を確認。
- 森林の94株で形状・描画回数・三角形数を維持。単体の木質内部ピクセルは変更なし。自然な暗部と葉の隙間は残る。
- 隔離Unity 6000.5.9f1 / D3D11で取り込み、葉識別、元の位置・法線・色・UV・揺れウェイト、他材質への漏れ、shader errorの検査と実描画を確認。
- 固定サンプルは最新mainの完成データを保持し、葉JSのキャッシュ識別に必要なキーのみ変更。岩・地形・配置・通路・水・衝突データは再生成せず、キーを戻した展開内容が元と完全一致することを検査する。

スマホ実機とGPU時間、ゲーム本体への組込み、Unity D3D12は未検証。三角形数据置きを性能保証とはしない。
