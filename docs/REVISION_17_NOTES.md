# マップエディター 修正報告（Revision 17）マップ名・名前を付けて保存・置く物の整理・暗さの段階

ユーザーの要望 4 件に対応しました。

## 1. マップ名

- 「マップ」欄に「名前」を足しました（80 文字まで）。
- 入れた名前は、次のところに使います。
  - ブラウザのタブの題名（「森の入口 - マップエディター 試作」）
  - 保存データ（`name`）
  - 書き出しの `meta.json`（`mapName`）
- 読み込むと名前も戻ります。名前の無い古い保存データは、ファイル名を名前にします。
- 「平らな新規」で名前は空に、サンプルでは「サンプル」「サンプル2（隠し通路）」になります。
- 名前は取り消し（`Ctrl+Z`）の対象にしていません。

## 2. 名前を付けて保存

- 「保存 (JSON)」（`Ctrl+S`）：`<マップ名>.json` で保存します。
  - ファイル名に使えない文字（`\ / : * ? " < > |`）は `_` にします。
  - 名前が空なら `map.json` です。
  - 名前の入力欄で `Ctrl+S` を押しても保存します（ブラウザの「ページを保存」は開きません）。
- 「名前を付けて保存」（`Ctrl+Shift+S`）：
  - Chrome・Edge では保存先とファイル名を選べます。最初はマップ名がファイル名として入っています。マップ名が空なら、選んだファイル名をマップ名にします。
  - その後の「保存」は、選んだファイルへの上書きになります。上書きする先は「マップ」欄に「保存先: ～（「保存」で上書きします）」と出ます。
  - 別のマップを読み込む・新しく作ると、上書きする先は忘れます。
  - 保存先を選べないブラウザ（Firefox など）では、名前を聞いてダウンロードします。
- 書き出しの zip 名も `<マップ名>_export_unity.zip` にしました（名前が空なら `map_export_unity.zip`）。

## 3. 置く物の整理

- 「置く」ツールの置く物を、小物の一覧と同じグループに分け、たためるようにしました。
  - 木・倒木
  - 草花・低木
  - 岩・崖
  - 遺跡・墓
  - 建物・道具
  - その他
- 選んでいる物のグループと、自分で開いたグループは、物を選び直しても開いたままです。
- グループ名の右の数字は、いまのパレットで置ける物の数です。

## 4. 太陽光なしの明るさ（3 段階）

- 「太陽光」のチェックを外すと、その下に「明るさ」が出ます。

| 段階 | 空の光（半球光） | 上からの補助の光（影なし・太陽の色） |
|---|---|---|
| 暗い（明かりだけ） | バイオームの値のまま | なし（今までと同じ） |
| ふつう | ×2.2 | 強さ 1.6 |
| 明るい | ×3.5 | 強さ 3.2 |

- 補助の光は影を落とさないので、洞窟の「上に太陽がある」ようには見えません。松明・水晶などの明かりはそのまま効きます。
- 洞窟の空の光の色はとても暗い（`0x6a7890`）ので、倍率だけでは明るくならず、補助の光を太陽の色で当てています。
- 霧の無い洞窟で、画面の平均の明るさ（0〜255）を比べました。
  - 暗い：1.1
  - ふつう：20.8
  - 明るい：39.3
- 明るさは、次のものに入ります。
  - 保存データ（`darkness`）
  - 取り消し
  - 書き出しの `meta.json`（太陽光オフのときだけ）：`darkness: { level, skyLightScale, overheadFill }`
- 前からあった不具合を直しました。
  - 天候で空の光を変える行が、コメントの続きになっていて動いていませんでした。
  - そのため、雷の光った後は、バイオームに関係なく空の光が 1 に戻っていました。
  - いまは、天候（雨・嵐など）で空の光も少し暗くなり、雷の後は元の値に戻ります。
