# マップエディター 修正報告（Revision 16）編集の操作

ユーザーの要望 5 件に対応しました。

## 1. 取り消し・やり直しを地図の側に

- 左のパネルにあった `↶` `↷` を、地図の上のバー（パネルの右）に移しました。パネルをスクロールしても、いつも見えています。
- `Ctrl+Z` / `Ctrl+Y` もこれまでどおりです。
- 画面上部のお知らせ（トースト）は、バーと重ならないよう少し下に出します。

## 2. 四角いブラシ

- バーの `○` `□` で、ブラシの形を円か四角にします。
- 四角は地図の縦横にそろった正方形で、半径は辺の半分です。カーソルの枠も四角になります。
- 効くツール：台地・上げる・下げる・平らに・なだらか、地面の塗り（草・土・石畳ほか）、岩壁を塗る、通行可・通行不可・隠し通路・自動に戻す、小物を撒く・消す。
  - 小物を撒く数は、面積に合わせて四角の方が多くなります（円の 4/π 倍）。
- 坂・階段・橋・滝・マーカーなどの幅は、これまでどおり半径から決まります。

## 3. 1〜9 のスロット

- `Shift+1`〜`9`（またはバーのボタンを `Shift`+クリック）で、いまの設定を登録します。覚えるもの：
  - ツール
  - その種類（橋・階段・置く物・マーカー・岩壁の種類など）
  - 半径・強さ・密度・ブラシの形
  - チェックした小物（種類の名前で覚えるので、種類が増えてもずれません）
  - 置くツールの大きさ・向き
- `1`〜`9`（またはボタンのクリック）で呼び出します。歩くモードでも使えます。
- 登録していない番号は、これまでどおりのツールです（1＝台地 … 9＝小物を撒く）。登録した番号は、バーのボタンの文字が明るくなります。
- 右クリックで登録を消します。
- 登録はこのブラウザ（localStorage）に保存されます。地図の保存データ・書き出しには入りません。
- いまのパレットで使えないツールの番号を押したときは、お知らせだけ出して切り替えません。

## 4. 歩くモードでも編集

- `Tab` の歩くモードでも、左のパネルを出したままにしました。
- 左クリック・ドラッグで、編集モードと同じように編集できます。
- ブラシの範囲（カーソルの枠）も出ます。歩くとカメラが主人公について動くので、毎フレーム、カーソルの下の地面を取り直します。マウスを止めたまま歩いても、範囲はカーソルの下についてきます。小物を撒く・消すも、ボタンを押したまま歩けば、通った所に効きます。
- ツールのキー（`z` `x` `c` など）も使えます。歩く操作のキー（W A S D Q E Shift）とは重なりません。
- 出入口などのマーカーと開始地点の印は、これまでどおり歩くモードでは隠しています。

## 5. 小物の種類をグループのツリーに

- 次のグループに分け、たためるようにしました。
  - 木・倒木
  - 草花・低木
  - 岩・崖
  - 遺跡・墓
  - 建物・道具
  - その他：グループの表に無い新しい種類は、ここに入ります。
- 起動時は、チェックの入った種類があるグループだけ開いています。
- 見出しのチェックで、そのグループの（表示中の）種類を全部入れる・外すことができます。一部だけのときは「－」になります。
- 右の数字は「チェックした数／表示中の数」です。パレットで隠れる種類は数えず、全部隠れたグループは見出しごと隠します。
- グループ分けは `app.js` の `PROP_GROUPS` にあります。
