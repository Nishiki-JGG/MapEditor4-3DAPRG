# 遺跡構造 v1 — ローカル実装中

ローカルの無装飾・直角構造の統合検証段階です。Webと専用Unity 6000.5.9f1 / URP17.5で正式出力・再読込・実Collider歩行を確認しました。製品の最終美観判定・公開・元ゲームへの導入は行っていません。

## 正本と編集

`ruins.js` の `{version:1,nextId,items}` が建築の正本です。各部材は独立ID、種類、位置、90度単位の向き、対応寸法、仕上げを持ちます。支持する高床と階段上床だけはIDで明示参照します。形状・歩行判定・地形非表示領域・地形補完面・exportをこの正本から生成します。

- 元の高さ配列を削らずに保持。高床を削除すると元地形が再び表示されます。
- 壁長は接合点間。壁厚0.5mは接合基準線の両側へ0.25m張り出します。内法と外寸は壁長そのものではありません。
- 角とT字は中心から0.5m先に接合点。終端は接合点から0.25mの厚み。内角／外角は同じL断面を向きで使い分ける初期構成です。
- 格子原点は世界XZ=0、刻み0.5m。奇数半格子長の壁は中心でなく接合点を格子へ合わせます。
- 格子表示、格子吸着、パーツ接合は独立チェック。両吸着ON時は格子に適合する接合だけを採用。接合距離0.3m以内、向き・高さ・厚みを検査します。
- 吸着は確定前だけ。保存後の再吸着、隣材の自動追随はありません。位置・寸法変更が既存構造へ干渉する場合は拒否します。
- 高床を参照する階段／壁が残る場合、削除は拒否します。高さ変更は階段の段割りを再計算して全体検査し、成立しない場合は全体を保持します。
- 階段は段高上限0.24m、踏面下限0.28m。2.2m差・3m長なら10段、段高0.22m・踏面0.30m。現行Web歩行は0.08m以下の移動分割で踏み越しを検査します。Unityでは半径0.25m・身長1.6m・stepOffset0.3mのCharacterControllerで昇降を検証しました。元ゲームの移動実装やPlayer実行の保証ではありません。
- 仕上げ変更は形状・接合・Colliderを変更しません。高床上は構造材の仕上げ欄で編集します。自然地形ブラシによる建築基礎の編集は拒否します。
- 編集候補の検査とメッシュ生成を終えてからUndoと正本を更新。Esc、フォーカス離脱、ポインタ取消、2本指操作、モード切替は未確定配置を破棄します。

高床上の既存小物は既存の固定高さ項目を使用し、保存と正式出力でも保持します。柱と巻き縄で確認済みです。階段上や高床から張り出す小物は拒否。小物を載せた高床の移動・高さ変更・削除で小物が浮く場合も拒否し、先に小物を移します。小物全種類の混在確認は未実行です。

初期範囲外：傾いた基礎、多層床、水・既存橋／階段・トンネルと重なる構造、斜め壁、任意拡縮、汎用ギズモ。既存の自然階段生成関数や小物一括削除処理は呼びません。

## 保存・出力契約

建築がない旧マップは従来の `map-editor-proto` と archive v1/v2 のままです。建築があるマップは `map-editor-ruins`、archive v3、`requiredFeatures:["ruinsStructuresV1"]` を使用します。旧Webの通常形式検査で誤読される形式を避けています。

正式exportは `meta.json` / `manifest.json` に必須機能を記し、`ruins_structures.json` を含めます。Webとは異なるUnity地形解像度で穴を計算し、穴のうち建築外側に残る部分を補完メッシュで復元します。補完面は地形全体の正規化UVを持ちます。Z反転と三角形巻き順反転を同時に行います。

`RuinsStructureImporter.Preflight` は地図を変更する**前**に必ず呼び出します。呼出側が対応機能の集合を渡し、未知必須機能・欠落・不正データを拒否します。旧Unity Readerがこれを実施するとは仮定していません。旧Reader／未更新のゲーム本体へ新形式を投入する対応は未完です。

`Build` は既存Terrainと新しいAssets出力先を受け、TerrainDataを複製して穴を適用します。元TerrainDataは保持し、成功するまでTerrainの参照を交換しません。同形状メッシュと同じ仕上げの材質を共有し、MeshColliderにも同じメッシュを使います。

補完面は標準URP Terrain/LitのTerrainLayerを利用できます。ラッパーshaderはURPの既存passを使用し、エンジン専用値を保存可能な材質プロパティへ接続します。4層ごとに追加描画が必要で、Colliderとmeshは共有します。TerrainDataのasset化時に塗り分けを32行ずつ転記し、Control参照を保存後に結び直します。5層・2パス・独立した色とUV尺度の診断で、通常Terrain対補完メッシュの検査画素RGB差は最大0。Prefab/Scene再読込後の塗り分けと参照も確認済みです。

設計上1～32層に対応しますが、全層数・normal/mask/height-blendの全組合せを実測した意味ではありません。カスタムTerrain shaderには呼出側が明示的な対応材質を渡す必要があり、黙って単色へ置換しません。Web側は元のterrain shaderと塗装属性を再使用し、地表の塗装更新に合わせて補完面だけを更新します。

利用側はこのフォルダーのEditorコードと2個のshaderを更新し、地図を変更する前にPreflight、通常地形の生成後にBuildを呼びます。既存TerrainDataを原本として保持し、新規Assets出力先を指定してください。現在の元ゲームのホストImporter接続と既存出力への上書き再importは、この専用検証の対象外です。旧Readerを使わないでください。

## 確認結果と残作業

`node tests/ruins-contract.cjs`：正本／依存、無効編集の原子的保持、段割り、格子／接合、角／T／閉ループ、異解像度の穴と補完面積、座標・巻き順・法線、非平坦基礎の拒否。

ローカルheadlessで確認済み：19部材の試験室・回廊・高床・階段、正式.map保存再読込、正式export、壁遮断と階段往復、低フレーム時相当の0.8m移動、寸法失敗／Undo、入力欄のQ/E保護、ポインタ／タッチ取消、不正読込で現行マップ保持、旧形式往復、既存レール直線／曲線／Undo／取消／保存。

試験室：19部材、720三角形、共有形状11、使用材質2。9／225個の単純壁について正本検査と形状数を測定しましたが、GPU・スマートフォン性能保証ではありません。

Unity検証：`RuinsReview.Run`（正式出力19部材・共有mesh/材質・元Terrain保持・Prefab/Scene）、`RuinsCapReview.Run`（5層材質・全塗り分け保持・画素比較・再読込）、`RuinsPhysicsReview.Run`（保存Sceneから壁/開口と階段往復）、`RuinsBoundaryReview.Run`（床レイと画面背景抜け）。いずれも専用Editorの非表示処理です。テスト用の色格子は診断材であり、遺跡の最終石材ではありません。

未確認：全既存小物との混在、元ゲームのホストImporter接続。旧Unity Readerバイナリ・GPU/スマホ/Playerは未実行です。公開はしていません。


## 石材仕上げと最小欠損壁（最終ローカル候補）

追加の質感改善では、既存同梱CC0 Rock050の32KB補助サンプルを自作石積みに合成した。石の長さ・粗さ・色の差を増やし、過剰な一様の欠けは比較後に弱めた。詳細と再生成手順は `ruins-stone-material.md`。形状と最終3textureの寸法・枚数は不変。

自作の石積みを256×256のalbedo/normal/surfaceの3枚で共有。2m周期、色はsRGB、normalとsurfaceは線形。Web surfaceはR=AO/G=roughness/B=metal。Unity取込時にR=metal/G=AO/A=smoothnessへ変換し、標準URP/LitのNormal/AO/MetallicGlossへ接続する。材質2種で同じ3textureを共有する。RGBA8全mipの参照見積は合計1,048,572B（CPU保持・ドライバ分を含まない）。GPU実測ではない。

`wall_broken`は壁上部の欠損1種。支持面、外寸、接合点は標準壁と共通、4区間の高さから表示と衝突を派生する。開口用の通路ではない。形のない透明な壁で塞がない。試験部屋では1枚だけ置換し660→720tri、他18部材、地形穴、補完形状は不変。崩れた瓦礫の独立量産はせず、必要なら既存瓦礫と組み合わせる。

通常俯瞰と反対光・欠損壁近景をWeb/専用Unityで確認。高床・階段・出入口は読めるため自動透過や露出変更を追加していない。低いカメラからは壁により床が隠れる。石目の反復、欠けの直角的な形は残る。専用試験部屋は地表補完を診断する5層チェック柄で、実ゲームの美術環境そのものではない。

最終石材版はRuinsCapReview/PhysicsReview/BoundaryReviewで正式import、Prefab/Scene再読込、共有texture、NormalMap取込とtangent、実CharacterController階段上下、壁/開口、境界を再検証。元ゲームへのhost importer接続、旧Unityバイナリ、Player、GPU/スマホは未検証。ローカル成果でありpush/deployは未実施。
