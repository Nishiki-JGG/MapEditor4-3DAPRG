# レールのドラッグ敷設（レビュー候補128）

公開済み `65d27a6883748d6e707591c1d8a62e29b4f092eb` から分離した入力機能の変更。未公開の岩壁は含めない。独立レビュー前であり、push・Pages公開は未実施。

## 操作

- 編集の「置く」で直線または曲線レールを選び、マウス／ペンを押してドラッグし、離すと一括確定する。直線・左右90度曲線を自動で組み合わせる。
- 自由端ではQ/E等の基準角度を使用。既存の空き端点付近から始めると、その外向き接線へ合わせる。サイズは自動変更しない。
- 規格は従来どおり、倍率1で直線2m・曲線半径2m・中心間隔0.84m・走行面高さ0.14m。倍率に比例して全体を拡大縮小する。終端は近い規格位置へ量子化し、カーソルとの差を補助線で示す。
- 緑は確定可能。赤は高さ、重複、接続先の向き／サイズ、短すぎる曲がり等が不成立。赤のまま離すと一筆全体を取消。既存端点への接続要求には自由端の長さ許容を使わず、端点・接線・高さを一致させる。
- 末尾2部品は方向変更に応じて再構成し、それ以前の経路は維持する。以前の端点へ戻すと縮められる。接線の合う4曲線の閉ループにも対応。
- ドラッグ中はサイズ／角度／ランダム設定を固定。Ctrl＋ホイールとQ/E/Rでは変更せず、表示でも知らせる。通常ホイールのカメラズームは継続する。右／中ボタンによるカメラ操作開始は未確定敷設を取消す。
- Esc、pointercancel、pointer capture喪失、ウィンドウblur、非表示、種類／道具／モード変更、新マップ読込で未確定分を破棄。プレビューはprops・保存・exportへ入らない。一筆がUndo一回に対応する。
- 一筆は最大64部品。車止めとタッチ操作は従来の単体配置。他小物のクリック／ドラッグ時の単体配置は変えない。

## 実装範囲

`props/mine-rail-drag.js` が経路・端点・線路重複判定を担当。既存レールmeshをそのまま使い、左曲線は右曲線を逆方向に使用する。負scaleや曲線の変形はない。`app.js` は未確定Groupと確定時の一括追加を担当。端点一覧はrebuild時のrevisionで無効化し、待機中の再計算を抑える。

mesh、material、ID、保存形式、export schema、Native製品ソース、Collider規格の変更はない。一般小物との干渉は従来の手置きと同じで、今回新たに検査する重複は線路同士。分岐・交差・任意曲率・車両走行は追加しない。

## 確認結果

- `node tests/mine-rail-drag.cjs`：左右曲線の実mesh端点、連続曲がり、4曲線閉ループと解放時の安定性、既存端点への始終接続、不正接続／重複／地形／境界拒否、尺度・回転、64部品上限、実マウスのpreview→release、一回Undo/Redo、7種類の取消、地下床、通常小物、保存再読込、exportが通過。
- `node tests/placement-shortcuts.cjs`：従来のCtrl＋ホイール／Q/E・上下限・入力欄・他道具／歩行モード等26項目が通過。
- `node tests/mine-rails-placement.cjs`：維持対象であるタッチ単体配置、端点、異倍率、地下床、保存再読込が通過。旧マウス単体配置の期待は新しいドラッグテストへ移管した。
- 正式Unity importer：48Prefab生成、公開基点48種すべてのmesh hashと実Collider保持。Webで敷いた6部品の5接合点・接線、共有材質1、保存→破棄→Prefab再instantiate、シーン保存→再読込を確認。専用Unity 6000.5.9f1／URP17.5を背景batchmodeで実行、終了0。
- 固定サンプル2件は既存bundle・歩行データを再利用。再生成関数を例外ガードして呼出0、5761／536配置。bundle内容・keyは公開基点から不変。`build-prepared-samples.cjs --check`も通過。
- 225本を別区画に分散配置し、8～9部品の経路更新20回を計測。直近CPU中央値約0.30ms・最大約0.40ms。主に遠距離除外が働く限定条件であり、最大密度・64部品・全機種の性能保証ではない。GPU時間は未測定。
