# 2026-10-31 起動時の完成サンプル拒否を修正

今回の保存軽量化commit `9f08124` が、通常起動時に「完成サンプルと現在の生成条件が一致しません」を発生させていた。起動用データの互換キーに全scriptの配信URLを含めていたため、保存/出力のみの変更に伴うapp.js・cliff-fits.js・map-storage.jsのURL更新で既存の完成サンプルが拒否された。

失敗後は開始前の空の状態への復帰と描画準備へ入る。今回のローカル実測では失敗した方の終了は正常版より短いため、ユーザー環境の待ち時間すべてをこのエラーで説明できたとは扱わない。今回の変更による起動失敗は実Chromeで再現できた。

当該3scriptには `data-preparation-key` で生成互換版を明示し、配信キャッシュを更新するsrcと分離した。モデルの頂点/index、体格、バイオーム、生成版などの照合と、完成品のSHA/長さ/内容検査は維持する。生成・衝突の意味を変える際はこの互換版を更新し、対応する完成品も更新する。未対応キーを無条件で受け入れる修正ではない。

Chrome・同じPC・loopback・使い捨てprofileで確認。通信回線や低性能端末を含む所要時間の保証ではない。
