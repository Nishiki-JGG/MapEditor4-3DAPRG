# 石窓壁：27番目の選択式構造部材

## 棚卸しと選定

既存26種は、壁・破損壁・崩落壁・開口・破損開口・内外角・端部・T字・壁龕の10種、アーチ2種・角柱2種・分割柱3種・梁の8種、敷石2種・高床・階段・床縁3種・欄干の8種。各構造に簡素／装飾仕上げがある。

不足する機能は「通路を増やさず、壁の向こうの空間を見通す窓」。壁龕は背面が塞がれ、開口とアーチは人の通路、欄干は低い柵であり、代替しない。装飾違いを量産せず、`window_wall` の1種だけ追加する。

## 規格と使い方

- `石窓壁`／`装飾：石窓壁` を選択。幅2m・厚さ0.5m、高さ2.2〜4m。90度回転。
- 開口幅0.9m、窓台高さ0.9m、上枠厚0.35m。ガラス・格子・扉・可動機構はない。
- 両端は通常壁系ソケット。同じ高さの壁・角・T字・端部に接合。幅と厚さの自由拡縮は不可。
- 高床支持、格子／パーツ接合、再配置、Undo、保存は既存正本データを利用。支持床の先行削除は拒否。
- 壁厚を通る実開口。Unity MeshColliderも開口を保持する。通常人物は窓台を乗り越えられず通過しない。ジャンプ・よじ登りを導入したゲームでの遮断保証ではない。
- 装飾は両面の枠・まぐさへ既存石彫を適用。簡素版の形状・材質体系を保持し、共有テクスチャの追加はない。
- 窓の光源・新しい採光システムは追加しない。既存照明と陰影を使う。

## 検証範囲
