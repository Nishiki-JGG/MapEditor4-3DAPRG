# 置物の岩：割れ面と石肌（2026-10-24）

大岩の丸すぎる形状を改善。既存の3塊構成・XZ寸法を保ち、大塊だけを、向きの異なる節理面が交差する岩体へ変更した。斜めの割れ目、上面の欠け、面の小さな起伏を形状に加え、割れ面の稜線を残す。脇石2個は元の形状を維持。灰褐色の鉱物粒・層理・細い亀裂・控えめな地衣の512²画像を流用する。

- 版はrock v6。大塊の位置・UV・面は更新、全体のXZ寸法・ピボット・種類ID・配置と衝突設定は維持。
- 合計120→1,480三角形。単純に全体を滑らかにせず、割れ目を造るために面を増やした。描画速度や実機性能の改善は主張しない。
- 配布: `props/shared/rock-surface.js`。起動時の形状/画像生成は不要。原稿: `tools/nature/rock-surface-recipe.js`。
- 再生成: `node tools/nature/bake-rock-surface.cjs`、続いて `node tools/build-prepared-samples.cjs`。旧固定サンプルは新版で置換する。
- `node tests/rock-surface-browser.cjs`: 脇石形状・XZ寸法の保持と裾の埋め込み、閉じた面、退化面/法線の反転なし、保存・書き出し、固定サンプル読込を確認。
- Unity: v4/v5互換を維持しv6を受入れ。同一PNG・位置・法線・頂点色・UV・面の受渡し、実取り込みとURP描画まで20項目PASS。
- Webの既存配置はページ再読込で更新。Unityの既存配置には最新インポーターでの再取り込みが必要。手順は [UNITY_SURFACE_SYNC.md](UNITY_SURFACE_SYNC.md)。

旧表面調整はv5として履歴に保持。ゲーム本体のScene更新、Windows build、スマホ実機の性能測定は未実施。

## 裾の接地修正（2026-10-24）

岩の底を地面と同じ高さに揃えると、すぼまった下面と影の組み合わせで浮いて見えるため、大塊を14cm、脇石を8cm埋め込む形状へ更新しました（倍率1、配置倍率に比例）。形状内の高さを補正し、Web表示・配置プレビュー・Unity向け共有メッシュへ同じ結果を渡します。XZ寸法、割れ面、影の設定、配置座標は維持。Yのみ埋め込み分下がります。岩v6の読込形式は変更ありません。

影の補正も修正：従来bias=-0.0004は48mマップの深度範囲267mに対して約10.7cm、64mなら約11.3cm相当となり、normalBias=4cmも加わって接触部の明るい隙間を生んでいた。深度補正をマップサイズに依存しない5mm、法線方向補正も5mmへ縮小。草・樹木を含むサンプルと岩の足元で比較する。Unityの既存Light設定は別管理であり、このWeb設定を直接流用しない。共有メッシュの裾修正はUnity書き出しへ含む。参考：https://threejs.org/docs/pages/LightShadow.html
