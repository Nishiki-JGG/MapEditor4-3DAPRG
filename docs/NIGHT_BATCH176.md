# 壁掛けランタン公開候補 176

独立評価91点、当該P1/P2なしの候補 `ba980286601accc69a3be9264b3e20dd5970777f` を公開する。旧種・他担当変更を保持した通常の追加コミット。固定岩サンプルは再生成せず、キー・完成bundleは前公開版と一致する。

## 導入と意図する変更

「坑道小物」の壁掛けランタンは床から1.65mを標準取付高さとし、壁へ向きを合わせて置く。鉄の支持腕・吊り環・ガラス・芯炎を持ち、既存の共有6灯枠内で新ランタンの影付き光を最大2灯に制限する。金銀虹の照明枠は別で維持する。

Unity利用時は同梱のImporter、RoomTorchBudget/Instance、MapTunnel.shaderを更新し、新しいJSONをexportして別出力先へimportする。古いPrefabへファイルを上書きするだけでは新種や変更は反映されない。保存後のPrefab再生成・再配置まで検証済み。

**坑道の主光源の影は従来と完全同一ではない。** ShadowCaster追加により屋根・壁・支柱が主光源も遮り、従来光が通った坑道が暗くなる場合がある。これは遮光の修正であり全体露出の変更ではない。影なし主光・SHのみ・全消灯はForward/Forward+双方で前後画素一致。点光の影・距離減衰とForward+の追加光も確認した。cutawayは表示用であり遮光形状まで無効化しない。

## 根拠と制約

- Native正式72Prefab（旧種保持）、不正optionalの旧51種fallback、任意Collider、保存後instantiateを確認。スロット移動で消灯先を取り違えるP2は6条件の移動/逆順/フェード差/無効化で再検証し、最終残留0。
- Web164種、壁取付・Ctrl+wheel・Q/E・保存読込・共有照明、レールドラッグと取消/一括Undoの回帰を確認。
- 9/225配置は見えている数9/121、mesh2/material2/texture4共有。CPU提出時間は限定条件の参考値。GPU、影付き多数灯の性能保証、スマホ、Player、旧Readerバイナリは未検証。Player起動・buildは行っていない。
- 近景の炎の白飛び、簡易ガラス、手動の壁合わせは残る制約。採点を完成無欠の保証とはしない。
