# 木橋の木目（2026-10-21）

既存の標準木橋に、`props/foliage2.js` の木目画像を再利用した。各板・手すり・支柱の長い方向へUVを向け、部材ごとに読む領域を少しずらした。橋の石の土台はアトラスの白い領域を読み、木目を付けない。

- 位置・法線・頂点色・三角形、板の間隔、手すり、橋脚、歩行床、配置、保存値は不変。
- 板の既存の色を保つため、画像の明度を平均で正規化して重ねる。材質は不透明のまま。既存の灰色の岩肌模様を木材へ重ねる処理は、この標準木橋では外す。
- 新しい画像・ポリゴン・透過パス・毎フレームCPU処理は追加しない。既存アトラスを共有する材質1個と木橋のUV配列を追加する。描画回数は増やさない。実機のGPU時間は未測定。
- その他の橋6種類・階段は従来の材質を維持する。
- PC Chromeの実エディタで近景を比較し、標準木橋と他6種類の位置・法線・頂点色・歩行床が変更前と一致した。書き出しはmanifest以外の24ファイルのSHAが一致。ブラウザ例外・GLエラー0。
- これはエディタの表示改善。橋の出力は従来どおり端点・幅・型・床曲線のデータであり、Unityの橋Prefabへこの表示処理を自動移植したものではない。
