# 骨・石像・装飾石柱の改修記録

比較基準は `e0c3b6a`。Webで実画像を撮影し、指摘・計画・形状改修・再撮影を8回行った後、2回の形状を保つ負荷調整を行った。失敗した撮影・構文検査・材質変更だけを独立した美術反復とは数えていない。

[同じ画角の変更前後](props-review/index.html)。画像は実エディタの描画から作ったWebP。元のPNGと全反復の記録はローカル証拠に保持している。

## 観察と改修の反復

| 回 | 実画像で見つかった問題 | 行った形状改修と次の判断 |
|---|---|---|
| 1 | 頭骨が箱、胸郭が均一な輪、関節端が同じ球 | 頭蓋・眼窩・頬骨・顎と長骨端を別の構造へ。顔面が浮いた仮面に見えたため不採用 |
| 2 | 顔面と後頭部がつながらない。像は柱の継ぎ合わせ | 顔面の側壁、頭・衣・手足を再構成。台座の上面欠落と袖口突出が判明 |
| 3 | 台座が開き、袖の始点と頭髪が歯車状 | 面の向きと袖口の埋込み、連続した頭髪、損傷像の共通人体を修正。顔・衣の平板さが残る |
| 4 | 顔面が板、石像に岩の大きい模様 | 顔面を湾曲させ、肩から落ちる衣を追加。対象だけ細粒材質・滑らかな法線へ。筒状の衣は未解決 |
| 5 | 肩と首の硬さ、固定された石柱片 | 衣の非対称な折り、独立石柱2部品。肩の突起と柱の扇状断面が残る |
| 6 | 胸郭・椎骨が直線的。柱断面が人工的 | 胸郭の曲率・間隔と椎骨の突起、断面内側の不規則な輪を調整。衣が胴から離れ、断面の裏面が判明 |
| 7 | 衣が平板、柱断面の面が消失 | 胴の丸い断面に沿う衣と面の向きを修正。19小物の一覧も確認し、容器・道具は識別できるため無差別な作り直しは避けた |

## 形・保存・負荷

- 骨は人型を想定した部分的な遺骨。完全な骨格・法医学用モデルではない。像は着衣の人物で、特定の人物の忠実な復元ではない。
- 旧ID・数値上の衝突半径・高さ・配置座標を維持。旧 `brokencol` は互換用に残す。新規の `brokencol_base` / `columnfragment` を独立して選択・配置できる。古い配置は勝手に分割しない。
- 6種の三角形数：骨700→2148、骨の山636→1310、頭骨606→1866、立像372→1554、座像376→1498、損傷像294→1322。合計2984→9698。新しい柱は根元444・先端288。
- Webの新しい画像・透過板・毎フレーム頂点処理はなし。新規の細粒材質は1種類。木箱・樽は既存1024×512アトラスを共用。
- 同一68個・1280×1000画面のPC比較：描画22→22回、描画三角形33194→60050。CPU処理平均2.48→2.41ms、GPUタイマー平均2.62→2.71ms、フレーム間隔約16.67ms。各80フレームの一例で、CPU差を高速化の成果とはしない。
- 全カタログの計測対象バッファ89780916→91929348 bytes。ジオメトリと新IDごとの通常／プレビュー用インスタンスバッファを含む。WebGL内部の実割当やドライバー全メモリではない。

## Unityと回帰確認

- 正式書出しに任意の `small_props.json` を追加。Webが使う19種の頂点・法線・色・UVと、既存の木目アトラスを出力時だけ生成する。編集・歩行時の余分なモデル複製はない。
- `MapSharedPropsBuilder` の既存取り込みから `SmallPropsV1` を呼び、同じメッシュのPrefabを生成する。古い書出しは従来通り。地面追従する道具・縄は個別姿勢を結合して取り込む。
- 隔離Unity 6000.5.9f1 / D3D11 / RTX 4070 SUPERで実取り込み・全19種の真上／近接描画を実行。43項目の技術検査で頂点・法線・色の一致、材質数、衝突の有無、旧柱と新2部品の取り込みを確認。
- Unityの一部の台座・溝には細い陰影が残る。小物限定の影バイアスを比較したが十分な改善がなく、そのシェーダー変更は採用していない。ゲーム本体への組み込みとスマホ実機は未検証。
- Webの実UI選択・配置、回転／倍率を含む保存再読込、旧形式、旧柱を確認。完成サンプルはキーのみ更新し、地形・岩・配置・通路・衝突の内容一致を検証。
- 森林／遺跡の変更前後で同梱復元、TAB移動、保存読込、破損キャッシュからの同梱復帰を確認。TAB後の岩再処理は0回。PC初回約9.4秒／6.9秒、起動の最大long task約395ms／774msが残る。
