# マップエディター 修正報告（Revision 8）水の流れ・泡・Unity 側の水

水（川・池・滝）に、流れと泡を付けました。エディターで1回だけ計算して書き出し、Unity 側は書き出しを読んで水面・滝・小川・飛沫・波紋を自動で作ります。エディターの画面でも同じ流れと泡が見えます。

- `exporterVersion`：`tdj-map-editor/2026.10.19-r9`（schemaVersion 3 のまま。既存のファイル・キーは変えていません）
- 確認：エディター側はブラウザ（Chrome を CDP で操作）、Unity 側は試験用の Unity 6000.5.9f1（URP 17.5）プロジェクトで撮影して確かめました。凸ダン本体への組み込みはしていません。

## エディター

- `water.js`（新規、画面に依存しない純関数。node でも動きます）：水の所・水深・流れ・流れ関数ψ・岸からの距離・泡の帯を計算します。
  - 流れ：∇・(D∇φ) = εDφ を共役勾配法で解きます。入口は滝の着水点（滝の幅に合わせた円）、出口は地図の端に接する水です。出口の無い池は漏れの項（12m）で静かに回ります。
  - 滝の無い川：地図の端に2か所以上で接する水は、水底が最も高い端を入口、ほかの端を出口にします。
  - 泡の帯：滝の着水点から、流れの筋にそって細い泡の帯を引きます。
  - 同じ入力からは、ブラウザでも node でも同じバイト列の画像になります（`Math.hypot` を使わない等）。
- 画面の水：流れで運ぶ細波、水際の泡の線、早瀬、泡の帯、滝の着水点から外へ広がる輪を描きます。編集の 350ms 後に計算し直します。
- 「水」の欄に次を追加しました。
  - 「流れを表示」：矢印と速さの色。
  - 「水際の帯（緑）と泡の帯（赤紫）を表示」。
  - 水の情報：水の所・滝・川の入口・警告の一覧。

## Unity 向け出力（追加のみ）

| ファイル | 内容 |
|---|---|
| `water_flow.png` | RG＝流れ（Unity の x, z）、B＝流れ関数ψ、A＝岸からの距離÷1.5m（0＝陸） |
| `water_mask.png` | R＝泡の帯の濃さ |
| `meta.waterSim` | 解像度・符号化・滝の着水点・川の入口・流れの筋・保存則の数・警告・未対応の一覧 |

- 水深の画像は持ちません。Unity 側が `heightmap_r16.raw` と水位から作ります。
- 海・溶岩・水の無い部屋は、`waterSim.available = false` と理由だけを書き、画像は出しません。

## Unity 側の水（`unity/Assets/MapWater/`）

Unity のプロジェクトの `Assets/` に `MapWater` フォルダごと入れます（`.meta` も一緒に。URP が要ります）。

- 作り方：エディターのスクリプトから `MapWater.EditorTools.MapWaterBuilder.Build("<書き出しを展開したフォルダ>")` を呼びます。
  - 作る物：水面・滝の板・滝の上の小川・着水の飛沫・波紋。生成物は `Assets/MapWaterGenerated/` に入ります。
  - 作らない場合（`waterSim` が無い・壊れている等）：理由を「MapWater: 水は作りません — …」の1行でログに出し、何も増やしません。
  - `MapWaterBuilderChecks.Run`：壊れた入力 9 通りで、何も作らないことを確かめる試験です。
- 描画：
  - 深度テクスチャ・不透明テクスチャを使いません（スマホの画質設定でも同じ絵になります）。屈折のゆがみはありません。
  - 波紋：滝ごとに 128² の窓を1枚のアトラスにまとめた compute で計算します。1/60 秒の固定刻みなので、同じ時刻は同じ絵になります。
  - 時刻は MaterialPropertyBlock で渡すので、材質の資産は書き換えません。

## 確認結果

- `node tests/water_unit.js`：17 件合格。
- `node tests/water_export.js <元のエディターの写し>`：全合格。
  - 書き出しの中身を検査しました。
  - ブラウザと node の再現性（バイト一致）を確かめました。
  - 元のエディターと比べて、既存ファイルは変わっていません。
  - 海・溶岩・遺跡の場面では、水を作らない（`available=false`）ことを確かめました。
- `node tests/water_perf.js`：128m・川ありの部屋で、画面の水の計算は 0.74 秒でした。
- Unity：試験用プロジェクトで 9 回撮影し、毎回、撮影の前に決めた数（水の外の画素が変わらない・描画の費用・継ぎ目・流れの向きと速さ・決定性・滝の透け具合など）で確かめました。見た目は、作った人とは別の担当が判定しました。
  - 池：外へ広がる弱い波紋が合格。
  - 川の泡の小片：小さな三角形に見える所が残ります（今の形で確定）。

## 未対応

- 水に入る物（橋の脚・岩・キャラクター）のまわりの泡。
- 屈折のゆがみ、水への映り込み。
- 海の波打ち際、溶岩の面。
- 入口が2か所以上ある川の分流（入口は水底の最も高い端1か所）。
- 細波の模様の向きは、まだ流れに沿い切っていません（流れに対して約 80 度）。
