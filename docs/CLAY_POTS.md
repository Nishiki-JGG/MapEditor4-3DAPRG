# Unglazed storage and broken pots

The storage pot and broken pot were selected after comparing actual pixels. Their former angular shoulders, flat lip and thin-looking fracture read as simple polygon vessels. The revised storage pot has a rolled lip, a continuous shoulder/body curve, hollow interior and small foot. The broken pot has a solid 26-30mm fracture section, uneven fracture heights with a few secondary chips, and a continuous interior/floor. The three existing scattered shards and their placement envelope remain. No handles, gameplay or decorative luxury glaze were added.

Stable IDs, names, asset keys, size metadata, scale ranges, ground offset, tags and placement remain unchanged. The storage pot keeps its radius 0.29m and height 0.73m cylindrical Collider. The broken pot remains nonblocking (radius zero), with height 0.42m. The new visual radius remains within the existing proxy and the old shard envelope. Triangle counts change from 640 to 1,776 and from 260 to 564.

Unglazed clay uses an opaque 128x128 cell in previously unused pixels of the existing 1024x512 shared atlas. It contains restrained firing variation, sparse pores and very faint turning traces, multiplied by spatially coherent clay vertex colour. Inner walls and exposed sections differ subtly. Existing atlas pixels outside [832,256,128,128] are byte-identical; texture allocation and light count do not grow. The two pot types share one additional cached clay material; each placement still has one renderer and one material. The compressed shared PNG grows by 25,002 bytes. This uses the existing diffuse-only material; there is no new PBR roughness/normal channel, glossy glaze, illumination change or baked directional highlight.

The first Unity trial exposed an exporter mismatch: core cards2 objects forced face normals even though Web used smooth normals. The export now retains supplied normals for storagepot and brokenpot only. All other exported assets remain exact. Existing schema is unchanged; the baseline Reader successfully imports both revised pots, with the existing cards2 atlas contract. The current importer additionally opts the two pot types into the already existing URP light shadow bias, using a dedicated shared clay material key. This reduces near-camera self-shadow striping without altering global lighting or shadow settings. Old Readers remain functional but retain their old shadow-bias behavior. The atlas change updates shared export content hashes normally.

Web save/reload, finite geometry, unchanged Collider metadata, every unrelated asset payload and all previous atlas pixels passed. Unity 6000.5.9f1 / URP17.5 generated 43 Prefabs and two placements; the storage Collider vertices/indices match, the broken pot still has no Collider, and all 41 unrelated meshes reuse identical cache objects. Pots and barrel share the same atlas object. Close/opposite-light pixels and the existing grassland generator seed 71421 with normal camera were reviewed. Original game scenes were not saved. Player, full gameplay sessions and Native GPU timing were not executed.

Treasure chests, barrel, crates, grave markers, shoreline props, classification, fixed rock samples and water work are preserved.
