# 真上の植物品質改善

`d289a6b` を基準に、既存69種類と保存配置を維持した美術改善。新種は追加しない。[一覧](../tests/plant_set_view.html) は真上90度を初期表示とし、同じ共有形状・画像をブラウザとUnityで使用する。

## 目視で見つかった問題と変更

- 草：根元から均等に広がる葉が、群生すると同じ星形に見えた。11枚の細い葉の根元をずらし、方向・曲がり・到達距離を不均等にした。同じ論理頂点の法線を生成時に平均し、折り目が黒い直線板に見えるのを抑えた。葦・花の足元に共用する草も同様。縦十字カードは使わない。
- スゲ：三方向の扇が揃っていた。株元・開き角・葉の長短・曲率・ねじれを不均等にした。
- つる性の茂み：葉が枝の実際の高さとずれていた。枝の折れ線上で葉の付け根を求め、枝そのものの角度・長さ・株元もずらした。
- 地這いツタ：同じ葉輪郭が三方向に並び、枝と葉柄の位置も揃っていなかった。葉柄を枝上に接続し、小葉の左右幅・傾き・葉形を少しずつ変えた。最低点はY=0のまま、葉を地面近くへ下げた。
- 広葉ロゼット・鈴花：共通の曲げ葉を非対称な中心線とねじれにし、同じ放射状の輪郭を弱めた。鈴花の花穂・ベル、ロゼットの種穂は保全した。
- 柳：長く平行な葉模様が束全体を扇状に見せていた。画像内の小葉を短くし、向きの幅を広げた。樹形・幹・枝・枝下高さは元の形状をそのまま維持する。白樺・傘形松・株立ち低木・トクサも形状を保全した。

変化は生成時の固定seedで決まる。毎フレームの頂点更新や新しい材質分岐は追加しない。各配置の差には、既存の回転・縮尺を使用する。同じ向き・同じ縮尺で連置した場合は同じ形になるため、無制限の個体差を導入したものではない。

共有19資産全体で4,640→4,640三角形。頂点配列長・インデックス数、予約インスタンス配列、材質数、画像数は据え置き。草は約0.615→0.605 m、茂み0.820→0.815 m、ツタ0.120→0.062 m、スゲ0.924→0.978 mとなり、カタログ高さも追従させた。保存済みの位置・回転・縮尺は変更しない。

共用512×512画像のPNGは254,277→258,248 B（+3,971 B、約1.56%）。小葉の向きのばらつきで圧縮後容量が少し増えるが、RGBA8＋全mipの画像領域1,398,100 Bは変わらない。変更ピクセルは柳のセル内だけで、他のセルと従来4画像は完全に保全。sRGB・trilinear・mipmap・異方性2・alpha cutoff・両面設定も保全。

葉の幅と重なりが変わるため、三角形数が同じでも画素処理の負荷が同じとは限らない。真上の投影重なりを同じ格子で前後比較したが、これは最近傍alpha・mipなし・深度判定前のCPU推定であり、GPU時間やスマホ性能の測定ではない。

草の投影積層面積は約0.212→0.161 m²（約−24%）、平均重なりは前後とも約1.23層、95%点は2→3層。茂みの積層面積は約+2.3%、葦−3.1%、花−10.2%。柳・ツタ・スゲ・鈴花・ロゼットでも積層面積は減少したが、スゲ・ロゼットなどの局所的な平均重なりは増えている。これらから実機の速度向上・低下を断定しない。

根元Y=0、各樹木の1.8 m人型に対する枝下余裕、幹の当たり判定は保全。草・葦・花の風と接触押し分け、影も保持する。新10種の静止仕様は継続。既存の岩・シダ・針葉樹・倒木・切株・根、主人公、水、地形機能、ライセンス、公開範囲、Pages設定は変更しない。

## 検証

- ユーザーPCの使い捨てChromeで真上一覧・各単体・斜め・近景・遠景を比較。群生は固定seed 19271・同じ134配置・同じカメラ・同じ照明。真上のカメラ方向も数値確認した。画像はリポジトリ外の検証資料へ保存。
- ブラウザ95検査：69 IDと順序、旧配置、保全対象と材質、接触押し分けと影、分類・選択・配置・削除・回転・非一様縮尺・保存再読込、Unity用共有出力とCSV丸め。
- 元ZIPの48 m/384配置と64 m/1,025配置を保存再読込し、全配置・マーカー・橋・階段を照合。元ファイルは変更しない。
- 全19形状の数値・法線・UV・非退化三角形・Y=0・全三角形数と画像領域を検査。旧岩の反復UVはクランプUVと区別して保全。
- 隔離したUnity6000.5.9f1 / URP17.5で128検査：19資産・10配置・旧9資産出力の互換性、全配列・PNG・材質、描画とシェーダー、静止10種のGPU頂点、草・葦・花のGPU風と固定根元。

スマホの実機FPS・GPU時間・発熱、Android/iOSビルド、Built-in描画、ゲーム本体統合は未検証。遠景で画素以下になる葉先のちらつきを完全になくすものではない。急斜面への追従や自由な縮尺での枝下保証は、従来の制約のまま。

再生成は `node tools/plants/bake_new.cjs` の後に `node tools/plants/bake_grass.cjs`。検査は `node tests/plant_polish_validation.cjs`、`python tests/plant_polish_source.py`、`python tests/plant_polish_overlap.py`。比較は `node tests/plant_polish_compare.cjs <比較対象checkout> <before|after>`。全出力は今回用のリポジトリ外フォルダーへ保存する。
