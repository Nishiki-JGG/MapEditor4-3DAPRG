# 木製支保枠 195–196（ローカル候補）

既存の坑道生成には柱と梁がある一方、独立配置できる支保枠はなかったため、手作りの坑道・洞窟分岐に使う基本品を追加した。自動坑道の置換や構造計算用部材ではない。既存 `tunnels.js` の柱・梁・筋交いを構造参考にした創作規格であり、歴史的な特定工法の再現ではない。外部通信制限中のため新しい資料取得はしていない。

## 製品範囲

- ID `mine_timber_frame`、表示名「坑道の木製支保枠」。寸法約幅2.58 × 高さ2.86 × 奥行0.34m、柱間の木材内寸1.98m、梁下2.55m。
- 2本の柱、上梁、2本の短い筋交い、細い鉄帯と留め頭。364三角形。固定岩・既存レール・トロッコ・坑道生成は不変更。
- レールの木材／木口／鉄atlasと材質を参照共有。追加texture・material・lightは0。材質テクスチャを書き換えていない。
- Webのプレビュー、坑道床への配置、通常サイズ・角度操作、保存ID対応を追加。レールドラッグ部品にはしない。ランダムサイズは適用しない。
- 任意拡張 `mineTimberV1` を追加。別ファイル参照の共有libraryでも保持する。既存の厳密な小物ID配列は変更しない。不正拡張は警告して新規品だけ省略。検証済み `mineRailsV1` の材質が無い場合も新規品だけ省略。
- Unity標準URP/Lit、法線／UV／接線を正式Importerで生成。柱2本の円柱proxyを1つのMeshCollider内の2島に結合し、中央通路を塞がない。半径・高さ・中心のcustomとnon-solidに対応。

## 検証

- Web正式export、保存復元、Map/Setの実内容を正規化したCollider比較。9/225配置で材質共有・GLエラー0。headlessによる実クリック、プレビューと確定、地下床、回転・縮小・拡大時の2柱proxyを確認。
- レールドラッグ：直線・左右曲線・4曲線ループ・既存端点・不可能な接続拒否・保存復元・一筆Undo・取消7条件・通常小物非干渉を再実行してpass。
- Unity6000.5.9f1 / URP17.5 / Linear / Forward+、専用Editor batchmode・オフスクリーン描画。対象4Prefab（レール3＋支保枠）を正式生成。Prefab保存後破棄・再instantiate、Scene再読込、実MeshCollider、材質参照共有を検証。
- 混在正式生成は旧54＋新1の55Prefab、25配置、skip0。旧54の実Collider数／内容を比較し、非衝突物は0であることを別に確認。75カタログ全種の再生成ではない。
- 混在fixtureは完了済み187の配置を保ち、190クモ巣・192トロッコ・195支保枠の正式payloadを合成した共有library。新規品のWeb exportは別途実行済み。巨大library・画像はローカル証拠のみでrepoへ同梱しない。
- 欠落／未知version／非有限頂点／不正index／レールatlas欠落、custom半径高さ中心、non-solidで表示だけ残る経路を検証。旧Readerは任意フィールドを無視するソース契約確認まで。旧バイナリは未実行。
- Unity9配置は9可視、225配置は195可視。mesh/material各1、texture3共有、meshメモリ163,200B。全225が描画された負荷試験ではなく、GPU・スマホ・Player性能は未測定。
- 実坑道 `Input123Mine`（幅2.4m、高さ2.8m）、通常距離／近景／裏方向。196で梁全体が入る画角を追加し、既存壁掛け灯1個を専用コピーへ追加する条件も確認。露出や製品照明は変更せず、原本・ユーザー画面は操作していない。

## 試験の訂正と限界

初回テストのCapsuleCollider仮定は実際のMeshColliderへ修正。9配置の計測配置誤りを訂正。混在テスト初回は非衝突物にも空を許さないCollider比較を適用して失敗したため、実Collider数を先に検証する形へ修正し再実行成功。古い `error.txt` は失敗証拠として残し、最終 `checks.json` 成功と区別する。

木目は共有atlasのため均一さが残り、暗い坑道で素材評価は限定的。平床に手動配置する品で、地面追従や自動支柱間隔合わせはない。柱proxyは保守的な円柱で梁上端まで届くが、頭上梁自体の精密衝突はない。実構造の耐力は保証しない。

## 導入と公開状態

ローカルレビュー用。新旧Importerのソースを一式更新し、この版からexportして別出力先へimportする。新規optionalに加えレールatlasデータが必要。既存Prefabは自動変更しない。

直前のトロッコ193は通常push成功済みだが、Pages/API確認はHTTP前のローカルTLS設定アクセス拒否で保留。この支保枠では外部push・API・配信確認を一切行っていない。拒否の再試行や別経路回避はしない。公開cache/release同期は未実施。
