# 岩盤床の公開後レビューと未公開の品質改善

## 公開済みの版

公開コミットは `5e7b486eecbbc0b38bf53d3cee99333707cc0cc4`。Pages 実行 [40121403212](https://github.com/Nishiki-JGG/MapEditor4-3DAPRG/actions/runs/40121403212) は同じコミットで成功した。[公開アプリ](https://nishiki-jgg.github.io/MapEditor4-3DAPRG/)で画像を含むアセットのバイト一致、岩盤のブラシ・全体塗り、保存ボタンによる JSON とファイル選択による復元、森・遺跡のバンドル読込と TAB を確認した。照合キーとプロファイルは一致し、岩の再生成は0回。記録は `bedrock/publication-5e7b486.json`。

以下の品質改善はこの公開版を基準にしたローカル変更であり、まだ公開していない。

## 率直な所見と採用した修正

1. **広い面の斜めの帯が規則的だった。** 半タイルずらし4枚の同じ向きの合成では、継ぎ目を消せても元画像の流れが短い周期で繰り返された。元画像の内側から、位置と緩やかな回転を変えた4パッチを連続補間する方式に変更した。元画像の端は参照しない。90度回転の試作は織物のような直交模様になったため不採用とした。
2. **床の細かい写真風の粒が、既存の岩の大きな面と競合していた。** 独自生成した元画像に弱い低域処理を混ぜ、彩度と明度を少し抑えた。シェーダーでも細部のコントラストを控えめにした。狭い割れ目と白い鉱物脈は残している。既存の岩パーツ・岩壁の色、テクスチャ、形状には変更を加えていない。
3. **回転パッチの初期案に1ピクセル程度のミップ境界が出た。** WebGL 2ではワールド座標から連続した微分を渡し、格子の境界で不適切な縮小画像を選ばないよう修正した。微分の参照幅も少し広げて細部のちらつきを抑えた。

真上・斜め・近距離・48mの広域・緩斜面・土と草の境界の6視点で、地形、塗り、岩の配置、照明、カメラを固定して再描画した。岩の配置と床の高さのハッシュも同一である。広域の整列した帯は弱まり、近距離の粒度差も小さくなった。草・土との塗り境界に新しい段差や硬い直線の継ぎ目、岩の足元の浮きは確認していない。

床は連続した露出岩盤、パーツは角張った割れ岩であり、近距離では作風の差がまだ残る。白脈は基準画像の特徴として残しているため、完全に無方向な砂状の面にはしていない。画像の実見による判断であり、テスト通過を美術品質の承認とは扱っていない。

## 予算と制約

512×512のRGBA画像1枚を継続使用する。PNGは805,659から679,141バイトへ減少した。RGBA8と全ミップは1,398,100バイト（約1.33MiB）、デコード後のCPU画像は約1MiB。色と浅い凹凸を同じ画像に格納し、追加画像はない。描画1画素当たりの画像参照は4回。旧方式の連続ノイズ2回を除き、固定数のハッシュと小角度回転、補間に置き換えた。追加の形状や描画パスはない。

比較シーンは両版とも描画11回・三角形94,693・GPU画像18枚。12回の小さなカメラ移動で同じ床上の8点を追い、各3×3画素の平均RGBの最大変動幅は旧版6.0、新版2.34以下（0〜255）。これは限定した視点での安定性の参考値で、動画全体や実機のちらつきの保証ではない。

**岩盤専用シェーダーの最初の描画待ちは残る。** 同じ岩パーツを草の床で先に描画して準備し、その後に岩盤を有効にした描画からGPU完了までを測った。新規Chromeプロファイルで旧版4.48秒、新版5.35秒だった。シェーダーのコンパイル、リンク、画像アップロード等を含み、内訳を分離した数値ではない。通常描画の時間とは区別する。初回の短いブラシ操作はこの待ちの影響を受ける。サンプル読込時には岩盤のシェーダーや画像を追加で使用しない。

初期化後の比較シーンの25回描画は旧版の中央値5.1ms、新版2.4ms、新版95パーセンタイル3.4msだった。別の24mの床だけの場面では草2.9ms、岩盤3.2msで、両方とも描画3回・三角形9,600個。ドライバーと実行順、外部負荷の影響があるため、旧版より高速になる保証とは扱わない。

実測時間はPCの負荷とドライバーのキャッシュで変動する。スマートフォンの実機は未検証。WebGL 1では明示的な微分が使えない場合の通常サンプリングへの分岐を持ち、その経路の見た目は別途検証が必要。Unity側のゲームプロジェクトやシェーダーは変更していない。

## 検証とサンプル保全

`tests/bedrock-quality.cjs` は6視点の比較画像、同一シーンの照合、描画負荷、カメラ移動時の参考値を記録する。`output/playwright/bedrock-quality/` に元のPNGと `review.json` を保存する。

公開後に別作業の `4973cac25d71b2abdd193b75edd33f12aa62ea82` がmainへ追加されたため、未公開の改善だけをその上に載せ直した。競合はindexの読込行で、共有資産のスクリプト追加と両方の版番号を保持した。Unityを含む後続mainの変更はそのまま保持し、今回の差分からUnity・岩パーツ・海・泉の変更はない。

`4973cac` はindexの変更後も古いサンプルキーを保持しており、森・遺跡とも実行時のキーと不一致だった。これは生成を禁止した平地ページでキーを計算して確認したもので、公開サイトで再生成させた実測ではない。証拠は `bedrock/prepared-key-audit-v2.json`。

統合後は `tools/repack-bedrock-samples.cjs 4973cac` で完成データを再梱包した。既に10チャンネルの完成品にも対応させた。キーとソース照合情報以外の地形・配置・衝突・歩行データはデコード後の完全一致を検証する。岩の形状生成は実行しない。

統合版の実UI検証では、森・遺跡の初回はバンドル、再読込はキャッシュ、全ケースで岩の再生成0回。キーとプロファイルは一致し、歩行データを再利用した。マップ・岩の形状・配置のハッシュは公開版 `5e7b486` と一致。TABの応答は森227ms、遺跡80ms、キャッシュ後は95ms／86msで、再生成はない。`bedrock/prepared-comparison-quality-v2.json` に記録した。書き出し・マウス／タッチを再検証し、後続mainの部屋ZIPの実UIテストと共通資産の単体テストも通過した。

床の塗装・全体塗り・消去・取り消し／やり直し・JSON復元・材質切替後の描画一致は `bedrock/quality-paint.json`、`quality-input.json`、`quality-material-switch.json`。既存の草・土・荒地は通知を除く比較領域でRGB差分0。崖の肩・凹凸、石畳マスク、表面塗装、泉の単体テストも通過した。

6視点の比較は [比較画像](bedrock/quality-comparison.jpg)。元のPNGはローカル出力に保存し、比較画像のコピーをLibraryへ保存した。見た目と負荷の数値は `bedrock/quality-comparison-v2.json`。

従来の海HLSL同期テストのCRLF差分は、この改善では変更していない。基準コミットとの証拠は `bedrock/sea-line-endings.json` にある。
