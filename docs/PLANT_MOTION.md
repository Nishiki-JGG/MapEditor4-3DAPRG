# 追加植物の風・接触揺れ

追記：以下は `6bf963c` 時点の仕様と検証記録。現在は[本体の強風応答と鈴花の可視性](PLANT_GALE.md)を改善し、風の振幅・応答・低い葉のマスクを更新している。

追加10種に、共有頂点マスクを使う水平のGPU変形を実装した。形状・三角形・画像・材質数・69種のIDと保存形式は変更していない。[一覧プレビュー](../tests/plant_set_view.html) は初回から風が有効。「接触テスト」で1.8 m人型が横切り、「風」を切れば接触だけを確認できる。

エディタ本体の風は既存の天候設定に従う。「なし」では静止するため、「そよ風」などを選んで確認する。接触は天候によらず、歩くモードの人物の現在位置・移動方向・足元高さを使う。

## 対象と最大水平変位

数値は標準縮尺・風の強さ1の上限。風と接触は加算される。全体を水平移動するのでなく、固定点0から先端1の重みで変形する。

木3種の標準枝下は2.570 / 2.509 / 2.631 m。1.8 m人型には届かないため、標準サイズの高い樹冠は接触で曲がらない。小さく縮めて葉が人物の高さに入った場合は接触可能。Y変位は常に0なので、揺れで枝下高さが下がることはない。低い植物は根元約3.5 cmを固定。ツタは高さによらずつるを固定する別マスクを使う。

## 共有実装

`props/shared/assets.js` の `shared-plants/3` に風・接触用の2成分マスク、振幅、接触半径・高さを追加した。元の頂点・法線・色・UV・三角形と5枚のPNGは `6fb6c07` と完全一致する。既存9共有資産のデータも完全一致する。ブラウザは既存の針葉樹GPU風シェーダーと接触経路を拡張し、UnityはUV2に同じマスクを渡す。位置と種類で位相をずらし、株が一斉に揺れないようにした。CPUで毎フレーム全頂点を書き換えない。前方描画と影に同じ変形を使う。

接触は4 mセルで候補を絞り、到達できる高さだけを判定する。押し分けは人物から外向きの力と移動方向の引きずりを合成する。ばね係数70・減衰8、最大1/120秒の小刻み積分、1回の経過時間は最大.1秒。変位を種類別上限（ブラウザでは全体上限.3 m）で抑え、離脱後は振幅.5 mm・速度3 mm/s未満で正確な0に戻す。移動速度20 m/s超は瞬間移動として方向の引きずりに使わない。保存座標・元頂点は変えない。

## Unity隔離プレビューへの受け渡し

同梱 `unity/Assets/MapSharedProps` を更新してから新しい書き出しを取り込む。旧 `shared-plants/2` 以下も読み込めるが、新しい `/3` は今回のインポーターが必要。

取り込みルートには `SharedPlantContact` が付き、対象10種を登録する。人物の**足元**のGameObjectに `SharedPlantContactSource`（半径.3 m・身長1.8 m）を付け、ルートの `source` に明示的に割り当てる。既存ゲームの人物やコントローラーは自動で変更しない。風は既存 `SharedPineWind` が担当する。

植物の配置や縮尺を実行中に変更したら `SharedPlantContact.Refresh()` で空間インデックスと可視範囲を再計算する。人物の移動には再計算不要。接触中だけRendererの `_PlantTouch` をMaterialPropertyBlockで更新し、静止復帰・無効化で元のブロックを戻す。他の処理も同じRendererのブロックを書き換える場合は所有・合成の調整が必要。ゲーム本体への組み込みは行っていない。

## 検証と負荷

- ユーザーPC上のChrome（使い捨てプロファイル、SwiftShader）で96項目：登録・選択・配置・削除・回転・縦縮尺・保存読込・旧ID・共有書き出し。既存サンプル2マップも配置・マーカー・橋・階段を保って再保存読込した。
- 10種すべてで実GPU変形を読み戻し、根元固定、風なし・接触なしでの静止一致、時間差の風、配置による位相差、回転・縮尺を確認。ブラウザとUnityのGPU座標差は最大約1.1 µm、根元差は最大約.24 µm。
- 本体の歩くモードで左右からの通過、20秒の連続接触、離脱6秒後の完全静止、高い枝の接触除外、縮小した木の接触、頭上に配置した草の除外、影用材質とカリング設定、保存座標・頂点バッファが変わらないことを確認。
- 一覧10種は風なしの時間差画像が完全一致、風あり画像が変化。真上の柳・スゲ・ツタおよび歩くモードの接触／復帰画像を確認した。
- Unity6000.5.9f1 / URP17.5の隔離環境で83項目：19共有資産・10配置、UV2、実GPU変形、接触・連続接触・減衰・可視範囲、旧19資産書き出し互換、実URP描画と影パスのシェーダーコンパイル。接触源はEditor内で時間を進めて検査した。ゲーム本体のPlayモード統合は未実施。

三角形は追加10種合計2,838、共有19種合計4,640で増加なし。各種1材質、共有画像512×512・258,248バイトも変更なし。追加の頂点重みは計68,112バイト。ブラウザの既存最大8,000個/種に合わせた接触属性は10種合計960,000バイトで、CPU配列とGPUバッファにそれぞれ必要。活動中の種は最大96,000バイト/種の属性更新になり得る。共有データJSは未圧縮3,584,779→3,758,180バイト（+173,401）。画像増加はない。
