# Readable coiled-rope strands

Actual sack, haystack and coiled-rope images were compared. The rope's broad smooth bands read like a hose, so only coiledrope was selected. The sack and haystack are retained. The same 2.8-turn coil, tail, nominal 40mm diameter, flattened section, ID, purpose, scale range, ground offset, nonblocking radius 0 and height metadata 0.065m remain. More evenly sampled curves and an eight-sided section reduce angular corners. Count rises from 520 to 1,216 triangles; there are no separate strand meshes.

The existing arc/section UV and derivative-filtered fibre shader now darken narrow strand valleys instead of weakly modulating the whole section. Normal relief increases modestly. The Web and URP formulas agree; the built-in fallback receives the same colour groove. This is stylized procedural strand detail, not a photographic fibre texture or individually modelled fibres. The cloth branch is byte-identical after the two rope-specific substitutions, and cloth/rope material kinds remain separate. No image texture, material instance per placed object, light, new schema or save field is added.

Web save/reload, finite geometry/UV, Collider output, grounding identity/placement, every non-rope export asset, shared atlas PNG and complete fire payload passed. The baseline Reader source is unchanged and actually generates 43 Prefabs from both exports. The grounded rope's saved UVs equal the prototype UVs; all 42 unrelated cached meshes are identical, and the rope remains nonblocking without lights. An initial test incorrectly expected Unity's unused map slot to retain the built-in white texture; Unity serializes it as null. The assertion was corrected to accept either null or the built-in white texture, and all checks passed without allocating an image.

Unity 6000.5.9f1 / URP17.5 comparisons use the original baseline shader under a separate review-only name for before images, avoiding a false comparison where both versions use the new shader. Close, opposite-light and existing generated grassland seed 71421 normal-distance images were reviewed. The clearer twist and softer polygon corners justify adoption close up; normal-distance improvement remains restrained and does not rely on making the prop larger or brighter. Original game scenes, water, chests, mining tools and previous improvements are unchanged. Player, full gameplay and Native GPU timing were not executed. Screenshots are local only.
