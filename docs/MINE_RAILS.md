# 坑道レール基本セット（レビュー候補122）

未公開の候補。独立レビュー前に合格・公開済みとは扱わない。直線・90度曲線・終端を一つの接続セットとして追加した。トロッコ本体は未制作。

## 寸法と用途

既存 `tunnels.js` の標準坑道（幅2.4m・高さ2.8m）、入口付近の既存レール中心±0.42m、枕木幅1.24mに合わせた創作規格。歴史的な軌間の標準を主張しない。

| 項目 | 仕様 |
|---|---|
| ID | `mine_rail_straight` / `mine_rail_curve` / `mine_rail_end` |
| 単位・原点 | m、Y上。入口の線路中心・床面が共通pivot |
| 直線 / 終端 | 長さ2m |
| 曲線 | 90度、線路中心線半径2m |
| レール中心間隔 | 0.84m。頭幅0.05mなので内側の隙間は0.79m |
| 走行面 | pivotから+0.14m |
| 枕木 | 幅1.24m、厚さ0.07m。木口・小さな面取り・留め具あり |
| 三角形 | 直線456、曲線1524、終端556 |

Webの入口端点は `(0,0,0)`、外向き接線 `(0,0,-1)`。直線の出口は `(0,0,2)` / `(0,0,1)`、曲線は `(2,0,2)` / `(1,0,0)`。終端の接続端は入口だけ。Unity exportでは位置・方向のZを反転する。端点は `mineRailsV1.assets[].ends` に保存する。

将来のトロッコ用検査ゲージは車輪中心±0.42m、車体幅1.0m・長さ1.4m・高さ1.1m。走行面は0.14m。曲線での車体外側の張り出しは約0.596m。寸法確認のみで、車両の運動・車輪・連結機構を実装したものではない。

構造参考は鋼レールと木枕木の組合せ（[East Bay Regional Park District、12ページ](https://www.ebparks.org/node/7164)）。[Science Museum Groupの18インチ木製軌道](https://collection.sciencemuseumgroup.org.uk/objects/co208054/section-of-track)は異なる時代の例で、今回の寸法根拠にはしていない。参考写真をテクスチャへ転載していない。

## 配置と互換性

「坑道小物」から「置く」で配置。Ctrl+ホイールとQ/Eの既存操作を使える。同じ等方scale、端点距離0.32m×scale以内、高低差0.06m×scale以内、接線修正15度以内だけ接続を補助する。異なるscaleへ自動変形しない。使用済み端点も再接続しない。枕木幅と中心線を含む途中の地面も確認し、平らでない場所は拒否する。

レールだけはランダム寸法・ランダム回転を使わず、プレビューと確定値を一致させる。坑道内では床を拾い、天井高に配置しない。他の小物・別ツールのpickや操作は維持する。

既定では直線と曲線は通行を妨げない。終端のみ横木・支柱の範囲をWeb footprint / Unity BoxColliderにする。正規カタログの非衝突設定では見た目を残してColliderを省く。直線等へ明示的な円形Colliderを指定した場合は既存の円柱プロキシ生成を再利用する。

新IDは末尾追加。従来の保存ID・本体寸法・Colliderを変更しない。`mineRailsV1` は任意拡張で、欠落・不正なら警告して既存44種を保持する。正常なら47種。共通ライブラリ形式にも格納する。旧Reader自身の旧バイナリは未実行で、未知フィールドを無視して旧配列を処理するソース制御フローを確認した範囲。

## 材質

512×256の共有アトラス3枚。色はsRGB、packedとnormalは線形。packedはR=metallic、G=1（AO予約）、B=0、A=smoothness。WebではG=roughness / B=metalnessへ変換。Unityは標準URP/LitでR/Aを使う。PNGの上下とUVの変換に合わせnormalのGを一度だけ反転し、最終メッシュから接線を作る。

木の長手方向の筋、木口、鉄側面の控えめな錆、磨かれた走行面を分けた。不透明1材質・3meshを共有。個体色を保存されないMaterialPropertyBlockへ置かず、白い共有材質と保存済みmapで色を保持する。既存の別小物の個体色永続化問題は今回の対象外として残る。

## 実行した検証

- Web: 接続17項目、実クリック配置、scale違い、モード・種類切替、途中の段差、坑道床、プレビュー、保存再読込、実Map/Set内容のCollider比較。既存配置操作26項目も通過。
- Editor: 正常・欠落・未知version・不正index・不正PNG・非有限値・非衝突・共通ライブラリ・カスタム円柱の9ケース。既存44Prefabの実mesh/Colliderを比較。正常ケースでは保存Prefabを破棄後に再instantiateし、色と共有参照を確認。
- 表示: Webの通常距離/近景/逆方向/夜。正式Prefabを既存生成洞窟 seed71421（648セル・既存松明21灯）へ配置し、元シーンを保存せず撮影。別途、正式坑道生成・取り込み経路で幅2.4mの確認用坑道を作成し、既存入口レールと重ならない中央区間へ配置。後者は新規の検証用マップであり、既存ゲームの保存済み坑道とは区別する。
- 9/225配置でもUnityは3mesh・1material・3texture。参照mesh約1.08MiB、texture約3.90MiBで不変。1280×720診断グリッドでCPU Camera.Render提出時間中央値は0.5732/0.8537ms。GPU時間・ゲーム全体FPS・スマホ性能を保証する値ではない。
- Player、GUI操作、画像アップロード、固定岩再生成、他担当の水面・氷床変更は実施していない。

## 固定サンプルの既存不一致

基点219f211と本候補は同じruntime preparation keyだったが、配布manifestの旧keyと一致しなかった。レールはmanualOnlyで固定サンプルへ混入しない。完成済みbundleを復号し、key以外の地形・配置・衝突・通行データが完全一致することを確認してキーだけ復旧した。岩再生成0。旧bundleは保全。両固定サンプルのbundle読込・walk再利用を確認した。新bundleのgzip合計は約7.96MiBで、レール素材自身の容量とは分けて扱う。
