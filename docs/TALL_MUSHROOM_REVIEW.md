# 高いキノコの厚み・曲面・UV（cnd014）

既存3本の高さ・分布・外形寸法・pivot・ID・床配置を維持し、紙の円錐状だった傘を、丸い肩・薄い巻込み縁・閉じた下面のある形へ変更。柄は緩く曲げ、最大の柄を5辺、他2本を4辺で表現する。傘・ひだ・淡い柄を分けた自作128pxマップへUVを割り当てた。shader/発光は追加せず、Importerの既存局所光keywordをcnd014の新mapにも適用する1条件を追加。

## 調査と制作

Australian National Botanic Gardens / Australian National Herbariumの[What is a fungus?](https://www.anbg.gov.au/fungi/what-is-fungus.html)を参照。傘の下面にひだがあり、柄がその面を地面から持ち上げる構造を制作の基準とした。特定の実在種の厳密再現ではなく、洞窟内の有機物付近に配置する既存装飾の改善。参考写真・イラストの転載やtexture化はしていない。

220初稿は傘肩と柄が角張り、独立90点で不採用。221では肩の断面を再配分し、最も見える柄だけ周方向の面を追加。221は形状改善が認められたが粒状材質が残り91点で保留。222は均一すぎる茶色になり自己不採用。223は形状を固定して色むら・放射状ひだ・縦繊維を自作128pxへ分離。下面はcolour textureによる疑似ひだで、立体の薄板を大量に重ねていない。

```sh
python tools/build-tall-mushroom.py --output output/mushroom-reproduction/cave-decor-data.js
python tests/tall-mushroom-static.py
node tests/tall-mushroom.cjs
```

生成元は公開43315a98のcnd014を寸法基準にし、現在の他資産を保持して指定先へ出力する。傘と柄はそれぞれ閉じたメッシュで内部接合しており、単一の溶接済みmanifoldではない。

223では傘画像の矩形領域が下面の円へ入り込むP2を独立監査で検出し未採用。224は描画領域をUV使用円＋paddingへ限定。ひだ円内2,289画素の混入195→0、既知texel(80,80)は傘色(174,130,86)→ひだ色(202,179,141)。形状・UVは223から不変。元PNGと失敗証跡を保持。粗いmipではひだの細線は失われるため、遠景の輪郭と明度を主に評価する。

## 軽量性・互換

- 51→254三角形、135→187頂点。20種合計1381→1584三角形。
- 頂点属性44B＋16bit index概算6246→9752B。3本1組を225配置した三角形数11475→57150。増加を隠して従来同負荷とは称さない。
- 旧texture2枚は内容不変。新しい128² mapを1枚追加し計3枚。PNG13,675B、RGBA8＋mip概算87,381B増。対象の9/225配置は同じ1枚を共有。材質・draw対象数の追加0。
- 外形寸法、定義20種、他19種の全データ、既存棚キノコ・垂れ根の成果を保持。固定岩再生成なし。
- 実Map/SetのCollider値、混在20種の保存再読込、サイズ・回転・高さ、共有exportを検証。schemaやID/任意material契約は変更していない。旧Readerバイナリの実行はしていない。

## Unityと限界

専用Unity6000.5.9f1 / URP17.5 / Linear / Forward+で、正式Web export前後20種を別出力先へ生成。Prefab群とSceneの保存再読込でmesh/normal/UV/vertexcolor/transform/material参照/keywordを比較。既存visual-only Collider仕様を維持。既存の製品坑道exportを一度生成し、同じカメラ・照明・支柱で対象Prefabだけ交換して比較する。原ゲームのSceneは変更しない。

CPU Camera.Render短標本と参照共有は検査するが、GPU時間・スマホ・Player・実ゲーム完全セッションは未検証。9/225可視数は証跡の値を参照。近景の輪郭の多角形、ひだの低解像度、傘の色むらの簡略化、暗所での小さな差は限界。高いキノコ3本を1組とする既存サイズを変更していない。

220・221・222・223・224は標準batchmode -quitで正常終了。前回の根217/218の終了時c0000005は原因未確定として記録を残し、今回の正常終了で過去異常の原因解消とはしない。公開ページ確認の既存証明書エラーは別件で、無視や別経路の迂回をしていない。

## Unity更新手順

更新版Webからexportし、現在の公開Importerで別出力先に取り込む。生成された新Prefabを確認して利用する。既存保存Prefab/Sceneは自動置換されない。今回Importerに新しいmapの局所光keyword条件があるため、更新したImporterも必要。ガラス206、他担当領域、ゲーム原本には変更を加えていない。
