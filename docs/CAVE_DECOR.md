# 自作の洞窟装飾20種

「置く」→「洞窟装飾（自作20種）」から選べます。パレットは「全て」、または洞窟・森林・ジャングル・沼地を選択してください。

| ID | 素材 |
|---|---|
| cnd001–004 | 広葉シダ、高い細葉シダ、岩隙シダ、壁面シダ |
| cnd005–007 | 苔の房、縁苔、垂れ苔 |
| cnd008–010 | 短い垂れ根、長い絡み根、地表根 |
| cnd011–012 | 壁ツタ、垂れツタ |
| cnd013–015 | 小キノコ、高いキノコ、棚キノコ |
| cnd016–020 | 湿地草、入口の下草、落葉、枯れ枝、朽ちた倒木 |

既にあるシダ・苔岩・茂みなどとは別の、制作済みの原モデルを追加しています。市販素材、購入素材、背景見本、購入品を使った部屋は含みません。原ファイルのSHA-256は [出典一覧](CAVE_DECOR_PROVENANCE.json) にあります。

## 配置

- 標準倍率1で元のメートル寸法を維持。大きさ・回転は既存の操作です。
- この20種を選ぶと「地面からの高さ」が出ます。0では素材の最下点が地面に接し、値を上げるとその分だけ上へ配置します。元の壁・吊り物の支点は変えず、配置位置で合わせます。
- 壁付け、縁、吊り物、棚キノコは「置く」で向きと高さを合わせます。壁へ自動吸着する機能ではありません。地面へ誤散布されないよう「小物を撒く」の候補からは除いています。
- 床用12種は散布できます。朽ちた倒木には当たり判定を付け、低い装飾は通り抜けられます。
- 床のシダ3種、湿地草、入口の下草は既存の風・接触方式へ接続。壁・吊り物、根、苔、キノコ、枯れ枝、倒木は静的です。

## 保存・Unity書き出し

種類IDは既存リストの末尾へ追加し、既存マップの種類順を変えません。高さ・向き・拡縮は既存の配置形式で保存されます。

既存の `shared_props.json` と `asset_bindings.json` の経路で20種を出力します。共通素材の保存では部屋ごとに素材を同梱せず、共有ファイルへまとめます。全20種で1,123三角形、元の512×512カラー画像1枚を共有。追加データは約0.61MB（圧縮前）です。

表示は既存の拡散照明材質を使用し、形・カラー画像・UV・両面・抜き閾値0.5を引き継ぎます。原本のNormal/ORM画像はこの材質では使用しません。原本のPBRレンダーと完全に同じ陰影ではありません。
