# 真上から見る草の修正

最新mainの59種類を基点に、既存ID `grass`、`reed`、`flowers` を維持して修正した。新種の追加に先立つバッチ。

`grass` は縦の十字カード3組、`reed` は根元の十字草カード2組、`flowers` は根元のロゼットカード3組を持っていた。真上では板の端が直線/Xに見え、裏側の暗い面と影も目立っていた。影だけの問題ではない。

草むらを11枚の独立した曲げ葉へ置き換えた。各葉は3節と小さい折り目、狭い付け根、先細りの先端を持つ。株元をずらし、向き・高さ・幅・先端の垂れを非均等にする。葉の面が真上に投影される面積割合は約54%。透過板は使わず、輪郭は実形状で作る。葦と花の根元も同じ方式の7枚葉へ交換した。葦の元レシピに含まれた潰れた先端4三角形は除去。

| ID | 三角形 旧→新 | 高さ m | 材質 |
|---|---:|---:|---:|
| grass | 12→110 | .615 | 1、不透明・両面 |
| reed | 404→462 | 1.790 | 1、不透明・両面 |
| flowers | 76→134 | .437 | 1、花弁のみalpha .42、両面 |

三角形数は増えるが、縦板を大量に重ねる方式ではない。草/葦の透明な矩形領域とその重なりは除去した。スマホのFPSやGPU時間は未測定で、高速化したとは主張しない。遠景にも葉面が残るが、極端に遠い距離では細い葉は画素より小さくなり得る。

共有形式は `shared-plants/1`、schemaVersion=1。従来6資産の形・PNGを保ち、草/葦/花を加えた9資産。既存59 ID順・塗り・配置・保存形式・CSV列は維持。元のゲーム、水、地面、主人公、最新の木材・岩改善は変更しない。

草と花は512×256 atlasを共有する。上半分は既存コード生成の花画像を必要な4セルだけ切り出し、下半分に数値生成の淡い葉脈と白領域を格納した。PNG95,035 B、RGBA8全ミップ概算699,052 B。sRGB、trilinear mipmaps、異方性2。葦は既存forest atlasの白領域を共有。外部画像/素材/サービスを使わない。生成元は `tools/plants/bake_grass.cjs` とレシピ。

共有GPU風は高さ.06m以下を固定し、最大水平変位は草3.5cm・葦4.5cm・花1.8cm。Y方向の風変位は0。既存の針葉樹はUVによる樹冠マスクを保持し、この3種だけ全UVモードを使う。影も同じ変形で描く。影材質のキャッシュは元材質ごととし、花の透過を草の影へ取り違えない。

ブラウザの既存の接触押し分けも維持する。共有材質のコンパイル処理を接触処理と合成し、風を失わないようにした。接触時の影にも同じ頂点処理を適用する。Unity側は共通の形/画像/材質/風を取り込める。ゲーム側キャラクターとの接触連携は従来同様、ゲーム統合の範囲外。

## 検証

- ユーザーPCのChromeを使い捨てプロファイルで使用。真上90度、斜め俯瞰、単体・19株の群生・遠景を、変更前後24画像で点検。縦の十字板や根元の不透明な四角は除去された。
- 18項目の機能検査：旧59 ID順、旧マップの位置/回転/縮尺、選択、配置、削除、Rキー回転、保存読込、接触、影材質、共有出力、既存6資産保全。
- Unity6000.5.9f1 / URP17.5で53項目：共有9資産の形・法線・色・UV・三角形順・PNG・フィルター、接地、配置、GPU風と固定根元、描画、シェーダーコンパイル。GPUと数式期待値の差は最大約.00000034m。
- 両環境の無風と静止基準を比較。草/葦とUnity花は画素一致。ブラウザ花はalpha境界1画素の差が残る。風の2時刻と影も撮影した。
- 全共有メッシュに非数値・退化三角形なし。草/葦のalpha矩形なし、花は花弁の透過のみ。スマホ実機、Builtin実描画、ゲーム本体への組み込みは未検証。

再実行は `node tools/plants/bake_grass.cjs`、`node tests/plant_ground_browser.cjs <旧版checkout>`、`node tests/plant_ground_validation.cjs <旧版checkout>`、`node tests/plant_ground_wind.cjs`。Unityは既存の隔離検査プロジェクトへRuntime/Editorと `tests/unity/PlantGroundChecks.cs` をコピーし、PC指定の実行キュー経由で `PlantGroundChecks.Run -nature-output <証拠フォルダー> -nature-export <ground-export>`。検査画像とログはリポジトリ外に保存する。
