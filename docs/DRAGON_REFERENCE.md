# 参照写真に基づく龍血樹の修正

[龍血樹を真上から確認](../tests/tree_view.html?id=dragontree) / [参照に近い低い視点](../tests/tree_view.html?id=dragontree&view=low) / [本体](../index.html#size=64)

旧版は少数の枝に6個の大きい葉束を載せた形で、ユーザー提供の龍血樹写真2枚との照合が不足していた。両写真をLibraryの正式な転送で取得し、実ピクセルを確認してから、反復分岐が浅く横広い連続天蓋を支える構造へ作り直した。写真と透かしは形状の参照だけに使い、素材・テクスチャや公開ファイルへ転用していない。

## 直した点

- 幹の分岐位置を下げ、3本の主要枝から6・12・24へ分かれる支持構造と中央の3経路を用意。合計48の枝経路を低い視点でも読めるようにした。幹の太さ、灰褐色、法線も整理した。
- 27の軽い葉面パッチを共通の浅いドーム面へ揃え、枝先ごとの大きな穴や小円錐の積み重ねを減らした。各パッチの画像は細い放射葉の小束7個をまとめた自作の共用画像で、巨大な単葉6束から密な小束へ変えた。
- `dragontree` ID、地面原点、6×5.8×6mの外形、配置用設定、材質と既存の風パラメータを維持した。枝下は標準サイズで約2.43m。根・幹は固定し、枝端と葉面のウェイトを接続している。

写真を寸法測量したモデルではなく、既存設置寸法と低ポリ方針の中で特徴を表したもの。実物の全小枝を個別に作る方式にはしていない。

## 負荷

|項目|変更前|変更後|
|---|---:|---:|
|三角形|624|669（+45、約7.2%）|
|共有頂点|1,100|771|
|材質|1|1|
|樹木アトラス|1024×512|同じ|
|アトラスPNG|283,181 bytes|212,077 bytes|

アトラス内の龍血樹用256×128領域だけを変更し、領域外のRGBA画素は完全一致。他48共有資産と他6画像も一致している。全96種・49共有資産・7画像のまま。RGBA8の全ミップを含む樹木アトラスの理論容量は約2.67MiBで変わらない。

本体の岩・倒木との混在配置では真上・斜めとも24描画のままで、三角形が45増えた。冠を埋めた分、葉面の重なりと影の塗り面積は増える。追加の影専用モデルや描画パスはないが、GPUの画素処理時間は未計測。三角形数だけでスマホの性能を保証しない。

## 検証

- ユーザーPCのChromeで、同じカメラ・照明の真上、斜め、写真に近い低い視点を変更前後で比較。本体の岩・倒木・人物との配置でも輪郭・接地・影を確認した。
- 1,433項目のデータ検査で、対象外の資産・アトラス外画素の一致、既存外形、法線、面の向き、非退化三角形、根幹固定、葉面の剛体ウェイトと枝下を確認。
- 全96種のID順序、前版マップの配置・回転・非均一拡縮と保存再読込、龍血樹の選択・配置・削除・共有書き出しを確認した。
- 37共有資産の実WebGL GPU計算が期待位置と一致。龍血樹を本体の無風・そよ風・強風、標準／0.6倍、連続接触と復帰で検査。標準では1.8m人型は高い枝葉に接触しない。0.6倍の接触は0.015m以内で減衰復帰した。CPUの頂点更新は増やしていない。
- 最大の風・接触合成変位を8方向へ与えて面反転なし。辺長比は約0.927〜1.073。変形は厳密な長さ保存ではない。

Unity 6000.5.9f1 / URP / D3D11の隔離環境で、共有49資産・26配置・旧v2〜v6・37資産のGPU位置一致・接触と復帰・影シェーダー・龍血樹の実描画を247項目で確認し、exit 0。公開確認は通常プッシュ後に行う。スマホ実機性能、ゲーム本体統合、Built-in描画は未検証。既知のUnity D3D12終了時クラッシュは未解決。小縮尺の枝下と急斜面接地の制限は維持する（0.8倍の枝下は約1.95m、0.6倍は約1.46m）。

## 再生成と今後の受入条件

`node tools/plants/bake_dragon.cjs` で龍血樹だけを焼き出す。`--check` は資産を書き換えず再現性を確認する。生成元は `tree-canopies.js`、画像パッキングは `pack_dragon_texture.py`。Node、Python/Pillowと既存のChrome/CDP経路を使う。共有資産をブラウザとUnityの両方が読む。

今後の実在樹種も、実際に開いた参照資料を基準に樹冠、枝分かれ、幹との比率を照合し、真上を主基準・資料に合う補助視点で確認する。未確認の資料を根拠に「実物に忠実」としない。比較画像と取得記録はローカル証跡へ保存し、転載条件を確認していない写真を公開リポジトリへ含めない。
