# 保存済み地形の水際補正（表示版2）

水際専用の補正範囲を設け、崖に配置した岩の保護範囲で岸の補正まで無効になる問題を修正した。水までの距離をなめらかにして表示面を調整する。編集用の高さ、塗装、岩の配置、通行判定は変えない。

- 小さな池・細い水路・陸橋を消さないよう、水陸の符号と薄い地形を保護する。
- 補正範囲の端は元の高さへ連続的に戻す。橋・階段・滝・出入口・地図端は保護するため、一部の角は残る。
- 保存済み完成面に `surfaceVersion: 2` を持たせる。旧版は読み込み時に表示面だけ一度更新する。保存後の再読込とUNDOでは同じ更新を繰り返さない。旧版を保存せず閉じた場合、次回は再び更新する。
- 配布サンプル2件は配置と通行データを保持して完成面・照合キーを更新した。通常起動は引き続き平面で、素材は後から読み込む。
- 96mの既存地形は3,101,141→3,141,312バイト（約1.30%増）、64m海岸は1,939,976→1,962,637バイト（約1.17%増）、48m地形は1,478,804→1,478,859バイト。圧縮方式は変更していない。

確認：実Chromeで既存3マップの読み込み・保存・再読込・UNDO、元の高さ/塗装/配置/通行情報の保持、描画エラーなし。独立担当が草原・海岸の比較画像と小水域の保持を確認。完成面・圧縮保存テスト、固定2サンプルの起動/再読込も確認した。

Unityへは更新後の地図を再書き出しする必要がある。地形の表示面と水深生成をそろえて取り込む。既存のUnity部屋や実行ファイルをこのWeb更新だけで更新したことにはならない。
