# 橋下の通行（2026-11-04）

橋の平面範囲に入ると、下の地面を歩いていても橋上の高さを選んでいたため、大きな段差として移動が止まっていました。

歩行中は現在の足元から届く高さの橋だけを足場に選びます。高い橋の下では地面・水深・地形の通行判定を使用し、上の岩などは身体と高さが重ならなければ下の道を塞ぎません。

頭上空間は身体の高さと半径を含めて判定します。橋桁の厚さと橋の曲線、木橋・石橋・直線橋の支柱、桟橋の横断フレームは既存の生成寸法を使った保守的な判定です。表示メッシュそのものとの精密な衝突判定ではありません。橋下で頭が当たる低さや支柱のある場所を、通行可能にする変更ではありません。

`node tests/bridge-underpass-browser.cjs` で、幅3m・長さ20mの吊り橋について実ブラウザで次を確認します。

- 下の地面を前後方向に各8m歩行（足元の高さ0mを維持）。旧版は橋の端で停止。
- 上の道を24m歩行し、橋から対岸まで到達。
- 低い橋・深い水・石橋の支柱・地面の岩で停止。
- 上空の岩は下の道を塞がない。
- 橋の保存配置データは不変。WebGL・JavaScriptエラーなし。

この修正はWebエディタの歩行処理です。Unityの歩行処理と、従来の一層の通行画像・出力足場の仕様は変更していません。保存データや固定サンプルの完成面を作り直す必要はありません。
