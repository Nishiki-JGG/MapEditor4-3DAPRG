骨・石像・石柱の比較

変更前 e0c3b6a と今回のメッシュを、同じカメラ・光・倍率で撮影しています。近接の形と、真上の通常距離での読みやすさを切り替えて確認できます。

骨は人型を想定した頭骨・胸郭などの断片です。石像は特定の歴史人物の復元ではありません。近接では簡略化した面や衣の折りが残っています。

石柱の配置

新しく置く石柱は「折れた石柱・根元」「折れた石柱・先端」を別々に選び、自由に配置・回転できます。旧マップの一体型は、そのまま読み込める互換用IDとして残しています。旧配置を勝手に分割・移動することはありません。
