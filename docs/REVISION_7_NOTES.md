# マップエディター 修正報告（Revision 7）

岩壁の種類を、場所ごとに塗り分けられるようにしました。

- `exporterVersion`：`tdj-map-editor/2026.10.19-r8`（schemaVersion 3 のまま）
- 確認はエディター側（ヘッドレス Chromium）で行いました。Unity 上では未確認です。

## エディター

- 新しいツール「岩壁を塗る」（`.` キー）を追加しました。
  - 種類は 8 つから選べます：マップの既定、標準、土壁、黒い岩壁、濡れた岩壁、苔むした岩壁、砂漠の岩壁、雪山の岩壁。
  - 「マップの既定」で塗った場所は、バイオーム欄の「岩壁」の設定に従います。
- 種類はエディターの頂点ごとに持ちます（0 = マップの既定、1〜7 = 種類）。
  - 地形の崖面は、種類ごとの色・苔・濡れ・雪の値を頂点に持たせているので、境目は 1 マスぶん自然になじみます。
  - 岩・崖石・小石は、置いてある場所の種類で描画します。
- 取り消し・やり直し、保存（map.json の `cliffMap`）、読み込みに対応しています。
- 読み込み時の検査：長さが違う、または 0〜7 以外の値が入っている cliffMap は拒否し、地形は変更しません。

## Unity 向け出力

- `cliff_style.png`：書き出しの頂点ごとの岩壁の種類。R の値が `meta.cliffStyles` の番号です。いちばん近いエディター頂点の値をそのまま使い、補間はしません。
- `meta.cliffStyles`：番号と種類の対応表（色・苔・濡れ・雪の値を含む）。
- `meta.cliffStyle`：マップの既定と、上の画像ファイル名。
- `props.csv` に `cliffStyle` 列を追加しました。岩・崖石・小石だけに値が入ります。

## 確認結果

- ツールで黒い岩壁と雪山の岩壁を塗ると、それぞれ 325 頂点・288 頂点になりました。
- 取り消し・やり直し・保存して読み込み直しで、塗った値が元に戻ることを確認しました。
- 書き出し：
  - `cliff_style.png` は 129×129 で、種類ごとの点の数が塗った数と一致。
  - `props.csv` では、標準 733、雪山 13、黒 8 の岩が該当しました。
  - 検証のエラーは 0 件です。
- 不正な値（9）を入れた cliffMap は、読み込み時に拒否されました。
