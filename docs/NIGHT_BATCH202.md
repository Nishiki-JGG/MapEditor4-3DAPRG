# 洞窟装飾の Unity 局所光対応 202（ローカル確認版）

既存の洞窟装飾20種は、正式Importerで `MapSharedProps/Lit` を生成していたが、既存の追加光計算を選択する `SMALL_PROP_LOCAL_LIGHTS` が付いていなかった。点光源だけの条件では、シダ・キノコ・倒木が黒く描画された。照明や露出を変更せず、この接続だけを修正した。

## 修正範囲

- `MapSharedPropsBuilder.cs` に3行追加。正確な `cnd001`〜`cnd020` のID集合、`cave-decor-atlas-v1`、`MapSharedProps/Lit` がすべて一致するときだけ有効化する。
- シェーダー、Web、書出し形式、形状、UV、法線、頂点色、画像、照明数は変更しない。他の共有資産や一般小物、宝箱、固定岩には適用しない。
- この20種の正式Unity経路は従来から表示用で、Colliderは0。今回追加・削除していない。Web側の既存衝突判定とも区別する。
- 直前の倒木197〜200の造形・樹皮試作は不採用。元の60三角形データへ復元した。本修正を、倒木自体の新造形が91点になった証拠として扱わない。

## 再現と検証

Unity 6000.5.9f1 / URP 17.5 / Linear、専用Editorの背景実行とオフスクリーン描画。元ゲームのシーンやユーザー画面は操作しない。

1. 正式旧Prefab3種（`cnd001 / cnd014 / cnd020`）の複製材質でkeywordだけを切り替え、Forward / Forward+、全消灯・SH・主光・点・遠方・spot・spot範囲外・点影・spot影の計54条件を比較。点・spotの欠落を再現し、接続後の応答・距離減衰・遮蔽を確認した。主光・SH・全消灯・spot範囲外はPNG画素一致。
2. 修正版の正式Importerから20Prefab、20配置を生成。計1123三角形、20材質・共有画像1枚、既存Collider0を保持。旧Prefabとmesh・法線・UV・色・画像参照・材質値を比較し、追加keyword以外が不変。Prefab保存後の再instantiate、Scene再読込でも同じ状態を確認。
3. 同じ実坑道生成データ・カメラ・照明で通常距離／近景／反対側を比較。既存灯によるシダ・キノコ・倒木の表面の読みが改善した。灯火VFXの時刻差は材質効果の根拠にせず、上記固定条件の診断を主証拠とする。
4. シダの同じ非ゼロ風時刻で反対方位を比較し、主光・全消灯は一致。別の診断ではカメラと点光を葉の下へ置き、複製材質の前面をすべてカリングして裏面だけを描画した。旧平均画素値0、修正後約0.04127、明るい画素30,996を確認。診断のカリング設定は製品へ保存しない。
5. 正式共有材質のまま9／225配置。可視9／223、mesh・material・texture各1、meshメモリ14,976B。短いCPU `Camera.Render` 中央値は旧0.517／0.796ms、新0.505／0.760ms。測定ノイズの範囲として扱い、性能向上やGPU性能は保証しない。全225個体が点光範囲内だったという意味でもない。

検証コードは `tests/unity/Cave202*.cs`、小さい集約結果は `tests/evidence/cave-local-light202.json`。既存の `Shared117Review` と `ColliderSnapshot109` を利用する歴史比較ハーネスで、旧入力は変更前の20種正式書出し、新入力は同じデータを使う。比較用の生成先と `Input197-before` は専用検証環境の名前であり、ゲーム側へ作成する必要はない。

## 到達点と制約

独立レビューは限定修正の採用を支持し、確認範囲内で新規P1/P2なし。新モデルの美術採点は行っていない。追加光の頂点モード、GPU時間、スマホ、Player、元ゲームの完全セッションは未検証。旧バイナリを実行した検証ではない。入力形式は不変なので旧Readerの解釈は変更しないが、旧Importerの局所光欠落もそのまま残る。

反映するには更新したImporterソースを導入し、元のexportを別出力先へ再importする。既存Prefabの材質は自動更新されない。Webの見た目がこの修正で変わったとは説明しない。

ネットワークのアクセス拒否を維持しており、この変更のpush・Pages・配信確認は実施していない。公開前のcache/release整合と最新remote確認は保留。画像はローカル保全のみ。
