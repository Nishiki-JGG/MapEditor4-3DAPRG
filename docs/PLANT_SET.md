# 真上向けの植物10種

草・下草の輪郭と接続、柳の画像は[後続の品質改善](PLANT_POLISH.md)を反映。以下の寸法・画像容量も更新した。

先に公開した [草の十字板修正](PLANT_GROUND_FIX.md) (`f8e60d1`) に続く追加セット。実際の既存カタログは59種類で、旧59 IDの順と配置を保ち、末尾へ10種類を追加した（合計69種類）。共有ライブラリは `shared-plants/2`、既存9資産と新規10資産の計19種類。

[一覧プレビュー](../tests/plant_set_view.html) は真上90度が初期表示。斜め一覧、樹木、低木・下草、遠景、単体を切り替えられる。基準人型は高さ1.8 m・半径.3 m。既存サンプルの配置や自動生成比率は変更せず、新種はパレットで選んで置く・撒く。

## 共通資産と予算

全新種で材質は1個。3樹種と株立ち低木は葉のalpha cutoff .42、その他6種類は葉面・輪郭を実形状で作る不透明モデル。全て両面材質。真上で線になる縦十字カードや、地面に立てた透明矩形を根元に使わない。樹冠の葉束は上から面が見える傾きと曲面にした。

新しい画像は全10種で共有する512×512 atlas 1枚（PNG 258,248 B）。既存エディターのコード生成葉・針葉・樹皮セルと、今回の数値生成による柳・葉脈を使う。外部画像、出典不明・有料素材、新規サービス、ゲーム本体の元素材は使用しない。ライセンス・帰属は変更していない。

sRGB、trilinear mipmaps、異方性2、RGBA8全ミップ概算1,398,100 B。ブラウザとUnityで同じPNGバイト、UV、線形頂点色、Lambert拡散材質を読む。照明・トーンマッピングまで画素一致したという検証ではない。

新10種は合計 2,838 三角形。正本の位置・法線・色・UV・16bit indexの配列は計 391,644 B。JSON・展開中の画像・エンジン管理領域等は含まない。既存のエディターは種類ごとに8,000配置と256ゴーストの行列・色バッファーを予約するため、今回10種分の予約配列は6,274,560 B増える（実際の配列長を計測）。GPU全体のメモリーやスマホFPSの測定ではない。

全新種は静止モデルで、CPU毎フレームの全頂点更新や新しい風計算は追加しない。先に直した草・葦・花と針葉樹の風は保全した。新種への風・接触動作の追加は今回の完成範囲に含めない。

## 寸法と接地

単位はm、pivotは地面原点、全メッシュの最下点Y=0。回転・非一様縮尺を含む保存読込とUnity配置を検査した。木の幹の円形代理判定は白樺.30 m・柳.33 m・松.30 mで、樹冠全体を障害物にしない。低木・下草7種は通れる装飾。

枝と葉の形状全体で確保した標準倍率の下端は、白樺2.570 m・柳2.509 m・松2.631 m。1.8 m人型の頭上に約.71〜.83 mの余裕がある。新しい散布倍率の下限は1。全体縮尺×縦縮尺が約.84未満になると、最も低い柳で2.1 mの余裕を保証できなくなる。手動縮尺や保存済み配置を強制変更しない。

根元が水平面に接地することを確認した。モデルは地形へ変形追従しないため、急斜面・非一様縮尺では葉や根の一部が浮く/埋まる場合がある。地這いツタなどは散布可能な傾斜を控えめにした。

## 検証

- ユーザーPCのChrome・使い捨てプロファイルを使用。真上90度の正投影一覧（幅30 m）、斜め、遠景（幅57 m）、10種それぞれの真上/斜め、1 cmカメラ移動を撮影。葉面・輪郭・人型のサイズ、裏面設定、根元を点検した。極端な遠距離で細い葉が画素より小さくなる限界や、実機での時間方向のちらつきを完全保証するものではない。
- ブラウザ78検査：69種類のID一意性、旧59順、旧配置、従来9資産/4画像の保全、各種の分類・選択・配置・削除・回転、寸法、非一様縮尺の保存読込、共有出力、CSV丸めの境界値。
- 元のサンプルZIP内の2マップ（48 m: 384配置、64 m: 1,025配置）を読み、全配置・マーカー・橋・階段を保存再読込後も照合した。元ファイルは変更していない。
- 全正本の数値・法線・UV・非退化三角形、予算、根元を自動確認。木3種の枝下は数値と人型画像で確認し、実エディターの幹の脇を通る判定も点検。
- Unity6000.5.9f1 / URP17.5で122検査：共有19資産、旧9資産出力の互換性、10配置、配列・法線・色・UV・三角形順・PNG・材質、GPUで静止頂点を維持すること、真上/斜め描画、シェーダーコンパイル。
- 既存CSVの縮尺小数3桁の丸めは保全。約7 mの白樺では元のブラウザ配置との差が最大3.487 mmになった。丸め差は形状寸法から求めた境界内。Unityと実際のCSV値との頂点差は20 µm未満で検査した。
- 真上の重なりを、最近傍alpha・ミップなし・深度判定前のCPU投影で見積もった。新種の平均は約1.06〜2.11層、95%点は1〜4層、枝の集まる局所最大は21層。この値はGPUオーバードローや速度の測定ではない。

スマホの実機FPS、GPU時間、発熱、Android/iOS/Builtin描画、ゲーム本体への統合は未検証。水、最新の主人公、地面・崖・舗装、既存サンプル、公開範囲・Pages設定はこの追加バッチでは変更しない。

再実行は `node tools/plants/bake_new.cjs`、`node tests/plant_set_browser.cjs`、`node tests/plant_set_validation.cjs <草修正版checkout>`、`python tests/plant_set_source.py`、`node tests/plant_tree_clearance.cjs`。Unity隔離プロジェクトへRuntime/Editorと `tests/unity/PlantSetChecks.cs` をコピーし、PC指定のキュー経由で `PlantSetChecks.Run -nature-output <証拠フォルダー> -nature-export <new-export>`。画像・ログ・検査プロジェクトはリポジトリ外へ保存する。
