# 資料に基づく根張り・広葉樹の葉塊改善

葉塊と樹皮の反復に対する追加調整は [TREE_SURFACE_POLISH.md](TREE_SURFACE_POLISH.md) と [新しい比較ページ](../tests/tree_surface_compare.html) を参照してください。以下は372797fまでの改善記録です。

9eeb579 を基準に、普通木の独立した爪状の根を幹と連続する根張りへ修正しました。裸地のまま形を確認し、草や地面シールで隠していません。既存96種・50共有モデル・ID・配置原点・設置幅と高さを維持しています。

## 資料と使い分け

- [UMD Extension の正常なブナの根張り写真](https://marylandgrows.umd.edu/2024/01/12/free-the-flare-maintain-visible-root-flare-for-tree-health/)をPCブラウザで実際に確認。幹の地際が丸く広がり主根へつながる曲面を参考にしました。モデルの広葉樹をブナと同定したものではありません。
- [Dallas Arboretum の解説](https://blog.dallasarboretum.org/gardening-tips-trees-gardening-root-flare/)でも、幹と根の境が滑らかな曲線でつながる点を照合しました。
- [UMD の深植え解説](https://extension.umd.edu/resource/trees-planted-too-deeply)の冒頭写真は悪例なので正常形として模倣していません。[UMN の根系資料](https://trees.umn.edu/sites/trees.umn.edu/files/2024-03/root_systems_the_forgotten_50.pdf)は本文と提供されたページ観察を補助に使用。ローカルPDF取得は403で止め、こちらで写真を閲覧済みとはしていません。
- [NParks の湿地根系解説](https://biodiversitysg.nparks.gov.sg/our-ecosystems/terrestrial-and-freshwater-habitats/freshwater-swamps-in-singapore/)と区別し、特殊な板根を全樹種へ付けていません。世界樹・エルフの木の既存板根は今回形状を維持しました。
- ユーザー写真は形の参考のみ。写真・透かしをatlasへ転用していません。目標画像は親側の実画像観察を取り入れましたが、この検証環境で添付ピクセルの直接表示は完了していません。

標準森林サンプルの橋付近にある2本は `oak`（prop_0017 / prop_001v）です。添付の個別マップを取得できていないため、添付2本と同一個体とは断定しません。比較では同じ保存済み標準サンプル・照明・カメラを使い、水・橋・道・人物・茂みの構成を変更していません。

## 変更

- 広葉樹・ナラ・ケヤキ・オリーブ：独立した細い根2本を除き、非対称の幅広い肩が幹から連続する根張りに変更。過大な下方オフセットは追加していません。
- 柳・傘形松・枯れ木・異形の木：露出根を8点の閉じた丸断面、曲線、付け根からの急なテーパー、埋まった終端へ変更。少数の露出根を残す表現で、根系全体の再現ではありません。
- 広葉樹・ナラ・ケヤキ：葉塊を7→21三角形の丸みのある面へ変更。外周位置と最高点を保ち、側面の厚み・法線・局所明暗を調整しました。標準サイズの葉の最低位置は2.1m以上です。
- 広葉用256角セル：放射方向に揃う小葉から、不規則な向き・重なり・濃淡の手続き小葉へ変更。透明余白にもRGBを入れ、フィルタ時の黒い縁を抑えています。ほかのatlasセルのRGBAは完全一致です。赤いモミジ等の樹種色は頂点色で保持します。

## 葉のテクスチャと負荷

以前から葉は `tree-canopies-v1` 1024×512 atlas を使用しています。広葉セル256×256、sRGB、三線形フィルタ、mipmap、異方性2、alpha cutoff 0.42、両面、各種類1材質です。atlasのRGBA8＋mip概算は約2.67MiBで共有。画像枚数・解像度・材質数は増加していません。PNGは317,235→326,241 bytes（+9,006）。

| モデル | 変更前tri | 変更後tri | 根元 |
|---|---:|---:|---|
| willow | 792 | 1218 | rounded-exposed-roots |
| scotspine | 698 | 1112 | rounded-exposed-roots |
| zelkova | 843 | 1529 | continuous-flare |
| nara | 759 | 1421 | continuous-flare |
| olive | 770 | 1610 | continuous-flare |
| oak | 661 | 1215 | continuous-flare |
| deadtree | 540 | 930 | rounded-exposed-roots |
| twisttree | 684 | 1098 | rounded-exposed-roots |

8モデルを1個ずつ合計5,747→10,133三角形（+4,386）。他42共有モデルの形状・パラメータは完全一致。atlas変更は広葉セルを使う他樹種にも共有されるので、モミジ・白樺・低木等も表示確認しています。丸い茂み `bush` はデータと専用画像をそのまま保持しました。

葉セルのalpha判定を通る面積は25.8→29.4%（約1.14倍）。これはセルの面積比で、画面上のoverdrawやGPU時間の実測ではありません。立体化した面の重なりもあり、透過負荷が増える可能性は残ります。樹種間は別InstancedMeshなので、同じatlasでも1描画にはなりません。裸地2本シーンは前後とも11描画、標準森林1,204配置の比較は前後とも31描画・582,420→596,270三角形でした（renderer.info の同条件フレーム、影等の総GPU負荷の保証ではありません）。

## 確認範囲と制限

ユーザーPCのChrome/SwiftShaderで裸地の根元近接、歩行補助視点、真上、人物比、同一森林サンプルを目視比較しました。通常の根張りは爪状突起をなくせましたが、近接の樹皮の縦線や葉塊の繰り返しは残ります。目標画像と同等の写真品質に到達したとはしていません。

検証はソース241項目、24種の選択・配置・回転・削除・旧保存読込211項目、根付き24種の斜面/非均一拡縮96ケース、裸地・草地・境界/太陽オンオフ/縮尺96ケースを通過。全38可動モデルと根付き24種のGPU座標を比較し、無風の静止一致・根幹固定・風/接触の合成・個体の位相差を確認しました。本体では今回の8種と保全した茂みの計9種について、無風/そよ風/強風の時系列画像、歩行接触、連続接触の上限、離脱後の復帰を確認。根張りの形を後から変更した最終データで再検査しています。

隔離Unity 6000.5.9f1/URP/D3D11で327項目、根元材質/受け渡し173項目を通過。共有50モデルの形状・法線・UV、GPU変形とブラウザの座標一致、新旧エクスポート、固定根幹、影、緩斜面の受け渡しを確認。裸地一定条件の根元近接も全24種を撮影しました。Unityの検査照明は本体ブラウザと異なり、色や陰影が完全一致するという判定ではありません。

PCのページング領域不足で途中のコマンドが一時停止しました。状態照合後、既存処理の完了を確認し、最終検査を確定しています。最初のUnity検査は材質比較用入力の準備漏れで停止しましたが、入力生成後に同じ検査を通過しました。これらを製品の不具合やスマホ性能の証拠とはしていません。

接触CPUのみの参考値はユーザーPC Chrome/SwiftShaderの484配置・2,400stepを計測。描画FPSやスマホのGPU負荷は測っていません。急斜面・曲面地形は15%上限の局所平面追従による限界、小縮尺の枝下、簡易幹colliderと細根の不一致を引き継ぎます。スマホ実機、ゲーム本体統合、Built-in描画は未検証。既知のUnity D3D12終了時クラッシュは未解決です。
