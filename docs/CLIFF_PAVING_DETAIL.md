# 岩壁と石畳の表示改善

急斜面の岩壁に石畳と同じ多角形の黒線を描いていたため、平面に壁紙を貼ったように見えていた。岩面用の粒子・地層の色に分離し、急斜面にだけ実際の凹凸を持つメッシュを追加した。草との境界は傾斜とノイズで混ぜる。

## 岩面

- `terrain/cliff-relief.js` は編集中の地形から派生する表示メッシュ。元の高さ、出入口、橋、隠し通路、通行判定は変えない。
- 凹凸は最大約0.6m。周囲の高さを使って裾・肩で減衰させ、選択領域の外周とマップ端は元の面に接続する。隣り合う三角形は同じ頂点を共有する。
- 急斜面だけを1〜4分割し、追加三角形数は `max(64,000, 元の急斜面三角形数)` 以下。描画は1メッシュ追加。平坦地は生成しない。ブラシ操作後100msでまとめて再生成し、古いGeometryを解放する。
- 保存する高さデータは従来と同じ。読み込み時に再生成する。
- exportでは `cliff_relief_mesh.json` を追加し、`meta.terrain.cliffRelief` から参照する。座標・法線・三角形の向きをUnity規格へ変換する。schemaVersion 3は維持する。
- **Unity側のインポーターとマテリアル対応、物理判定の変更は本変更に含まない。** 高さマップだけを取り込む場合、追加の岩面形状は出ない。エディターでは表示形状であり、元の地形が歩行判定を担う。

## 石畳

- 石を小さくし、細い土の目地、石ごとの色差、浅い面取りの陰影を加えた。面取りは照明用の法線だけに作用する。
- 石の目地は最寄りの点との距離差ではなく、実際のセル境界への距離から計算する。石の内部に偽の三角形の面取りを作らない。
- 草・土との端は塗りの重み、ノイズ、石ごとのばらつきでなじませる。既存の塗り・消し・保存をそのまま使える。

## 確認

`node tests/cliff-relief.test.cjs` は平坦地、凹凸の生成、外周の接続、元の高さの不変、再生成の一致、128mでの生成量の上限、Unity書き出し座標と巻きを確認する。
ブラウザーでは同じ48m遺跡マップを修正前後で撮影し、描画エラーと書き出しを確認する。既存サンプルの出入口警告は修正前後で比較する。
