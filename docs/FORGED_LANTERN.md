# Supported hanging lantern

Lantern, torch and brazier were compared in actual Web images. The torch and brazier already show their fuel holders, logs and support feet, so they are retained. Only the hanging lantern fixture changes: a diagonal forged brace into post collars, a thicker suspension ring, bevelled arm and tray, folded eave hems, corner shoes, small door hinges/latch and a stepped foot. The burner seat is under the existing luminous centre. Iron/edge/soot colours differentiate contact and exposed surfaces while retaining the existing shared carved grain texture and shader. No new texture, material, renderer or light is allocated per instance.

The lantern remains ID lantern, radius 0.15m, height 1.9m, with the same tags, placement, ground offset and lighting settings. Its arm/head envelope is unchanged. Triangle count increases from 304 to 908. The emitter is intentionally not redesigned: its exported positions, normals, colours and glow values are exact, as are light/asset/collision metadata. There are no new flames, particles or brightness changes. A local variable collision and incorrect cap winding in early trials were caught and corrected before adoption.

Web verifies save/reload, finite geometry, Collider data, all non-lantern small-prop payloads and the entire torch/brazier fire export with a fixed room seed. The baseline Reader and fire importer are unchanged. Unity 6000.5.9f1 / URP17.5 generates 43 Prefabs and one lantern placement per version, and imports both unchanged fire fixtures. Lantern Collider vertices/indices and all 42 unrelated meshes match. The one lantern Light has identical type, colour, intensity, range, shadow mode and local position. Fire particle configuration and lights match; the lantern shader, keywords and texture match.

Actual pixels were reviewed at Web close/normal distance, Unity close/opposite light and in the existing natural-cave generator, seed 71421, normal game camera, original torch/lighting/postprocessing conditions. Only the isolated in-memory review environment was used; source game scenes were not saved. Existing chest lighting tiers, water work, pots, barrel, graves and shoreline props are unchanged. This remains the project's stylized diffuse-metal fixture; no new physically based metallic material is claimed. Player, full gameplay and Native GPU timing were not executed.
