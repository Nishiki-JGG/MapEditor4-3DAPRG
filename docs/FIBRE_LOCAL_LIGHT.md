# Fibre props receive local light in URP

The existing Web fibre material retained the built-in local-light calculation. The formal Unity `MapSharedProps/FibreProp` material, used only by tiedsack and coiledrope, calculated SH ambient and the main directional light but ignored point and spot lights. Under a local light alone, both imported objects remained black even while nearby lit geometry responded.

The bounded correction adds URP additional-light variants and its light loop to this one shader. Existing fibre colour/normal detail, main-light response and shadows are retained. Local lights use their direction, distance attenuation and shadow attenuation. Forward+ includes non-main directional lights and clustered punctual lights. No importer, UV, shape, texture, scene light, exposure, save schema or other material is changed. There are no additional lights, textures or triangles. Cost includes the normal per-visible-light shader calculation; Native GPU timing is not measured.

Unity 6000.5.9f1 / URP17.5 tests actually imported 44 Prefabs from the existing formal export and compared positions/indices, UVs, normals, colours and actual Collider counts/geometry with the prior imported set. In Forward and Forward+ with per-pixel local lights, point-only and spot-only views now illuminate both props; a shadow-only blocker removes that light. Main-only and all-off PNGs are byte-identical before/after. The pre-change shader is loaded under a review-only shader name for real A/B comparison, not aliased to the changed shader. An old reader source control flow also generated its original 43 Prefabs with matching geometry/Colliders; no old executable was run.

The existing isolated production cave generator, seed 71421, was reused with its authored 21 torches and unchanged normal-distance camera offset. At the previous placement the nearest torch is 6.19m away and the difference is restrained. A same-room actual floor cell 2.24m from an existing torch shows the rope and sack receiving warm light at normal distance and close up. The first proposed close location intersected a wall and was rejected by the placement guard; the final location was selected from real floor cells with collision and camera visibility checks. No game scene was saved or light modified. Images remain local; their hashes and changed bounds are recorded in validation/fibre-local-light/results.json.

For reproduction, set FIBRE_REVIEW_PROJECT to the existing dedicated review project, then run `node tests/fibre-local-light.cjs` and `python tests/prepare-fibre-local-light.py`. The Editor checks require the existing Input114-after export, Imported115-default baseline Prefabs, ColliderSnapshot109 and LegacySmallProps114 helper, URP PC_RPAsset/PC_Renderer test assets. Run `Fibre116Checks.Run` then `Fibre116Checks.Legacy` in separate background Editor batchmode runs. Fresh Imported116 / Imported116-legacy folders are required. The shared view helper can be used with the existing isolated scene harness; production game-specific scene/generator code is not copied into this repository.

The Web check confirms existing local-light response and save/reload; Web product code is unchanged. Player, mobile, complete gameplay and Native GPU timings are untested. Additional-light vertex mode is declared but was not independently compiled or rendered. Updating the runtime shader in the consuming Unity project is required; publishing the editor page alone does not replace that project's imported assets.
