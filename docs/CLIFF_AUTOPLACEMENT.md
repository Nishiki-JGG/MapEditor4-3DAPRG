# 崖への岩の自動配置

崖の全域に1.45m間隔で岩を積み、垂直方向へ拡大していたため、石積みの堤防や浮いた大岩の列に見えていた。地形の岩面を主役にし、自動配置はまばらな張り出しと小さい崩落岩に変更した。

- 岩は崖の高さへ伸ばさず、等倍率で配置する。垂直積み上げはしない。
- 急斜面と十分な高低差がある場所だけを対象にし、緩い斜面・低い川岸・水没した岩場を除く。
- 岩の背面が地形へ埋まり、前面だけが出る位置を選ぶ。上端を崖上へ大きく飛び出させない。
- 約3m以上の間隔と、まとまった空白区間で連続する岩の列を崩す。
- 裾の大岩を大量に置く処理を廃止。乾いた緩斜面で支持される場所だけに、0.36〜0.65倍の小岩を少数置く。
- 橋・階段・滝・水源への流れ・開始地点・各種スポット・出入口・到着点・明示された通行域を保護する。橋/階段には岩の外寸と人物の半径も含めて余裕を取る。
- 自動生成フラグ1の岩だけを置き換える。手置きの物、植生、高さ、塗り、水、橋などは維持する。Undo/Redoも従来どおり使える。
- SEEDによる配置は再現可能。通常サンプルの生成では、橋・滝・階段・スポットを作った後に岩を配置する。

## 実装と確認

`terrain/cliff-placement.js` が地形から候補を選び、既存の `autoRocks` が通行域と手置きオブジェクトを保護して配置する。保存形式は変更しない。exporterVersionは `tdj-map-editor/2026.10.21-r19`。

- `node tests/cliff-placement.test.cjs`：同じSEEDの再現、積み上げ/縦伸ばしなし、間隔、保護域、障害物、緩斜面、水没。
- `node tests/auto-rocks-browser.cjs <repo> 64`：実ボタン、再配置、Undo/Redo、手置きと地形の保全、橋・階段への離隔。
- 同テストの48mは地下通路付き遺跡で確認する。

既存の手置き岩が地形から浮いている場合は本処理で動かさない。Unity側での再配置機能と物理確認は対象外で、書き出しにはエディターで確定した配置座標が入る。
