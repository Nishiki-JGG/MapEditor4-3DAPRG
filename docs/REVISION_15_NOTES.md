# マップエディター 修正報告（Revision 15）小物の質感・草むら・当たり判定・隠し通路の段差

セミリアル化の続きです。あわせて、ユーザーが見つけた不具合 3 件（隠し通路の前の茂みが消える、当たり判定の抜け、隠し通路から崖の上へ上がれる）を直しました。

## 不具合の修正

1. **隠し通路の前で、近づくと茂みが消えた**
   - 原因：隠し通路の上では、主人公と重なる小物を半透明（不透明度 0.28）にしています。葉のカードは、葉の無い部分をアルファの値で抜いています（基準 0.42）。抜く判定は半透明にした後に行うため、すべての画素が基準を下回り、茂みが丸ごと消えていました。
   - 直したこと：
     - 半透明にした葉のカードは、抜く基準を 0.1 にしました（共有小物の針葉樹・シダは元の値の 1/4）。
     - 揺れる低い植物（茂み・シダ・葦・花・草むら）は、半透明にせず、揺れて押しのけられるだけにしました。
2. **当たり判定が無い所があった**
   - 原因：崖石は幅約 2.3m の柱の列ですが、当たり判定は中心の円 1 つ（半径 0.6m）だけでした。岩も、横に付いた小さな塊には判定がありませんでした。
   - 直したこと：見た目の体（地面から頭の高さまで）が、当たり判定の円から 0.4m 以上はみ出していた小物の判定を広げました。
     | 小物 | 前 | 後 |
     |---|---|---|
     | 崖石 | 半径 0.6、円 1 つ | 半径 0.6、円 3 つ（-0.8・0・0.8） |
     | 岩 | 半径 0.8、円 1 つ | 半径 0.8、円 2 つ（-0.55・0.55） |
     | 折れた石柱 | 半径 0.5 | 半径 0.7、円 2 つ（0・0.85。倒れた胴まで） |
     | ピラミッド | 半径 4 | 半径 4、円 3 つ（-2・0・2。四隅まで） |
     | 霊廟 | 半径 1.5 | 半径 1.5、円 2 つ（-0.7・0.7） |
     | 石筍 / 氷塊 / 噴気孔 | 0.5 / 0.7 / 0.6 | 0.65 / 0.95 / 0.9 |
   - 確認：サンプル2で、崖石と岩の体の上の点のうち通れる所は、前の 948 点中 44 点・128 点中 21 点から、0 点になりました。
   - `asset_catalog.json` の半径・円の位置（offsets）も、この値になります。
   - 残っているはみ出しは、背の低い瓦礫・骨・雪だるまやサボテンの腕・ランタンの腕などで、0.3〜0.6m です。
3. **隠し通路から、崖の上へワープで登れた**
   - 原因：歩くモードの移動は、行き先が通れる所かどうかだけを見ていて、今いる床との高さの差を見ていませんでした。隠し通路は崖の下を通っているので、通路の壁の向こうの崖の上（通れる地面）へ、一気に上がっていました。
   - 直したこと：床の高さの差が段差（体格の `maxStep`、0.5m）を超える所へは進めないようにしました。坂・階段・橋は、1 コマあたりの差が小さいので、今までどおり上れます。
   - 確認（`tests/secret_climb.js`）：サンプル2の隠し通路の 13 か所から 8 方向へ 1.5 秒ずつ歩かせました。
     - 前：104 回中 39 回が崖の上（約 5.4m の段差）へ上がった。
     - 後：0 回。1 コマの床の変化は最大 0.17m。

## 新しい小物：草むら（`grass`）

- 丈の高い野の草の株です。種の穂と、枯れた葉が少し混ざります。
- 十字のカード 3 組で、1 株 12 三角形です。
- 歩くと押しのけられて揺れます（`touch`）。
- 自動配置：地面の塗りから小物を置く処理（`regenGroundProps`）が、何も塗っていない草地に、決まった並びで置きます。
  - 対象のバイオーム：草原・森・ジャングル・遺跡・墓地・浜辺・渓谷・城
  - 水際・急な斜面・橋や階段の上には置きません。
  - 乱数は使わないので、ほかの小物の配置は変わりません。
- 種類の番号は最後（59 番目）です。保存データは種類の名前で対応させるので、前の地図はそのまま読めます。

## 2 枚目のテクスチャ（`props/foliage2.js`）

- 1024×512 の 1 枚を、起動時に canvas で描きます。描いているもの：
  - 草むら
  - 藁
  - 風雨で色の抜けた木目
  - 野の花 4 種（デイジー・キンポウゲ・コスモス・ホタルブクロ）
  - 花の根元の葉
- 前の 1 枚目（1024×1024）は、ほかの道具（`tools/nature/bake.cjs` など）が大きさを決めて読んでいるので、変えずに別の 1 枚にしました。

## 作り直した小物

| 小物 | 内容 |
|---|---|
| 花 | 根元に葉のロゼット、茎、テクスチャの花（1 株ごとに主な花と混ざる花） |
| 干し草 | 藁のテクスチャ、腰の縄、足元にこぼれた藁 |
| 木の柵 | 木目の丸太の柱（先を尖らせた）、横木、釘 |
| 小舟 | 断面をつないだ船体（舳先と艫が尖り、底が丸い）、板の木目、縁材、腰掛け、櫂 |
| 流木 | 白く色の抜けた木目、ねじれた枝 |
| 松明 | 木目の柄、縄の巻き、焦げた先、3 層の炎 |
| 氷塊・氷柱 | 氷の材質：青緑の深み、縁が明るく透ける、細かいひび |
| かまくら・雪だるま | 雪の材質：なめらかな陰影と細かい粒 |
| 黒曜石 | 光沢のある材質 |
| 噴気孔 | 岩肌の模様 |
| 橋・階段 | 岩肌の模様（少し弱め。木の橋では古びた木目に見える）。石の階段の脇石を割れ面のある形に |

- 材質は、描画の回数を増やさない形で足しました：`cards2`・`ice`・`snow`・`gloss`、橋と階段用の 1 つ。
- 岩肌の模様の強さは材質ごとに変えられます（`DETAIL_K`）。
