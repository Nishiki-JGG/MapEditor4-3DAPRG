# 林床植物3種の磨き込み

[単体・群生の確認](../tests/forest_floor_view.html) / [本体](../index.html#size=64)

真上90度を主基準に、シダ・つる性の茂み・地這いツタを改善した。夜間に改善したユーカリ・龍血樹・エルフの木・世界樹と、他の共有46資産は維持している。全96種のID順序、原点、設置用の設定、3種の外形寸法を維持した。

## 変更と負荷

|対象|変更|三角形数 前→後|材質|
|---|---|---:|---:|
|シダ `fern`|粒状に抜ける細部を連続した羽状葉へ置き換え、葉色を穏やかに整理。既存形状を維持|220→220|1|
|つる性の茂み `bramble`|直線的な放射枝を4本の弓なりの枝へ整理し、葉束を枝の節に接続。長さと向きを不均等にした複葉で枝先を覆う|320→284|1|
|地這いツタ `ivy`|同形の星形を崩し、切れ込み・折れ・向きの異なる葉と低いランナーを組み合わせた|198→186|1|

合計738→690三角形。シダ画像は同じ512×128、PNG 36,083→18,339 bytes。他6画像はバイト一致、画像計7枚・解像度・ミップマップ・フィルタ・sRGB設定・材質数は維持した。RGBA8の全ミップを含むシダ画像の理論容量は約341KiBで変わらない。新画像もコードで描いたもので、外部画像を含まない。

シダの風の基準振幅0.10mを維持し、根元固定の高さウェイトを既存の共有GPU方式へ揃えた。接触上限は0.12m、風との合成上限は0.16m。旧ブラウザ専用接触の約0.247mから抑え、Unityにも同じウェイトと接触設定を渡す。毎フレームのCPU頂点更新は行わない。ツタのランナーは固定し、葉の付け根から先端へ重みを増やす。つる茂み・ツタの既存風振幅と接触上限は維持した。

実用配置の本体描画回数は通常距離の真上24回・斜め25回、遠距離55回で前後同じ。配置した12株の三角形は合計192削減した。これは本体描画のカウンターで、影の描画を含むGPU時間ではない。影は同じメッシュ・同じ変形を使用し、追加の影専用メッシュやパスはない。

## 確認した範囲

- ユーザーPC上のChrome（SwiftShader）で、同じ照明・カメラの単体と24株群生、岩・倒木・林縁・花畑に隣接した本体配置を真上／斜め、通常距離／遠距離で前後比較した。人型の基準は1.8m。表示用主人公の既存設定は変更していない。
- 自動763項目：対象外46資産・6画像の一致、既存外形寸法、非退化三角形、全96種のID順序、配置・削除・回転・非均一拡縮、公開済みマップと新規マップの保存再読込、共有エクスポート。
- WebGLの実GPU演算で37資産の静止基準、風・接触の合成、固定根元、株の位相差を確認。3種を本体の無風／そよ風／強風、連続接触、離脱後の復帰、0.6倍と標準サイズで確認した。最大変位を8方向へ与えて面反転なし。辺長比の範囲は約0.803〜1.205で、厳密な長さ保存ではない。
- Unity 6000.5.9f1 / URP / D3D11で49共有資産、26配置、旧v2〜v6、GPU位置一致、ウェイト、接触・復帰、影シェーダーと3種の実描画を247項目で確認し、exit 0。
- 本体接触CPU処理の参考計測は484株・2,400更新、候補最大27、バッチ平均約0.014ms、p95約0.10ms。ユーザーPCの当該検査のみで、描画全体やスマホの計測ではない。

## 制限と再生成

スマホ実機性能、ゲーム本体への統合、Built-in描画は未検証。既知のUnity D3D12終了時クラッシュは未解決。急斜面への自動接地と小縮尺での木の枝下制限も今回の対象外として残る。

専用生成元は `tools/plants/forest-floor.js`、焼き出しは `node tools/plants/bake_forest_floor.cjs`。`--check` はファイルを書き換えず再現性を検査する。初期10種用の `bake_new.cjs` は、この専用生成元へ移管したつる茂み・ツタと共有ウェイト付きシダを上書きしない。

主な検査は `forest_floor_validation.cjs`、`forest_floor_pose.py`、`forest_floor_review.cjs`、`forest_floor_main_review.cjs`、`forest_floor_contact_frames.cjs`、既存の `tree_gpu.cjs` と `tree_motion.cjs`。Unityの既存検査には `-tree-capture-ids fern,bramble,ivy` を渡すと3種を撮影できる。詳細な比較画像とUnity生成物はローカル証跡へ保存し、公開リポジトリには含めていない。
