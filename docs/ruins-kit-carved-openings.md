# 装飾された直角開口

`opening:carved` と `opening_broken:carved` を選択リストへ追加。
新しい構造種ではなく、既存の開口2種の任意仕上げ。既存の無装飾・風化版と保存配置は変えない。

- 内法2m、壁厚0.5m、既存90度回転・0.5m格子・壁端接合を使う。
- 標準の完成開口は全高3m、まぐさ下面2.7m。高さ変更は既存検査内。
- 縦の彫刻枠と菱形、まぐさの帯を共有の石材shaderへ追加。壊れた開口は上部が失われた形状なので、残存側壁の彫刻だけが残る。
- 元形状・接合面・Colliderは無装飾と同一。装飾は凹凸シェーディングであり、独立した深彫り立体メッシュではない。
- 浅い風化面も連続投影する。平滑な面だけを選んだ初案で生じた三角形ごとの色切替を採用しない。
- 新しいテクスチャ、マテリアル、追加Rendererなし。標準高さ2.2mは1081/1185tri、高さ3mの検証用2点は1117/1437tri。装飾追加による形状増分は0。

正式exportの `finish:carved` と既存 `ruinsStructuresV1` を使用。更新したJSとImporter/shaderを一緒に使う。以前のReaderに新しい装飾開口を渡さない。旧Webの拒否を実行確認、旧Unityはwhitelist制御フロー確認のみで旧バイナリ未実行。

検証対象: 既存70通りのメッシュ不変、24回転/高さ条件、格子/壁接合、headless実ポインタ配置/回転/Undo、正式map保存再読込、専用Unity正式importとPrefab/Scene再読込、既存46点のメッシュと画像不変、中央通行と両脇Collider、共有参照、Forward/Forward+の主光/環境/点/spot/消灯。
GPU、スマホ、Player、元ゲームへの組込みは未検証。公開していないローカル候補。
