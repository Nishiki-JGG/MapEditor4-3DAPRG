## 修正

1. **下り階段のワープ先が見えず、地面が重なって描画されていた**
   - 下り階段を、地面に掘った本物の穴にしました。
     - 穴の範囲の地形は、エディターの描画で消しています（地形シェーダーで切り抜き）。
     - 穴の中には壁と床、地上から下りていく 6 段の階段があります。
     - 底に旅の扉のゲートを置き、上から覗き込んだときに見えるよう少し後ろへ傾けています。
   - Unity 向け出力：
     - 穴の範囲に重なる書き出しセルを `holes.png` の穴に加えます。サンプル1 は 36 セル、サンプル2 は 54 セルです。
     - 数は `meta.floorLinks[].pitHoleCells` に、穴の形はカタログの `floorLinks.floor_stairs_down.pit` に出力します。
     - 穴の壁・床と、穴のセルを覆う縁は、stairsDown の Prefab 側で作る前提です。
2. **上り階段を上れなかった**
   - 6 段の階段（1 段 0.4m）と踊り場を歩けるようにしました。触れる範囲は踊り場のゲートの前です。
   - 確認結果：
     - キー操作で上ると、高さ 0 → 1.83 → 2.4m と上がり、踊り場で「▲ 上り階段 → B0」が出る。
     - 階段の横からと、ゲートの裏からは入れない。
   - カタログの `floorLinks.floor_stairs_up.walkSurface` に、段の寸法を Prefab のローカル座標で出力します。
3. **岩壁（崖石）をすり抜けていた**
   - 崖石の当たり判定の半径が 0 になっていたのを 0.6m にしました。
   - サンプル1 の崖石 600 個のうち、中心を通れるものは 0 個です。
