# 本体の強風応答と鈴花の可視性

`6bf963c` の風を、本体の天候操作と通常プレイ距離で再調査した。鈴花を含む追加10種だけでなく、共有植物15種と既存カタログ69種のモーション登録を確認した。形状・画像・材質数・ID・マップ保存形式は維持している。

## 原因

- 本体の天候は正常に届いていた。環境効果の量.7では「そよ風」.245、「強風」.7。方向の正規化は方向ベクトルだけで、強度は残っている。両者は上限クランプで同値になっていない。強度1より上は従来どおり1に制限する。
- 共有植物の旧式は原点を中心とする往復だけだった。鈴花の最大振幅.045 mに強度.7を掛けるため、理論上限は.0315 m。今回の撮影時刻では通常距離で最大約1.5ピクセルしか移動していなかった。
- 鈴花の低い葉は、全高約1.65 mを基準とした高さ重みが最大.0306だった。花茎と花は動いていたが、低い葉はほぼ読めなかった。広葉ロゼットも同じ問題を持っていた。
- シダには接触登録はあったが、風設定がなかった。広葉樹・茂み・枯木・ヤシ・バナナと旗には従来の別の風経路がある。今回その経路は変更していない。木の高い樹冠は通常の人間の接触対象ではなく、切株・倒木・根などは固定物として扱う。

## 修正

共有風の応答を、正規化強度 `s`、既存の2つの正弦波の合成 `wave` に対して次の式に変更した。波の速度を上げるだけの変更はしていない。

```
force = s * (.25 + .75*s) * (.65 + .35*wave)
displacement = direction * force * speciesAmplitude * vertexWeight
```

風下へ保たれるしなりと、その上の強弱を合成する。風上へ規則的に反転する動きを避け、同じ種類・同じ時刻の強風応答はそよ風の約5.1倍（環境効果量.7）になる。配置と種類による位相差は維持した。

鈴花・ロゼット・スゲ・つる茂みの葉では、既存の高さ重みに「葉の付け根から先端までの位置」を補う。枝に付く葉は付け根の従来重みを維持する。鈴花の低葉は最大.193、ロゼットは.553になった。枝や地面の固定点、木3種の幹マスクは変更していない。シダに高さマスクの風を追加した。種類別の硬さを残し、低いツタは小さな葉先の動きに留める。

風の最大変位 m は、白樺.16、柳.24、傘形松.14、株立ち低木.18、つる茂み.10、ツタ.018、スゲ.18、鈴花.28、トクサ.14、ロゼット.12、草.12、葦.20、花.07、シダ.10、既存針葉樹.16。これは強度1・最大突風・重み1での上限であり、常時この量だけ動くという意味ではない。Y変位は0。根元と接地、標準サイズの枝下高さは維持する。接触変位の上限は変更せず、風と接触の合成を保つ。

## 検証・負荷・互換

- 共有15種の実WebGL2シェーダーを読み戻し、無風・そよ風.245・強風.7・強度1、根元固定、風下への変位、強風との差を検証した。追加10種では回転・縦縮尺・風と接触の合成も再検査した。
- 本体で追加10種と旧5種（草・葦・花・シダ・茂み）の接触と離脱後の静止を確認。高い樹冠の接触除外、連続接触の上限、保存座標・頂点バッファ不変も確認した。旧高木を近くにいるだけで曲げる変更はしない。
- ブラウザ95項目の登録・分類・配置・回転・削除・保存読込・書き出し。従来の「シダ全データが静止版と同一」という検査は風追加の対象と合わないため、別の19種形状保全検査で全頂点・法線・色・UV・三角形・材質・5PNGの完全一致を検証した。
- Unity6000.5.9f1 / URP17.5の隔離環境で99項目。15種の風シェーダー座標をブラウザの読み戻し座標と照合し、接触・減衰・固定点・可視範囲・旧書き出し・実URP描画と影を検査した。元ゲームへの組み込みは行っていない。
- 通常の強風.7・時刻.9の三角形辺長比は全15種で約.930～1.079、95%点は種類別で最大約1.062。数値はこの代表フレームの診断で、厳密な長さ保存や布の物理計算ではない。無風では元形状に完全一致する。

最大突風と最大接触を同方向に足す理論上限も8方向で検査し、追加10種の三角形反転はなかった。この極端な合成で局所的な辺長比は.742～1.318となるため、強度最大・接触最大での伸縮は残る。軽量な頂点変形であり、厳密な長さ保存を保証する実装ではない。

共有19種4,640三角形、各種1材質、5画像とGPU頂点属性数・容量は増加なし。追加の全頂点CPU更新、追加の透明板、追加の乱数やテクスチャ参照はない。風があった種は正弦波の数を増やさず、応答の乗算・加算を追加した。シダは従来静止からGPU風の演算が増える。接触処理4,000株では候補114・活動4、CPU95%点約.1 msで前回と同程度（このPCのタイマー分解能を含む）。全体FPS・GPU時間・スマホ実機・発熱の性能は未測定。
