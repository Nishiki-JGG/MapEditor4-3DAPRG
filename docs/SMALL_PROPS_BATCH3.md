# 小物の派生3種：頭骨群・座像・損傷像

既存の骨・石像を共用し、配置用途と輪郭の異なる3種を追加したローカルバッチ。公開は含まない。基準は `8189006`、洞窟床選択 `4451d8e` と洞窟改善の取り消し `2188fbd` を保全している。

## 追加内容と実画像の所見

| ID / 日本語名 | 形と用途 | 三角形 / 頂点 | 高さの設定 |
|---|---|---:|---:|
| skullpile / 頭骨の集まり | 向きの違う頭骨3個と小さな長骨片。長骨を散らした既存骨山と使い分ける。通行を遮らない小装飾。 | 606 / 1818 | 0.40m |
| statue_seated / 座った石像 | 椅子に支持された着衣の座像。前へ出た膝、裾、足、膝に置いた手が立像と異なる。 | 376 / 1128 | 2.22m |
| statue_damaged / 損傷した石像 | 頭と片側前腕の欠損、斜めの破断面。落ちた頭部と小片を広い台座上で支える。 | 294 / 882 | 2.10m |

土面・倍率1・共通照明で、既存の骨山と立像および新3種を真上17mと近接から比較した。像はカメラ距離5.8m・注視高さ1.3m、骨は距離2.2m・高さ0.2mを固定。座像をカメラの自動拡大で立像と同じ高さに見せていない。

真上では座像の四角い背もたれと膝の前への張り出し、損傷像の低い上体と台座上の頭部を識別できる。近接では座像の膝・足・椅子が連続して見える。頭部を地面へ別置きした試作と、座像の胴が長かった試作は採用しなかった。最終座像は2.22mで、初期試作2.35mではない。

頭骨の顔、石像の顔と衣のひだは角張った簡略表現が残る。真上の通常距離では細部は小さく、主に輪郭と量塊の違いになる。写実品質や美観の完全解消を技術検査の成功から主張しない。

## 負荷と未検証

各種類は既存の1材質、追加画像0・追加シェーダー0。3種各3配置の指定シーンで描画8回・13446三角形・プログラム69。これは当該シーンの絶対値で、同じ場面の新旧FPS比較ではない。未配置種類が必ず描画呼出しを生むという意味でもない。

追加メッシュ属性は153120バイト（約149.5KiB）。さらに既存方式の各種類8000配置＋256プレビュー容量により、インスタンス配列が3種合計1882368バイト増える。合計のCPU側TypedArray増分は2035488バイト（約1.94MiB）。メッシュ分だけを総メモリとして扱わない。GPU実割当、スマホのCPU/GPU・透過重なり・FPSは未測定。毎フレームの頂点更新や自動処理は追加していない。

Unityではこれら旧来の手続き小物の外観は別Prefab経路であり、今回新しい外観Prefabの作成・実機取り込みは未実施。ブラウザの検証をUnity外観検証済みとはしない。前バッチの装飾用折れ石柱の平坦な破断面も未解決のまま保全した。

作業用の比較は `small-prop-batch3/index.html` とbefore/after画像、検査記録はverification.json、rekey.json、memory.json、sample-smoke.json。Libraryの既知の非対応経路は再試行しておらず、ネイティブ添付や共有URLは作成していない。未公開。
