# 混在林・林縁・根元のブラッシュアップ

龍血樹は後続の[実物参照修正](DRAGON_REFERENCE.md)で、反復分岐と浅い連続天蓋へ再構成した。以下は当該バッチ時点の記録。

[4つの実用配置を見る](../tests/nature_scene_view.html) / [木の確認一覧](../tests/tree_view.html) / [本体](../index.html#size=64)

配置例は本体の描画・風・接触を使う。「混在林」「花畑と林縁」「岩と倒木」「世界樹と人物」を切り替え、真上90度と斜め、無風・そよ風・強風を確認できる。「世界樹の根元」で接地部へ寄れる。画面をクリックしてWASDで歩ける。配置例内の操作は保存済みマップへ影響しない。ブラウザ制限がある場合はPagesのHTTP公開URLを使う。

## 監査と採用した変更

公開版c27e20eを同じ照明・カメラ・配置で比較した。種数を増やさず96種のまま、以下4種を改善した。

|対象|変更|三角形 前→後|材質|
|---|---|---:|---:|
|ユーカリ|枝の中ほどにも葉塊を置き、裸枝の長い隙間を減らす。縦長の銀青緑の輪郭は維持|330→379|1|
|龍血樹|葉束ごとに10〜12枚の長短・向き・幅の違う曲げ葉を置く。既存アトラスの空き領域に剣葉の筋と明暗を追加|516→624|1|
|エルフの森の木|固定された幹へつながる低い板根、樹皮UV、根元のAOと法線を整理|537→507|1|
|世界樹|細い放射状の突起を板根へ変更。高い部分を幹の既存当たり判定付近へ集め、外側は低くする。高さ24mと横の設置寸法は維持|871→801|1|

4種各1本の合計は2,254→2,311三角形、57増。世界樹とエルフの根は固定のまま。根の下面は地面近くにし、幹への接続面に樹皮を割り当て、黒い板に見えにくい上向き寄りの法線を使う。物理用の新しい根コライダーは追加していない。既存の幹当たり判定・保存形式は維持する。

樹冠の生成乱数を根の変更で消費しないようにし、世界樹の横輪郭を保った。原点と最大寸法は維持するが、根の地下部分を整理したことで世界樹の内部の高さのフィットには小さい差がある。標準寸法の最も低い枝葉はユーカリ約2.72m、龍血樹約3.48m、エルフ約2.78m、世界樹約4.51m。

針葉画像の描き替えも試したが、遠景の密度や輪郭が悪化したため採用しなかった。針葉の画像セルとモデルは公開版を維持する。岩・倒木・花畑など対象外45共有資産はデータ一致を確認した。地面・水・主人公・本体UI・花畑の配色制御・既存IDは変更しない。

## 画像・描画負荷

- 共有画像の枚数・解像度は7枚のまま。木の共用アトラス1024×512の空き領域だけに剣葉の模様を追加し、PNGは264,536→283,181 bytes（18,645 bytes増）。RGBA8とミップの理論GPU容量約2.67MiBは変わらない。外部素材なし、コード描画のみ。
- 上段の既存葉・針葉セルは画素一致。下段等の再描画縁に2,510画素の差があり、最大8/255、アルファテスト0.42を跨ぐ画素は0。既存の別6画像はバイト一致。
- 新しい材質・影用モデル・影パス・ライト・デカールは追加しない。種類数・インスタンス用固定配列の容量も増やさない。毎フレームのCPU頂点更新はない。
- 同じ4配置で、主描画の呼び出し回数と三角形数を記録。呼び出しは混在林25、林縁24、岩と倒木24、世界樹18のまま。三角形の差は順に+49、0、+108、-100。影も同じ共有メッシュを使い、影用の追加モデル・パスはない。影のGPU時間は未測定。透過の重なりや影のピクセル負荷が完全に同じという意味ではない。

## 検証

- 形状・固定根元・面向き・法線・標準枝下・対象外45資産など842項目。
- 96種の順序維持、従来の草/花/キノコと前回追加の木・花畑を含む保存マップ、24対象の選択・配置・削除・回転・非一様拡縮・保存再読込・Unity書き出しなど248項目。
- 36可動資産のWebGL2変換を実行し、静止・異時刻・位置別位相・最大風と接触・回転/非一様拡縮・固定点を確認。全24木質対象へ最大変位の包絡を8方向へ加え、面反転がないことも確認。
- 変更4種を本体の無風・そよ風・強風で時系列撮影。標準と0.6倍の接触高さ、連続接触の上限、離脱後の復帰、頂点配列が更新されないことを確認。高い樹冠は通常の人物に接触反応しない。
- 混在林・花畑と林縁・岩と倒木・世界樹と人物を真上/斜めで前後撮影し、世界樹の根元は近接比較も行った。描画はユーザーPCのChrome（SwiftShader）と隔離Unity。検査体格は1.8m、表示の主人公Remyは既存の身長約1.72m。
- Unity 6000.5.9f1 / URP / D3D11で49共有資産と26配置、旧v2〜v6、GPU変形・接触復帰・固定点、24対象の実描画など245項目を通過し、正常終了した。検査結果はローカルの証跡へ保存し、公開リポジトリへ大容量の生成画像やUnity生成物を含めない。

4配置の描画呼び出し回数は変更前後で同じ。共有JSは8,182,567→8,210,373 bytes、zlib圧縮の参考値は2,055,175→2,079,733 bytes。配信圧縮やスマホの実メモリの測定値ではない。

## 残る制限

小縮尺では枝下も下がる。急斜面への根の自動追従は実装していない。根の見た目と簡略な幹コライダーが完全に一致するわけではなく、細かい根の歩行物理はゲーム側の課題。風の変形は骨格による厳密な長さ保存ではない。

スマホ実機性能・ゲーム本体統合・Built-in実シーン描画は未検証。以前のD3D12終了時クラッシュは未解決で、今回は既知のD3D11を使う。世界樹の大きな葉面と影のピクセル負荷も、実機の性能保証はしていない。

生成元は `tools/plants/tree-canopies.js`、ベイクは `tools/plants/bake_trees.cjs`。比較配置は `tests/nature_scenes.js`。検査は `nature_polish_source.py`、`nature_polish_pixels.py`、`nature_polish_pose.py`、`nature_polish_validation.cjs`、`nature_scene_review.cjs`、`nature_scene_public.cjs` と既存のGPU・風接触・Unity検査を使う。
