# 遺跡30種のエディター統合

2026-11-06。採用済み30種を最新main（9a776b8）へ統合した。控え壁までの採用品を対象とし、後続の未採用アーチ・排水路試作は含めない。採用時の控え壁評価は91点（独立再採点ではない）。今回の作業は採用品の反映と互換性検証であり、新しい美術採点ではない。

## 使い方

ツール「遺跡を組む」を選び、「部材」から構造を選択して地図へ配置する。格子・接合・90度回転、寸法・仕上げ、選択削除、Undo/Redoを利用できる。保存は遺跡対応形式、Unity書出しは ruins_structures.json と必須機能情報を含む。

## 統合と保護

- 既存の橋下歩行、照明、風、敵ランク・旧マップ復元の変更を保持。
- 遺跡があるときだけ歩行キャッシュ署名に構造を含め、変更後の古い歩行結果の再利用を防止。遺跡がない旧マップの署名は維持。
- 元の未コミット作業は変更せず、隔離ブランチで統合。
- Unity配布Assetsは既存検証のGUIDを保持。従来のTerrain方式Importerとshaderを収録。

## 確認

- 実Chromeで起動、部材一覧30種、控え壁配置、Undoで消えること、Redoで復元することを確認。
- ページ由来のエラーログはなし。別のブラウザー拡張のethereum再定義エラー1件は対象外。
- map-archive.test.cjs、walk-preparation-compat.test.cjs（10項目）、cliff-shoulder.test.cjsを通過。
- ruins-integration.cjsで30種、歩行キャッシュ更新、旧署名保持、橋上下と遺跡床の優先を確認。
- 保存・形状・接合等の既存遺跡18テストと追加統合テスト1本、合計19本を統合版で再実行し全件通過。

## Unity側の区別

同梱ImporterはUnity Terrain/TerrainData方式。ゲーム本体のMapRoomTerrainImporterはMesh方式で、そのままのコピーでは接続できない。本体側の互換接続は別の隔離作業で進めており、このWeb側コミットだけを根拠に本体導入・Player動作完了とはしない。既存の専用Unity検証での歩行・Prefab/Scene再読込と本体検証は区別する。実機性能・モバイル・全組合せは未検証。
