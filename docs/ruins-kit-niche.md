# 壁龕（片面の窪み）

遺跡キットの既存24種・装飾24種を確認し、25番目の構造種 `wall_niche` を追加。単純な壁の連続に、通路を開けずに奥行きと装飾の焦点を作る。無装飾・装飾版を選択でき、既存配置は変更しない。

- 幅2m、厚さ0.5m、高さ2.2～4m。90度回転。長さ・厚さは固定。
- 窪みは局所座標の−Z側。幅1.1m、下端0.5m、上端は壁高−0.35m、深さ0.28m。背板厚0.22mを残す。
- 接合点は既存壁と同じ両端±1m、厚さ0.5m。格子・パーツ接合は既存処理を使用。
- 扉ではなく通行不可の壁。上下左右と背板から形状・Web衝突を派生し、Unityは出力した形状そのものをMeshColliderに使う。
- 元加工面を残し、窪みの露出縁にも既存の不均一な摩耗を適用。装飾は既存開口の彫刻意匠を壁龕幅に合わせ、追加テクスチャ・追加材質なし。
- 保存の正本は既存の遺跡構造形式。古いImporterは未知種別を検査時に拒否するため、この部材を含むexportには更新版Importerが必要。旧バイナリ自体の動作は未検証。
- 壁龕内に小物を自動支持する機能、任意幅、両面の窪みは今回含めない。

試験の根拠は `niche48-contract-result.json`、Webの正式保存/exportと専用Unityの結果に記録する。GPU・スマホ・Playerの性能保証はしない。
