# 洞窟3バッチの取り消し

ユーザーの指示により `e274f9d`、`01346c5`、`39cdcc2` をrevertした。品質改善や代替の美術制作は行わない。復元基準は直前の `7a001af`。水・波、茂み照明、貝殻・岩の接地、サンプルの事前計算と過去の性能修正は保持する。

## 復元範囲と保存互換

- 洞窟床へ差し替えた荒れ地の材質、微細凹凸、湿り表現、説明文を元へ戻す。追加前の共通地面シェーダーを使う。
- 石筍を旧形状・旧材質・旧接地へ戻す。洞窟壁の上端補正、入口シダの分類・説明、任意Unity壁置換、床用Unity拡張とフローストーンの特殊な影変更も取り消す。
- 既存103 IDの順序と形状を維持。追加2 ID `flowstone` / `cavebreakdown` は既に保存した配置を失わないため、互換データとして残す。通常の選択・散布一覧には出さない。既に置いた2 IDの外観まで別物に置換しない。
- 互換用画像・モデルとUnity読込許可だけは残るため、完全なファイル同一への復元ではない。既存103種の画面は旧版と比較する。
- 固定サンプルは旧版の完成データを再利用し、中身は変更しない。互換ID・スクリプト構成に対応する署名だけを更新する。

## 実際に何を変え、何を主張したか

確認できた発言・記録は次のとおり。これらを「一般の岩は丸いほど自然」という根拠にはしない。

| 記録 | 内容と実変更 |
|---|---|
| [旧CAVE_KIT.md 11行](https://github.com/Nishiki-JGG/MapEditor4-3DAPRG/blob/e274f9d/docs/CAVE_KIT.md#L11) | 石筍の幅広い基部・丸い頂部を参考にしたと記載。対象は石筍。 |
| [同17行](https://github.com/Nishiki-JGG/MapEditor4-3DAPRG/blob/e274f9d/docs/CAVE_KIT.md#L17) | 「旧288面の石筍を丸い成長形へ変更」。実際は新しい共有モデル366面へ置換した。今回撤回し、旧288面へ戻す。 |
| 親から転記された公開承認前の報告 Sentinel_c09a51c9cb488191974c2cddb7651dea | 「石筍を、尖った円錐から丸みのある自然な成長形へ改善」。数値検査や資料照合から美観の改善まで断定した点は適切でなかった。 |
| 同19行 | 新規崩落片は層状・角張った破片と記載。既存の一般岩・大岩・その共有画像は3バッチでは変更していない。 |

使用した資料は [NPS Speleothems](https://www.nps.gov/subjects/caves/speleothems.htm) と [Mammoth Caveの洞窟生成物解説](https://www.nps.gov/maca/learn/nature/stalactites-stalagmites-and-cave-formations.htm)。前者のStalagmites節は滴下による沈着物と頂部の形、後者は天井からの滴下地点と床の石筍の関係を説明する。一般の崩落岩や岩盤が丸いという説明ではない。資料の内容だけで今回の形状・材質・配置の美観を正当化しない。

コード上で変化した地面は、洞窟バイオーム中の荒れ地チャンネル。荒野バイオームそのものは条件外だった。ユーザーが見た画面の正確な状態は未特定だが、影響経路を含め3バッチ全体を取り消す。既存の一般岩の形を今回の変更が丸くしたという原因は確認されていない。以前からの岩変更を勝手に巻き戻さない。

ユーザーの「石筍は上からもワンセット」という意見は今後の検討事項として記録する。天井側・滴下地点・床側の文脈と真上からの視認性は、次回の設計時に扱う。今回は新しい鍾乳石や形状を追加しない。

## 確認範囲

ユーザーPCの隔離Chromeで、旧版そのものと同一照明・配置・カメラを使い比較。洞窟／荒野の荒れ地塗り、真上／歩行の4組は全画素一致。既存103種の位置・法線・頂点色・UV・index、既存共有資産・画像も一致。旧103 ID保存と互換2 IDの保存再読込を確認した。

この一致は取り消しの検証であり、美術品質の合格を意味しない。スマホ実機やゲーム本体への統合は未検証。
