# マップエディター 修正報告（Revision 12）主人公の体（Remy）

歩くモードの主人公を、ゲームで使う予定の体（Mixamo の Remy）にしました。マップの大きさ（通路の幅・段差・小物の大きさ）を、ゲームと同じ大きさの体で確かめられます。

- **見た目だけです。** 通行判定の体格（`state.agent`）・保存データ・Unity 向けの書き出しは変わりません。`exporterVersion` もそのままです。
- 画面左の「主人公の見た目」で、Remy と今までの簡易の人形を切り替えられます。既定は Remy です。

## 体（`hero/`）

- `hero/remy.js`：Remy の体のデータです（約 2.8MB）。
  - 7 部品で、頂点 21,459、三角形 35,196 です。
  - 大きさはゲーム本体と同じで、腰の高さ 0.95m、身長 1.719m です。
  - 腕を約 68 度下ろし、肘を少し曲げた立ち姿の静止形です。骨と動きは持ちません。
  - テクスチャは色だけです。体は 1024 画素、ほかは 512 画素です。髪とまつ毛は透明度の形で切り抜きます。
- `hero/build_remy.py`：`remy.js` を Remy の FBX から作る Blender のスクリプトです。
- `hero/hero.js`：データを three.js の形にします。
- 描き方：
  - Remy の材質は、普段は不透明です（部品どうしの描く順が乱れません）。
  - 隠し通路で岩に埋まった時だけ透過にして、前に描きます（今までの人形と同じ）。
  - 毒の上で光るのも、今までの人形と同じです。

## 確認結果

`node tests/hero_view.js`（Chrome をヘッドレスで操作）で、14 項目すべて合格しました。

| 項目 | 結果 |
|---|---|
| 部品・テクスチャの読み込み | 7 部品、テクスチャ 7 枚 |
| 既定の見た目 | Remy |
| 身長 | 1.719m |
| 足の裏 | 地面の高さとの差 0 |
| 顔の向き | 進む向き（内積 0.998） |
| 目の高さ | 1.591m |
| 普段の描き方 | 不透明 |
| 岩の中 | 透かしと戻し（全部品） |
| 毒の上 | 光る |
| 切り替え | 簡易の人形へ切り替えられる |
| 書き出し | 歩くモード・切り替えの後も 22 ファイルが同じ |
| ページのエラー | 0 |

- `node tests/water_unit.js`（17 件）と、`node tests/water_export.js <Revision 11 の写し>` も全合格です（既存の書き出しファイルは、Revision 11 とバイト一致）。
- 見た目は作った人とは別の担当が、正面・背中・左右・上からの絵で判定し、合格でした（腕のねじれ・テクスチャの崩れ・描く順の乱れなし）。
- ページの読み込みは 4〜5 秒でした（ヘッドレスの Chrome）。

## 注意

- `remy.js` は、Mixamo の Remy の形とテクスチャをもとにしたデータです。
- 歩く動きは付いていません（立ち姿のまま移動します）。
- 歩くモードのカメラは、ホイールで 7m まで寄れます。
- `rev3_acceptance.js` などの Playwright の試験は、今回は流していません（流した環境に Playwright がありませんでした）。
