# 敵の出現スポットの格

「マーカー」→「敵の出現スポット」→「敵の格」で選び、マップ上をクリックして配置します。

|格|保存値 enemyRank|表示半径の倍率|装飾|
|---|---|---|---|
|コモンエネミー|common|1|単円|
|中ボス|miniboss|1.45|二重円・4つの飾り|
|フロアボス|floorBoss|1.95|三重円・6つの飾り|
|ダンジョンボス|dungeonBoss|2.5|四重円・8つの飾り|

色は全て赤です。中央の印も格に応じて大きくなります。円の倍率は編集用の表示だけで、出現場所の予約半径は変更しません。

保存・読み込み・UNDO/REDO・Unity用書き出しで格を保持します。従来の格がない敵スポットはコモンエネミーです。自由入力のタグから格を推測しません。

Unity用メタデータの enemySpots に enemyRank を追加しました。既存の kind=enemy、id、tag、position、reserveRadius は維持しています。取り込み側では格がないデータを common と解釈してください。通常敵の配置には common のスポットだけを使い、ボス用スポットは対応する格を明示的に選んで使います。具体的な敵の種類・能力・進行条件はゲーム側で定義します。

確認: 実ブラウザーで4種の表示、旧保存の互換性、保存と復元、UNDO/REDO、Unity書き出しを確認（tests/enemy-ranks-browser.cjs）。
