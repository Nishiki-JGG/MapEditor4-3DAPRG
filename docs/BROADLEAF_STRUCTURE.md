# 広葉樹の枝骨格と樹冠の厚み

3c6019e を基準に、広葉樹・ナラ・ケヤキの幹から先の構造を作り直しました。色や葉の模様だけの調整ではなく、曲がる太枝、先細りの二次枝、その先の小枝、枝先に接続した複数の葉層を追加しています。

[同一カメラ・照明の変更前後](../tests/broadleaf_structure_compare.html) / [実エディタで裸地・草地・斜面を確認](../tests/root_reference_view.html) / [本体](../index.html#size=64)

## 変更した構造

- 広葉樹は外へ開く太枝と上部の内側の枝を組み合わせ、中央が大きく抜けた輪状の樹冠を避けました。手前と奥の葉層の間から枝が見える隙間を残しています。
- ナラは低めで厚い広葉樹冠、ケヤキは上へ開く扇状の枝ぶりとして、同じ配置を色だけで使い回していません。各枝の長さ・向き・分岐数と葉塊の大小には決定的な差を持たせています。
- 葉は既存の透過テクスチャを使う曲面の葉塊です。枝のない球で幹を隠したり、垂直な十字板へ置き換えたりしていません。
- 根と幹は元の頂点・法線・色・UV・固定ウェイトを三角形へ展開して完全一致を検査。既存の原点・設置外形・ID・風と接触の設定も保っています。丸い密な茂みを含む対象外47共有モデルと全7画像は完全一致です。

ユーザーの目標画像について親タスクが実際に見た、曲がる太枝と二次枝、前後に厚い葉層という観察を基準にしています。このPCでの添付取得は公式手順のWindows属性設定で失敗し、最終ファイルは設置されず、画像の実ピクセルは未閲覧です。別経路で取得していません。写真・透かしを素材へ転用していません。実在樹種の完全な植物学的再現ではなく、見下ろし用途のデフォルメです。

合計は4,165→15,654三角形（+11,489）、3,652→12,571頂点（+8,919）。各種1材質、共用画像7枚、樹木atlas 1024×512、RGBA8＋mip概算2.67MiBは同じです。alpha cutoff 0.42、両面、mipmap、異方性2も変更していません。atlasを共有していても、異なる樹種は別の描画になります。

共有データは8,803,371→10,054,450 bytes（+1,251,079）。同条件のzlib level 9参考値は2,399,426→2,722,078 bytes（+322,652）です。実際の配信圧縮方式による転送量そのものではありません。

葉面を真上へ投影して重なったまま合計した面積は、広葉樹36.21→71.24㎡、ナラ62.27→150.82㎡、ケヤキ43.28→145.14㎡。透明重なりと影の負荷が増える方向です。この値は実際の画面上のoverdrawやGPU時間ではありません。木を密に置く際の描画負荷増を、画像数据え置きだけで相殺できるとはしていません。CPUで頂点を毎フレーム書き換える処理は追加していません。

3c6019eの地面・配置を固定した1,204配置の比較では、通常視点は前後とも31描画、596,270→682,945三角形（+86,675、約14.5%）。真上は28描画、遠距離は61描画で、いずれも前後同数です。影にも同じ増量メッシュを使うため、影パスの面数も増えます。追加の影用モデル・デカールはありません。このフレームの集計を全パスのGPU時間とみなしていません。

比較画像は地面・照明を固定して枝葉の差を見ています。公開前に並行main `95b3fec` の草地・崖改善も保全して統合しました。統合後はカタログ97種、実行時の共有資産51種です。並行追加の細葉草について、Unityの許可ID・カタログと従来の高さによる風方式を受け入れ、既存の50資産のエクスポートも引き続き扱います。土際の色サンプル式は並行mainに合わせてUnityの根元材質へ対応させました。地形や水の機能をこのバッチで新たに作り替えてはいません。

## 検証と残る限界

変更前後の裸地・人物比較を、ユーザーPC上のChromeで真上90度と歩行補助視点から確認しています。初案は中央の穴と放射状の枝が目立ったため不採用とし、内側の枝葉の層と太枝の曲率を修正しました。根元を草で隠して判定していません。

標準スケールで動く頂点の最低高さは広葉樹2.83m、ナラ3.04m、ケヤキ3.30m。小縮尺で枝下の余裕が減る制限、15%上限の局所平面による根の追従、急な崖・凹凸での接地制限は残ります。葉塊の曲面の輪郭と近接時の葉模様の反復はまだ読み取れ、目標画像と同じ密度・写実品質へ到達したという意味ではありません。

ソース保全399項目、保存・配置・選択・回転・削除211項目、根の地面追従96ケース、裸地/草地/境界・太陽・縮尺・緩斜面96ケースを通過。可動38種と根付き24種のGPU座標で、無風一致、根幹固定、風と接触の合成、変位上限を確認しました。本体では対象3種に加えて茂み・針葉樹・龍血樹の計6種で、3風プリセットの時系列画像と接触・連続接触・復帰を検査。頂点のCPU書き換えはありません。標準高の樹冠は人型の接触対象にしていません。

最新main統合後の97種起動と保存互換、並行の草地・崖検査も通過しました。独立した色検査プローブは、並行mainの地表で使う微分命令に対して古いGLSL形式だったためコンパイルに失敗しました。プローブをWebGL2形式へ合わせ、破棄前の診断も記録するよう修正し、60点の色読み取りを再検証しています。実アプリのシェーダー失敗ではありません。

隔離Unity 6000.5.9f1/URP/D3D11では382項目＋根元材質173項目を通過。51共有資産の形状・法線・UV・頂点色、atlas PNGの完全一致、旧エクスポート、風/接触/GPU変形、細葉草1配置、裸地と緩斜面の根を確認しています。根元色60点のブラウザとの差は最大0.000116でした。照明・床・並行の崖機能まで含めて両エンジンの全画素が一致するという意味ではありません。

接触処理の参考値はユーザーPC Chrome/SwiftShaderで484配置・2,400step合計11.7ms、最大候補23。接触CPU処理だけの集計で、描画FPSやスマホ性能の測定ではありません。スマホ実機性能、ゲーム本体への統合、Built-in描画、プレイヤービルドは未検証です。既知のUnity D3D12終了時クラッシュは未解決で、隔離検査はD3D11を使用します。

再生成は `node tools/plants/bake_roots.cjs`。`broadleaf-structure.js` は生成時だけ使い、実行時システムを増やしていません。元の幹根の変換を保ったまま、対象3種の枝葉だけを正規の共有資産へ焼き込みます。
