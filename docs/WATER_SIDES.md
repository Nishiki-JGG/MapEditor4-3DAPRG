# 水の外周側面と強風の波（2026-10-29）

地図の端に水が接する部分に、水面から水底までの帯を表示します。水面の辺を再利用し、64mの地図で最大512区間、1メッシュ・1描画です。水の内部の体積は描きません。陸や内陸の池の周囲、溶岩には追加しません。

- 海では側面の上端も水面と同じ波で動きます。水位・地形・バイオームの変更時に更新します。
- 浅い色と深い色を深度で混ぜ、不透明度0.90〜0.98。海の上端には水面色と淡い照り返しを混ぜます。昼・夕方・夜・屋内と既存の点光源に追従します。
- 両面・深度書き込みなし。4辺を視点から遠い順に並べ、奥の帯が手前へ描かれる問題を抑えます。
- 強風の波で、周期が変わる瞬間の高さの飛びをなくしました。また、浅瀬の谷が海底を突き抜けないよう、水深の10%を残します。沖の波高は維持します。
- 色・泡に使う水深も画素側の波にそろえます。月の反射は継続します。

`sea.js` と `unity/Assets/MapWater/Runtime/Shaders/MapSeaShared.hlsl` は同じ波のコードです。変更時は `node tools/sea/build-sea-hlsl.cjs` で同期します。今回の側面描画追加はWeb側であり、受入先Unityの部屋への側面生成の接続は受入先で行います。

## 確認

`node tests/water-sides.cjs <画像と結果の出力先>`：実Chrome/GPUで周期境界16か所、浅瀬48時刻、昼夕夜・逆視点・海・池・屋内・溶岩・乾いた外周・内陸池を確認します。浅瀬の海底貫通は修正前21/48回、修正後0/48回。あわせて `tests/moon-reflection.cjs` と `tests/sea_hlsl_sync.cjs` を実行済みです。
