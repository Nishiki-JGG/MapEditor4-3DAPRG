# 主人公の体（hero）

歩くモードの主人公の見た目です。マップの大きさ（通路の幅・段差・小物の大きさ）を、ゲームの主人公と同じ大きさの体で確かめるために使います。

- **見た目だけです。** 通行判定の体格（`state.agent`：半径・身長など）、保存データ、Unity 用の書き出しには関わりません。
- 画面左の「主人公の見た目」で、Remy（ゲームの体）と簡易の人形を切り替えられます。既定は Remy です。

## ファイル

- `hero.js`：体のデータを three.js の形にします（`TDHero.add` で登録、`TDHero.build(id)` で作る）。
- `remy.js`：Remy の体のデータ（`build_remy.py` で作った物。手で直さないこと）。
  - ゲームの主人公用の体（Mixamo の Remy）です。
  - 大きさはゲームと同じで、腰の高さが 0.95m、身長が 1.719m です。
  - 骨付きです（骨 67 本、頂点ごとに 4 本までの骨と重み）。
  - 動きは 3 つです。止まっている時は腕を下ろした立ち姿、遅い時は歩き、速い時は走りです（Mixamo の Action Adventure Pack の walking・running、Remy 用）。
  - 歩き・走りは前へ進む分を取り除いて、その場で動く形にしています。ゲームの大きさでの進む速さは、歩き 1.63m/秒（1 周期 1.017 秒）、走り 4.25m/秒（0.7 秒）です。
  - エディターでは、移動の速さに合わせて再生の速さを変えます（足が地面を滑らないように）。普段（5m/秒）と Shift（8m/秒）は走り、浅い水（2.5m/秒）は歩きです。
  - 歩き↔走りの切り替えには戻りの幅があります（3.1m/秒を超えたら走り、2.8m/秒を下回ったら歩き）。切り替える時は足の位相をそろえ、約 0.2 秒で混ぜます。止まると約 0.1 秒で立ち姿へ戻ります。
  - テクスチャは色だけです。体は 1024、ほかは 512 画素にしています。
- `build_remy.py`：`remy.js` を作る Blender のスクリプトです。

```
blender -b --factory-startup -P hero/build_remy.py -- <Remy.fbx> <walking.fbx> <running.fbx> hero/remy.js
```

座標は three.js の向き（Y が上、顔は +Z）で、足の裏が 0、腰の真下が原点です。骨の名前は、Mixamo の名前から `mixamorig:` を外した物です（three.js のアニメーションの名前に `:` が使えないため）。

## 試験

`node tests/hero_view.js <出力フォルダ>` で確かめます。中身は次のとおりです。

- 部品とテクスチャが読めること。
- 身長が 1.70〜1.74m で、足の裏が立つ位置にあること。
- 顔が進む向きを向き、目の高さが合っていること。
- 岩の中で透けること。
- 簡易の人形へ切り替えられること。
- 歩き・走り：速さに合う動きになり、地面に着いた足が滑らないこと（着地中の足の平均の速さが、体の速さの 25% 未満。Shift は参考）。境目の前後で速さが揺れても入れ替わりが続かないこと。切り替えの前後で足先・膝が、切り替えない時の 1.1 倍より大きく跳ねないこと。止まった時と、壁に当たってキーを押したままの時に、立ち姿へ戻ること。描画の速さに左右されないよう、試験の中でエディターの更新を 1/60 秒ずつ進めて測ります。
- 切り替えの跳ねの原因を調べる時は `node tests/hero_switch_baseline.js` で、一定の速さと切り替えの時の 1 コマの最大を並べて見られます。
- ページのエラーが無いこと。
